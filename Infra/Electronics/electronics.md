## 电子学与电机控制

## 什么是电？电流与电子的方向之谜

在开始讨论任何电路之前，必须先搞清楚一件事：电流的方向到底是什么？

### 习惯电流方向

工程上，我们规定**电流的方向为正电荷从正电位运动到负电位的方向**。所有的电路方程——欧姆定律 u=Ri、基尔霍夫定律——都按照这个方向书写。

### 电子实际运动的方向

然而在导线中，真正能运动的只有**电子**。原子核里的质子被锁死在晶格结构里，动不了。电子带**负电**，所以在电场作用下，电子从负极出发，一路往正极走。

**习惯电流方向和电子实际运动方向——刚好相反。**

### 为什么将错就错

1747 年，本杰明·富兰克林用毛皮摩擦琥珀，发现有两种电荷，随手把一种叫正、一种叫负。1897 年，J.J. Thomson 发现电子——晚了整整 150 年。富兰克林相当于抛了个硬币，猜反了。

但全世界的教材、符号、方程全部锁死在习惯电流方向上。工程上统一按"正→负"来——基尔霍夫定律、欧姆定律、节点分析——符号统一即可。**你一辈子不需要知道电子实际往哪边跑。想多了反而混淆。**

## 直流电与交流电

电路里跑的电有两种基本形态——直流与交流。区别不在大小，在**方向变不变**。

### 直流电 DC

直流的电流方向保持不变，正极永远是正极，负极永远是负极。电池输出的是直流电——**所有的电子设备内部供电，全是直流电**。

对 Feelings 项目来说，FPGA、传感器、nRF52832 全吃 DC。电池出 DC，经过 LDO 降压稳压到 3.3V 和 1.2V，干净稳定地喂给每一个芯片。

### 交流电 AC

交流电的电流方向周期性翻转。50Hz 意味着每秒正反各 50 次。墙上插座输出的是 220V 交流电，波形是正弦波。

交流电对 Feelings 的意义不在供电——而在**测量**。AD5933 阻抗分析仪靠的就是交流电：输出一个扫频的正弦波去碰皮肤，读回来相位和幅值变了多少，从这两个变化反推皮肤阻抗。要用 DC 测阻抗——直流电直接打皮肤，会导致电极极化和化学灼伤。交流不打。

另一个关键事实：**示波器接交流地线和设备 DC 地线之间如果没有隔离——直接炸。** 这是 tDCS 安全隔离红线的物理根源：所有连接着市电地的下载器（ST-Link、CP2102、示波器探头）在人体测试时都必须断开。

## 电阻——电路中最基础的元件

### 欧姆定律

电阻的理想模型极其简单：电压和电流取关联参考方向，任何时候两端电压和电流服从欧姆定律。

**u = Ri**

其中 u 是电压（伏特 V），R 是电阻值（欧姆 Ω），i 是电流（安培 A）。

从另一个角度写：**R = U/I**——电阻不是元件本身，而是**那个元件对电流的阻碍程度**。1Ω 意味着 1V 电压能推出 1A 电流——通路很宽敞。22MΩ 意味着 1V 电压只能推出约 0.000000045A——几乎完全堵死。

常用的阻值范围为 **1Ω 到 22MΩ**。

### 串联与并联的本质区别

很多初学者以为串联和并联只是"接法不同"——其实它们的物理本质截然不同。

**串联电阻——阻值直接相加。**

R_total = R1 + R2。每多加一个电阻，相当于在电流的通路上多建了一堵墙。总电阻变大，电流变小。同一电压下，串联电路中流过的电流比任何一个单独电阻都小。

**并联电阻——电导值直接相加。**

G_total = G1 + G2 = 1/R1 + 1/R2。电导 G 是电阻的倒数（西门子 S），代表"导电能力"。并联时多个电阻同时提供电流通道——多打一个洞，两个洞一起流，总流量变大。电压不变，总电流变大。

一个常见的直觉误区："并联就是分流，总量不变"。**实际上并联是加带宽——每条路有自己的负载，不抢另一条路的电流。总电流比任何单路都大。**

## 基尔霍夫定律——电路的两条宪法

基尔霍夫定律是分析一切电路的基础。它包含两条独立的定律，分别对应**能量守恒**在两个维度上的投影。

### 基尔霍夫电流定律 KCL

**节点上所有电流的代数和为零。**

流进多少，流出多少。电荷不能凭空产生，也不能凭空消失。你在高中物理学过的"并联电路干路电流等于各支路电流之和"——那就是 KCL，只是当时没有告诉你它的名字。

### 基尔霍夫电压定律 KVL

**回路里所有电压的代数和为零。**

沿着任意闭合回路走一圈，推上去的电压和掉下来的电压——全部加起来——等于零。电源提供的能量，被沿途每一个电阻转化成热量带走了。

**P = I²R = UI = U²/R**——这三条公式是同一条能量守恒定律换了三件不同的衣服。热量公式、功率公式、欧姆定律——底层是同一件事：**能量既不会凭空产生，也不会凭空消失。**

## LDO 与负反馈——从控制论的视角看稳压

LDO（Low Dropout Regulator，低压差线性稳压器，如 AMS1117）如果只看表面，是一个非常无聊的元件——输入电压进、稳定电压出。但如果从**控制论**的视角去看，它是整个模拟电路思想的浓缩。

### LDO 的本质是一个自动反馈系统

LDO 的核心工作原理很简单：**用输出电压做反馈，自动调节串入回路中的晶体管的等效电阻，使得输出电压始终跟随内部参考电压，不受负载变化的影响。**

说白了就是**可调电阻串联分压**——负载重了（电流大了），反馈回路感知到输出电压有下降的趋势，立刻调高晶体管导通度（降低等效电阻），让更多电压加在负载上，输出端稳如磐石。

### LDO 的致命缺陷——发热

这个精妙的反馈机制有一个代价：**压差 × 电流 = 全部变成热量。**

LDO 的效率就是 Vout/Vin。输入 5V，输出 3.3V——效率只有 66%。剩下的 34% 全烧成了热。负载电流越大，烧得越狠。这就是 LDO 不适合大电流、大压差场景的原因。

### DC-DC + LDO——两级互补

工程上的经典解法：**前级用 DC-DC 开关稳压做粗调（效率高，但纹波大），后级用 LDO 做精滤（纹波干净，但压差小所以发热可控）。** 粗调加精滤，不发热也不抖。这和 Feelings 的多模态协同完全是同一种设计思想——不是替换，是分层。

## 电容与电感——动态电路的两个主角

一旦电路中的电压和电流不再静止不变，信号参与进来，就会用到两个新的基本元件：电容和电感。

### 电容——挡直流，放交流

电容由两块导体板中间隔一层绝缘介质构成。接通直流电：正电荷堆在一侧推不走，对面板上的负电荷被吸引过来但绝缘层挡住了——电子过不去。**直流被完全阻断。**

但如果是交流信号——电压一会儿正一会儿负——正半周把一面充电，负半周把电荷往回拉。电流实际上没有穿过绝缘层，但能量通过**变化的电场**从一侧传到了另一侧。**交流电被放行了。**

电容在 Feelings AFE 中的核心应用：

- **隔直电容**——AD5933 输出端串联一个电容，DC 偏置电压被拦死，只有 10kHz 的交流正弦波能过去碰皮肤。这是"AC 测阻抗不烧皮肤"的硬件实现。
- **低通滤波**——电容对地，高频信号走电容旁路到地，只有低频信号传到下一级。滤 PWM 毛刺。
- **电源去耦**——每个芯片的 VCC 脚旁边并一个小电容到地，瞬态电流从电容就近取，不会拖着整条电源轨抖动。

### 电感——挡交流，放直流

电感是一根绕成线圈的导线。通直流电：线圈就是一根普通导线，电流畅通无阻。**直流被完全放行。**

但电流一旦**变化**（比如通上交流电），线圈周围的磁场跟着变。电磁感应定律规定——变化的磁场会在同一根线圈里感应出一个**反向的电动势**，死死抵抗电流的变化。频率越高，抵抗越猛。**交流电被拦住了。**

电感在开关电源里当**储能元件**——先让电流慢慢建立磁场（储能），然后断开开关——磁场急剧坍缩，感应出高压把能量释放给负载。不是滤波——是能量中转。

## 正弦信号与频率响应——频域世界的语言

### 为什么是正弦波

正弦信号的数学表达式：**U = Asin(ωt + φ)**，其中 A 是幅值，ω 是角频率，φ 是初始相位。

正弦波在电子学中有不可替代的地位，因为它有一个独一无二的数学性质：**正弦波是描述线性电路特性的微分方程的解。** 给一个线性电路输入正弦波，输出必然也是正弦波——只有幅值可能被放大或衰减，相位可能被提前或延迟。波形本身不会变质。

AD5933 扫频就是依靠这个性质：它从低频到高频一串正弦波输出，逐个频率去问皮肤"你在这个频率下的阻抗是多少？"——如果输入不是正弦波而是方波，回来的信号里会混杂一堆谐波，你根本分不清哪个频率对应哪个阻抗。

### 频率响应——一张图看懂电路的性格

把电路对每个频率的"幅值放大多少倍、相位偏了多少度"画出来——横轴频率，纵轴幅值或相位——这张图就叫频率响应图。它是电路的**频域身份证**。

高保真音频放大器要求在 20Hz 到 20kHz 的范围内频率响应是**平坦的**——低频鼓声不衰减，高频镲片声不起伏——否则你听到的音乐比例不对。如果你设计的 50Hz 工频陷波滤波器要求把 50Hz 干扰压制 60dB 以上——频率响应图上就是 50Hz 那个点塌了一个很深的坑。

### 集总参数模型的适用边界——边沿时间比主频更危险

文中提到"FPGA 跑 24-48MHz，全在集总参数的安全领域内"。从基波频率来看完全正确，但信号的高频成分不仅取决于主频，**更取决于信号的上升/下降沿时间（Rise Time, tr）。**

FPGA 的 GPIO 输出翻转极快（tr 常在 1–2ns 级别）。根据经验公式 **f_knee ≈ 0.35 / tr**，其频谱能量可以延伸至 200MHz–350MHz。即使主频只有 24MHz，陡峭的边沿依然可能引发信号反射与高频振铃（Ringing）。

工程解法：在 FPGA GPIO 输出端（靠近源端）串联 **22Ω–33Ω 的源端匹配电阻**，吸收反射能量。当走线长度超过 f_knee 对应波长的 1/10 时（通常在几厘米量级），就必须加——FPC 排线跨耳挂到入耳延伸段的那几厘米——不加可能振。

## 工程补充——理论在真实电路中的四个关键坑

### 隔直电容必须用无极性电容

在 AD5933 AFE 的交流阻抗测量链路上，串联的隔直电容用于阻断 DC 偏置、只允许 AC 正弦波通过。**必须选用无极性电容（如 C0G/NP0 材质的贴片独石电容）。**

如果错用了有极性电容（如钽电容或铝电解电容），在 AC 信号的反向半周——电容两端电压极性反转——内部电解质会发生反向击穿与电解极化，产生严重的非线性失真，甚至直接损坏电容。

C0G/NP0 陶瓷电容在同体积下容值较小（通常 pF-nF 级），但温度系数极低、无极性、高频特性优异——是信号链路的首选。

### LDO 输出电容的 ESR 敏感性与自激振荡

LDO 的输出端通常并联一颗去耦电容到地。这颗电容的 ESR（等效串联电阻）不是越小越好。

**LDO（特别是低功耗、大压差型号）的输出对 ESR 极为敏感。** 如果 ESR 过小——例如直接并联了大容量的 MLCC 陶瓷电容（ESR 仅几 mΩ）——反馈环路的相位裕度会剧烈下降，导致 LDO 内部误差放大器自激振荡。结果：3.3V 输出轨上叠加几百 kHz 的巨幅正弦噪声，稳定电压变成噪声源。

工程解法：查阅所选 LDO 的数据手册中"Stable ESR Range"曲线——通常要求 ESR 在 0.1Ω–10Ω 之间。如果只有低 ESR 的 MLCC 可用，可以在电容支路串联一个小电阻（如 0.5Ω）人为提升 ESR，恢复环路稳定性。

### 高速信号：主频低不等于没问题

FPGA GPIO 的输出边沿在 1–2ns 级别——对应的频谱能量（f_knee）延伸到 200-350MHz。走长线或跨 FPC 排线时，即使主频只有 24MHz，陡峭边沿仍然会引发传输线效应——信号反射与振铃。

源端串 22-33Ω 匹配电阻可以吸收反射——放在靠近 FPGA GPIO 引脚的位置，不是靠近接收端。这条对 GW1N 到耳甲 AFE 之间的 SPI 总线尤其重要。

### 50Hz 工频干扰——三级协同压制

人体生物电采集（EMG/EEG/ECG）中 50Hz 工频干扰主要是**共模干扰**——信号线和地线同时被空间电磁场耦合抬升。单纯靠单端带阻滤波器（陷波器）硬切 50Hz，会引入严重的**相位非线性失真**——切掉的不止是干扰，还有同等频率附近的生理信号成分。

正确的做法是三级协同：

- **右腿驱动电路 DRL**——主动检测共模电压，反相放大后通过参考电极注入人体，在源头处抵消共模干扰。生物电采集的标配。
- **前级高共模抑制比（CMRR > 100dB）仪表放大器**——差分放大只取差模信号，共模成分被压制百万倍。
- **后级数字 IIR 陷波算法**——FPGA/DSP 端在线软件滤波，剩余残留再补一刀。

单靠任何一级都不够——共模干扰是无处不在的物理场，必须从电极到 ADC 全链路协同压制。

## 交流电路三大核心概念

### 相量法——正弦波的复数化妆术

两个正弦波相加：A1sin(ωt+φ1) + A2sin(ωt+φ2)。直接用三角函数算——套和差化积公式——又臭又长。数学家找到了一个捷径：**把正弦波压成一个复数 A∠φ**——幅值就是复数的模，相位就是复数的角度。两个正弦波相加减 → 两个复数直接加减——几行就出来。

傅里叶变换的数学底子就是相量法——把时域里上蹿下跳的正弦波压成频域里一个干净的点。AD5933 在你耳朵上扫频，FFT 吐出来的幅值和相位差——就是相量法在硅基芯片上的实时演算。

### 交流电路稳态分析——只看稳定之后的部分

电路刚上电时，电容在充、电感在建磁场——电压电流乱跳——这叫**瞬态**。过了一段时间，瞬态衰减干净了，电路进入**稳态**——只剩下一个稳定不变的正弦波在持续输出。

我们分析交流电路时，关心的不是上电那一瞬间——而是稳态之后信号怎么走。AD5933 在皮肤上扫到第三个频率点之后就是稳态——前两下的瞬态毛刺不管，只看稳了之后的那部分。

### 变压器——磁能过墙，电能不过

两个线圈绕在同一个铁芯上。交流电通入原边线圈→铁芯里产生交变磁场→磁场穿过副边线圈→在副边感应出电压。匝数比 = 电压比。

在 Feelings 的 tDCS 安全架构中，**隔离 DC-DC 电源（如 B0505S）内部就是一颗微型变压器。** 数字隔离器（ISO7721）负责隔离控制信号，隔离电源负责隔离供电——两者配合，把你和 220V 市电之间筑起一堵只有磁能穿过的墙。

## 频域分析与滤波——信号的地铁站

### 频域分析——换一个维度看信号

时域看信号：横轴时间，波形上蹿下跳。频域看信号：横轴频率，每一个频率上有多少能量。傅里叶变换就是做这件事——把一个复杂的时域波形拆成一组独立的、不同频率的正弦波的叠加。

AD5933 扫频本质上就是在频域里敲门——每个频率单独激励、单独响应——如果不分开频域，所有频率的信号混在一起，你根本不知道皮肤在高频和低频下行为有什么不同。

### 传递函数——电路对信号做了什么，一个公式说完

**H(jω) = 输出 / 输入。** 传递函数告诉你：对于每一个频率 ω，电路把信号的幅值放大了几倍，相位偏了多少。你耳甲电极到 AD5933 输出端那一段 AFE——隔直电容（高通）+ 运放增益（放大）+ 低通滤波器（去毛刺）——三级串联，每一级都可以写成一个独立的传递函数，相乘起来就是整条链的总传递函数。

以后要改参数——不用重新搭一遍——改一个电阻值，重新代入公式，输出就出来了。

### 滤波器——有选择地拦频率

- **低通滤波器**——高频滚蛋，低频通过。滤 PWM 毛刺，滤高频噪声。
- **高通滤波器**——直流别来，交流通过。隔直电容就是最简版的一阶高通。
- **带通滤波器**——只保留中间一段频率。呼吸信号 0.1-0.5Hz 就靠带通提取。
- **带阻滤波器**——只干掉一个特定频率。50Hz 工频干扰一刀切。

AD5933 AFE 输出端有一个经典的**三级滤波器链**：高通隔直（杀 DC）→ 带通取 10kHz 测量频率（排除其他频段噪声）→ 低通切高频毛刺（消除 ADC 采样前的 aliasing）。你第一个自己设计搭建的滤波器链就是这一条。

### 谐振——电容与电感的能量交换

在一个特定频率上，电容的容抗和电感的感抗正好相等——两个元件开始互相狂换能量。串联谐振：阻抗最小，电流飙到最大。并联谐振：阻抗最大，电流锯到最底。

无线电选频道就是靠谐振——调 LC 的谐振频率对准某个电台的频率，只让那一个电台的信号过来。你目前不太直接碰谐振，但要注意：如果 EMG 采集线上的寄生电容和引线电感**意外谐振**在 50Hz 附近——工频干扰不是被滤掉，而是被放大。

## 无源组件清单

### 开关

机械触点推上去接通，拉回来断开。tDCS 的**硬件熔断**就是开关的终极形态——电流超限→硬件比较器检测到→直接拉断电源轨——全程无 FPGA 参与。

### 继电器

电磁铁驱动的开关。小电流推电磁线圈→铁芯吸合大电流触点→用小电控制大电。隔离不靠继电器——光耦和数字隔离器速度更快、寿命更长。

### 连接器

排针排母、USB 口、柔性排线 FPC 插座、磁性 Pogo Pin。PoC 阶段杜邦线直插，简单粗暴。PCB 打样之后换成 FPC 连接器或磁吸触点——插拔几千次不能松动。

### 仪表

万用表确认 3.3V 在线。示波器看 I2C 边沿够不够干净。LCR 表测隔离寄生电容到不到 <5pF。**你不做仪表——你用仪表。**

### 指示灯

LED——第一个肉眼可见的硬件交付物。iCE40 上的 ball 39 绿灯，GW1N 上的 l1/l2。PoC 阶段的 LED 是最便宜、最诚实的 debugger——哪个模块卡在哪个状态，一个灯就说明白了。不需要串口打印，不需要示波器——灯亮了吗？

### 可变电阻

电位器——拧旋钮，阻值连续可调。AD5933 AFE 的运放增益倍数如果初期算不准——先焊一个电位器上去，手工拧到最优波形→然后用万用表测出当前阻值→换成固定电阻量产。**调试阶段拧一下，省你换三次电阻。**

### 通频带——放大电路对不同频率的放大能力

通频带用来描述放大电路对不同频率信号的放大能力。在频率较高或较低时，放大倍数的数值会下降并移相。同频段两端对应下限截止频率和上限截止频率。人耳能听到的声音频率为 20Hz∼20kHz，音响最好能覆盖这个范围。

对 Feelings 的影响有两条关键约束。

动圈入耳的放大电路必须覆盖 20Hz-20kHz 且平坦。Layer 3 暖音信号的低频锚定感在 20-80Hz——不是音乐——是安全基调的生理底噪。放大电路在 20Hz 以下衰减太多——那股"被包裹"的暖意——到不了耳膜。高频 15kHz 以上非必须——因为是信号，不是高保真交响乐。

AD5933 扫频范围不在音频带里。AD5933 最低激励约 1kHz——离 20Hz 远得很。低频阻抗（<1kHz 的 GSR 皮电）不在 AD5933 的扫频窗口内——需要外部分频时钟降 MCLK 才能测。但 10kHz 高频复阻抗测的是角质层+深层组织——够用——不需要覆盖人耳频段。

测量放大倍数，用中频小信号合适；测通频带，用小信号宽频来测。最大不失真电压 Uom 为有效值，使用大一点的信号测。

```
中频小信号测增益    PPG 纳安级光电流——先不管频响——先用 1kHz 正弦波把运放增益拉出来——确认倍数对。

宽频小信号测通频带  从 10Hz 扫到 100kHz——看 AD5933 AFE 在高低两端有没有塌——高通隔直别切多了——
                    低通滤波别在 10kHz 之前就衰减——那是皮电的窗。

大信号测 Uom        tDCS VCCS 恒流源——输出级推到最大不失真峰峰——确认大于 12V OVP 钳位轨——
                    否则电极开路时还没到 12V——信号先削顶了——OVP 没触发——皮肤先被信号失真电到。
```

测不了失真等于不知道你推到皮肤的电流有没有在放大电路里提前变形——不是波形漂了——是等控器收到的不是你要给的那组帧。

## 运算放大器简史——从真空管到电流镜

### 模电最初是为了做计算机

1930 年代，美国人要算弹道轨迹——用齿轮、杠杆、凸轮搭模拟计算机——电压代表数值，运放直接做加减法、积分、微分。运放的全名 Operational Amplifier——"运算放大器"——不是用来放大音频的，是**在模拟计算机里做数学运算**。后来数字计算机碾压过来——模拟计算机退场——但运放作为独立元件保留至今——现在用在 AD5933 AFE 里做信号调理。名字没改——场景换了。

### 从真空管到第一颗半导体运放

为了算得更快、更准，运放的性能被各大公司持续攻关。米勒效应出现了——高频下寄生电容把输出反灌回输入，放大倍数暴跌。振荡出现了——负反馈的相位偏了 180 度——反馈从"拉住"变成"助推"——电路自己嚎叫起来。人们通过物理模型逐步找到解决方案——但这时候运放还都是真空管——半导体尚未商业化。

1962 年，Bob Widlar 刚从科罗拉多大学本科毕业，在一家研究机构工作。他对电路设计的直觉吸引了供应商的注意。尽管挖客户跳槽是商业忌讳，这家公司还是想方设法挖到了 Widlar。1964 年，Widlar 主导研发的产品面世——**µA702，世界上第一款基于半导体的运算放大器**。世界从此进入了一个新时代："超大规模集成电路"。这家挖墙角公司叫**仙童半导体。**

### 电流镜——差模到单端的无损转换

和之前的真空管运放一样，µA702 也采用了两级电压放大。面临同一个难题：**如何在不牺牲增益的情况下，将一个差分信号转换成单端信号？** 差分信号有两根线——信号各占半周——如果只取一根，直接丢掉一半。之前的 K2-W 就真的丢掉了。

Widlar 用 **9 个 NPN 三极管搭出了一个后人至今无法凭直觉还原的电路——他把差模信号向上抬高了一半，同步保留了两条线的全部能量，从而避免了失真。** 这就是所有教材里电流镜（Current Mirror）的由来——不是凭空理论——是一个工程师为了解决"差一半"这个具体的物理问题而硬造的。

### 这和 Feelings 的关系

Widlar 面对的问题——差模到单端、信号损失一半、Miller 效应、环路振荡——和 Feelings 的 PoC 调试面对的是同一类问题：

```
电流镜 = 两条差分线无损合一路
     → Feelings 的耳甲 Arnold + 耳背耳大神经两路信号在同一帧融合进岛叶
       岛叶做的是同一件事——多输入单输出的无损融合

Miller 效应 = 高频寄生电容反灌
           → AD5933 100kHz 扫频时隔离 DC-DC 寄生电容 <5pF 的约束
             就是 Miller 效应的现代翻版——高频下小电容阻抗骤降

振荡 = 负反馈相位翻转
     → LDO 输出电容 ESR 过小→自激振荡——同一个物理机制
       PBM 闭环如果相位不对——等控器来回摆——纠不过来
       "慢修、稳修、彻底修"——就是给碳基等控器的环路做相位补偿
```

**模电最早真的是为了做计算机。但真正让模电活下来的——是它在任何需要和小信号打交道的地方——都是最诚实的那把钥匙。** Widlar 在 1964 年解决的是一个信号转换问题。你在 2026 年解决的还是同一个问题——只是介质从硅换成了碳。

### 从运放到模拟芯片设计——Widlar 的后续三部曲

Widlar 把几个三极管集成在一个器件中的这种行为，被后人称为**"模拟芯片设计"（Analog IC Design）。** 而这时，神的故事才刚刚开始。

**比较器——710 和 711。** Widlar 在搞定运放之后，顺手设计了专门用于比较功能的芯片——比较时间缩短至 40ns，将当时其他基于普通运放的带宽扩展了十倍。这种专门用来比较的运放被称为**比较器**（Comparator）。这就是教材里比较器那一章的由来——不是"运放比较两个电压"——是**专门优化了速度、牺牲了线性度的一颗独立器件。**

**μA726——军品温漂。** 之后 Widlar 又搞了 μA726，将温漂压到 0.2µV/°C，满足军品的全温度参数（-55°C 到 +125°C）。这就是教材里温漂那一节的由来。

**为什么这时候计算机需求这么大？** 美苏冷战开始了，军事和航空航天产业升级迅速铺开。国家每年将 GDP 的百分之几十用在科技创新上，半导体产业进入举国体制。

### 第一款线性稳压器的诞生

1965 年，Widlar 要求仙童加工资被拒绝。于是他带着同事 Talbert 离职，进入美国国家半导体公司（National Semiconductor）。跳槽之后的第一款产品是 **LM100/101A。**

Widlar 想：电流镜能做信号运算——**同样能做功率控制。** 于是用同样的思路设计了一款**基于运放原理的稳压器——世界上第一款线性稳压器。** 这就是教材里直流稳压电源那一章的由来，也是所有线性稳压器件的起点。

后面你用的 AMS1117、TPS7A4700、LDO 全家——都是 Widlar 1965 年那台 LM100 的直系后代。**运放不是只用来放信号——运放对标的是"任何需要把小信号转换成控制能力的物理场景。"** 稳压就是把输出电压的变化当成小信号——反馈给运放——运放去调功率管的电阻——小信号控制大功率。和 Feelings 的"微安级电流控制 HPA 轴→皮质醇潮"是同一条公式——只是基底从硅换成了碳。

### Widlar 创造的概念清单

```
µA702        世界上第一款半导体运放（1964）
710/711      世界上第一款比较器，40ns 响应
µA726        军品温漂 0.2µV/°C，-55°C to +125°C
LM100/101A   世界上第一款线性稳压器
电流镜       差模→单端无损转换，9 个 NPN 三极管
```

**一个 26 岁本科毕业生——在两年内——把模拟芯片设计的五大分支全部点开。** 不是"他赶上时代"——是大部分时代还没来得及被定义——就被他的手画上了线。

### LM317 与电压基准——把电压钉死在千分之一

**LM317 就是 Widlar 线性稳压思路的曾曾曾孙子。** 这款器件最大的特色是——无论负载怎么变，输出电压稳稳地定格在一个常值。这对电源的发展无疑做出了巨大贡献。

Widlar 的线性稳压思路同时诞生了另一个产品：**电压基准芯片（Voltage Reference）。** 在模拟电路中，电压需要一个绝对准确的标准作为参考电压——比如 5V 就应该是 5V。如果实际变成了 5.01V，那么最后的计算结果就跑偏了——相当于计算机的浮点精度崩塌。而 Widlar 的稳压思路大大提升了整个模电的参考电压精度标准。这就是教材里电压基准那一章的由来。

### CTAT——怎么把电压钉死

怎么把一个电压基准死死地钉在一个值上？Widlar 想到了二极管的导通电压是 0.6V——很固定。但问题来了：这个导通电压会随着电流和温度的变化而变化，高达 **0.3%/°C**。如果温度从 25°C 升到 85°C——0.6V × 0.3% × 60 = 漂了 108mV——基准已经废了。

如果能对这个电压做一个 **2mV/°C 的补偿**将是极好的。于是 Widlar 基于电流镜的经验，设计出了 **CTAT（Complementary To Absolute Temperature，负温漂系数电路）**——从物理原理上证明了输出电压可以和温度无关。电压准确度被精确钉在了 5mV 以内，即**千分之一。**

**硅管正向压降到底是 0.6V 还是 0.7V？** 两个都对。硅管正向压降不是一个精确常数——0.6V 到 0.8V 之间，随电流和温度漂移。小电流偏 0.6V，大电流偏 0.7-0.8V。教材取 0.7V 是折中——Widlar 拿 0.6V 做基准是因为那个电流点更稳、温漂更容易补偿。**0.6V 本身随温度漂 0.3%/°C——不用 CTAT 钉住的话，电压基准就是个温度计。**

### PN 结电流方程——为什么二极管的 0.6V 不是一个常数

CTAT 背后的物理基础藏在 PN 结的伏安特性里。PN 结的电流和电压不是线性关系——是指数关系。这条方程是 Shockley 在 1949 年从半导体物理里推出来的，是所有二极管分析的地基：

```
I = I_s × (e^(V / (n·V_T)) - 1)
```

每一项拆开看，每一帧都有自己的物理分量：

- **I** —— 流过 PN 结的总电流。正向偏置时电流从 P 区流向 N 区。反向偏置时等于 -I_s（极小，接近零）。
- **I_s** —— 反向饱和电流。由半导体材料本征激发产生的少子漂移形成。硅管的 I_s 通常在 nA 到 pA 量级。温度升——本征激发增强——I_s 变大——这是导通压降温漂的根源。
- **e** —— 自然常数，约 2.718。指数关系的底，电流随电压按 e 的幂次增长。
- **V** —— 外加在 PN 结两端的电压。正向偏置时 V > 0——P 区接正、N 区接负——势垒降低——多子扩散占主导——电流指数级增长。反向偏置时 V < 0——势垒拉高——电流被 I_s 锁住。
- **n** —— 理想因子。理论值 n = 1——对应纯扩散电流。实际硅管 n 在 1 到 2 之间——复合电流掺了一脚：耗尽层里的电子和空穴在中途撞上了——没穿过结——没形成有效电流——但消耗了电压裕度。
- **V_T** —— 热电压。**V_T = kT/q。** k 是玻尔兹曼常数（1.38 × 10⁻²³ J/K），T 是绝对温度（开尔文），q 是电子电荷（1.6 × 10⁻¹⁹ C）。室温 25°C（约 298K）下——V_T ≈ 25.8 mV ≈ 26 mV。这个 26 mV 不是电路里随便取的——是物理常数在室温下算出来的。

正向偏置下 V >> V_T（几十毫伏以上），e^(V/V_T) 远大于 1。方程简化为：

```
I ≈ I_s × e^(V / (n·V_T))
```

换个写法——电压由电流决定：

```
V ≈ n·V_T × ln(I / I_s)
```

这就是为什么二极管导通压降约 0.6-0.8V。把硅管参数代进去——I_s ≈ 10⁻¹² A，n ≈ 1.5，V_T ≈ 26 mV，I = 1 mA——V ≈ 1.5 × 0.026 × ln(10⁻³ / 10⁻¹²) ≈ 1.5 × 0.026 × 20.7 ≈ **0.81V。** 电流小一点——0.1 mA——V 掉到 0.7V 左右。再小——10 µA——V ≈ 0.6V。二极管的 0.6V 不是材料送的——是指数曲线的一个点。

回到 CTAT。温度升高——V_T 线性增大——同时 I_s 也随本征激发指数级增大——I/I_s 减小——ln(I/I_s) 减小——**V 下降。** 每度约 -2 mV——即 0.3%/°C。Widlar 的 CTAT 电路做的是反向补偿——温度升→另一路电路输出升→两路加起来→输出电压咬死不动。

对 Feelings 的意义：AD5933 扫频激励电流经过 VCCS 送到皮肤电极。电极界的 PN 结不是硅——是皮肤-电极界面的容性/阻性复合阻抗——但电流和电压的关系同样不是线性的。**非线性不是 bug——是指数曲线的物理性质。** 不懂 PN 结方程里的 I_s 为什么要随温度指数级增长，就不懂为什么冬天干手皮电测量偏差大——I_s 小了——信号通路在源头就塌了。

### PN 结的平衡——耗尽层、内建电场、两股相反的电导流

PN 结合金之后，耗尽层平衡，结构是三层：

```
P 区（中性区）        耗尽层（空间电荷区）        N 区（中性区）
─────────           ─────────────          ─────────
多子=空穴              空——没有自由载流子         多子=自由电子
少子=电子              只剩固定离子：             少子=空穴
                      P 侧是负离子（受主 B⁻）
                      N 侧是正离子（施主 P⁺）
```

关键就一个词：**"耗尽"——耗尽的是自由载流子，不是杂质。** 平衡之后：

1. **中性区不变**——P 区还是空穴当家（掺杂浓度决定多子浓度），N 区还是电子当家。
2. **耗尽层里什么都没有**——多子越过结扩散之后被复合/被电场拉走，留下不能动的离子，正负离子在结两侧面对面站着，形成内建电场。
3. **平衡 = 两股流抵消**——多子想扩散过去（浓度梯度推的），内建电场把扩散过来的少子又推回去（漂移）。扩散流 = 漂移流，净电流为零。不是双方都停了，是两股相反的流互相咬死。

电场方向和载流子流向要拆开理清：

```
           P区（负离子）──耗尽层──N区（正离子）
                │  ←─ 内建电场 E（正→负，N→P）─→
                │
 扩散流：N区多子电子 ──────────────→ 往P区跑（浓度梯度推的）
 漂移流：P区少子电子 ←────────────── 被电场拽回N区（受力与E相反）
                │
           平衡 = 两股流大小相等、方向相反 → 净电流为零
```

- **电场方向**：正电荷指向负电荷——所以从 N 侧正离子指向 P 侧负离子，即 **E 从 N 指向 P**。
- **电场的力**：电子带负电，受力与电场相反——把 P 区少子电子推回 N 区（漂移）。
- **浓度梯度**：N 区多子电子浓度高，往 P 区扩散（扩散）。
- **平衡**：扩散想过去，电场拉回来，两股咬死，净流为零。**多子想扩散（不平衡的推力），电场推少子回来（平衡的阻力），推到电动力等于扩散力，就稳态了。**

只有一个流那叫短路——PN 结是两股流对峙。结的宽窄由掺杂浓度决定——重掺杂结窄（齐纳能隧穿），轻掺杂结宽（雪崩有跑道）。前面两种击穿，就是在这块对峙区里演的。

### 正偏导通——Vbe 的过路费模型

平衡态是"没加电压"的静止画面。加上正向电压之后发生什么？**外加 Vbe 抵消一部分内建势垒——势垒从 Vbi 降到 Vbi - Vbe——矮到多子能大量翻过去——电流指数爆炸。** 把导通压降拆成两笔账：

```
Vbe = 抵消（性格价）+ 驱动（记账价）

抵消    买下内建势垒 Vbi——材料定死的——硅 ≈ 0.6~0.8V——
        0.7V 就是硅结"抵消势垒需要"的量级——性格签名
驱动    剩下的电压推电流——对数项 n·V_T·ln(I/Is)——电流的记账——很小

开关点就在 Vbe ≈ Vbi 附近：
  远低于它    势垒还高——电流指数级小——截止
  接近它      势垒矮到极限——电流指数爆炸——导通
  超过它      势垒完全抵消甚至反转——大电流（功率管 Vbe 到 0.9-1V）
```

**为什么 0.7V 能当工程常量用——对数压缩窗口：** 指数关系的反向是对数——电流从 1µA 涨到 100mA（10 万倍），Vbe 只从约 0.55V 动到 0.75V（0.2V）。每十倍电流 Vbe 只涨 60mV（ln10 × V_T = 2.3 × 26mV）——**巨大的电流范围被压进窄窄的电压窗口——任何正常范围的电流，落进去都读 0.6~0.8V。** 不是 Vbe 被固定，是它天生对电流迟钝。工程上取 0.7 几乎不会错，因为错的范围只有 0.2V，而电流可以错十万倍。0.7 是硅的性格代表值——像 π 取 3.14——不是性格本身。边界：功率管大电流 1V+、锗管 0.3V、温度每度 -2mV/°C——全在这个窄窗口附近，取 0.7 的近似始终够用。

**对三极管：** 发射结就是一个 PN 结——Vbe 就是三极管让电流过发射结要交的"过路费"——大部分买下内建势垒（性格价），小部分推电流（记账价）。这也是工程上"不用电压源直接驱动基极、永远用电阻喂电流"的原因：Vbe 对电压极其敏感（60mV 翻 10 倍），电阻吃掉电压的不确定性，剩下的才是设计者的。

### 空穴的本质——缺失态、状态传播与统计流

空穴不是实物粒子。**它是"电子缺席"这个状态的拟人化**——物理上叫准粒子（quasiparticle）：数学上完全按真实粒子处理（有自己的有效质量、迁移率），本质是一个缺失态的集体行为。

```
P 型掺杂后：
  受主负离子（B⁻）——固定在晶格位置——不动的骨架
  空穴（缺失的电子态）——不属于任何原子——属于整条价带——
  可以在整个晶格里自由移动

空穴=晶格里的气泡：气泡不是实物（是水的缺失），但会上浮、会扩散——
载体是抽象的，动力学是真实的
```

**空穴怎么移动？靠电子的接力跳变：** 电子跳进空穴→空位在原位消失→在电子原来的位置出现——空位转移了。看起来就是空穴在移动，方向与电子相反。**这本质是"状态传播"不是"实体平移"：** 每个格点只是在"被占据/空着"之间翻转，翻转序列看起来像空穴在走——像多米诺骨牌：没有一张牌移动，每张牌只是原地倒下，"倒下"这个状态在传播。波函数同理：ψ(x,t) 在每个点的值随时间演化，"波的传播"是图案的传播，没有波包在平移。

**而这是物理的通用图景——所有"移动"都是状态转移：**

```
声波      空气分子只在原地振动——传播的是"压缩状态"不是空气
光        场的每个点在振荡——传播的是场图案不是物质
空穴      每个格点翻转——传播的是"缺失态"
```

**微观是翻转，宏观是流：** 空穴的"扩散"是真实物理效应——热涨落造成的翻转在统计上不是均匀的——浓度高的地方向浓度低的地方多翻了几格——**统计偏差积累成净流。** 单个空穴不存在，扩散流存在——实体是抽象，流是真实。

对三极管：Ib 里的"多子扩散项"（基区空穴注入发射区）就是这个状态传播的宏观投影——发射区重掺杂，两边空穴浓度差巨大，净流从基区涌向发射区——这就是"发射效率"的物理源头。

### 产生-复合的能量循环——半导体为什么永远发热

复合和产生不只是"载流子的生灭"——它们带着一份能量账：

```
产生    吸收能量——热能踢电子上导带（本征激发）——温度越高产生越多
复合    释放能量——电子落回价带——释放 ≈ Eg（硅 1.12eV）——
        大部分变成热（声子），少部分发光（辐射复合）
```

**"车和车位一起拆掉"的时候，拆出来的就是能量。** 硅是间接带隙，复合必须借助声子（动量不守恒），所以硅的复合几乎全变成热——半导体器件永远发热的根源。而 LED 是"复合走发光路线"的特例：复合释放的能量直接变成光子，光的颜色 = 带隙（红光 1.8eV、蓝光 3.0eV）——**LED 就是把"复合的尾气"改造成了产品。**

而产热恰好是热失控正反馈循环的燃料：

```
温度↑ → 产生率↑（指数）→ I_s↑ → 漏电↑ → 功耗↑ → 结温再↑
→ 热失控/热击穿——半导体最该防的东西
功率器件上散热片、降额设计——管的就是这个循环的尾巴
```

完整闭环：

```
性能写死（性格）    掺杂、结构、材料——出厂焊死——Is、β、击穿电压
环境施压（外部）    温度、电压、光——可变的输入
产生-复合（呼吸）   吸收能量产生、释放能量复合——动态循环
复合产热（尾气）    循环的代价——也是热失控的燃料
```

**半导体 = 一台写死参数的呼吸机：性格出厂定死，环境决定呼吸快慢，呼吸产热，热反过来决定呼吸——管住热，就管住了这台机器的命。**

### 三极管的工作状态——偏置组合与四区控制权

**正偏 vs 反偏**——外加电压的方向问题：

```
正偏    P 接正、N 接负——顺着 PN 结导通方向——
        削弱内建电场——势垒变矮——多子能扩散过去——导通
反偏    P 接负、N 接正——反着 PN 结导通方向——
        加强内建电场——势垒变高——多子过不去——截止
```

**三极管四状态由两个结的偏置组合决定**（"发射结正偏、集电结反偏"不是默认值——是放大状态的偏置钥匙）：

```
放大    发射结正偏 + 集电结反偏    Ic = β·Ib——线性放大
饱和    两个都正偏                 导通——开关闭合
截止    两个都反偏                 关断——开关断开
倒置    发射结反偏 + 集电结正偏     几乎不用——倒置 β 极小
```

**为什么放大必须这个组合——两个门模型：**

```
发射结正偏 = 开入口门——N+ 发射区电子涌进基区——原料放行
集电结反偏 = 开出口吸——反偏电场把穿过基区的电子全吸向集电区——
             只收不发——电子不会回流
组合 = 原料进、成品出——单向放大链——
    注入量由发射结电压控制（门开多大）——
    收集率接近 100%（出口吸力全开）——
    复合率固定（基区结构决定）——
    注入量按固定比例分成 Ib（复合）和 Ic（收集）
```

**饱和 vs 击穿——谁到顶了：**

```
饱和    电流到顶——Ic 被外部电路限住：Icsat ≈ Vcc/Rc——
        管子电压被压到 Vcesat（0.1-0.3V）——集电结变正偏——
        "电路不想给了"——安全可逆——减小 Ib 就回来
击穿    电压到顶——Vce 超过击穿电压 BVceo——雪崩/齐纳——
        载流子倍增——电流失控——"管子扛不住了"——
        不可逆——可能热失控烧毁

外接电阻的角色：
    Rc 设定了 Icsat——让"电流到顶"恰好发生在电压安全的位置——
    把"到顶"从危险的电压区推到安全的电流区——
    Rc 在——电路先到顶（饱和）——Rc 不在——器件先扛不住
    （过流烧毁或击穿）——设计者的工作：决定"让谁先到顶"
```

**三区控制权——Ib 的地盘只有一段窄路：**

```
截止    Ib≈0——Ic≈0——电路说了算
放大    Ic = β·Ib——Ib 说了算——唯一的"控制区"
饱和    Ic ≈ Vcc/Rc——电路说了算——Ib 失去控制——
        继续加大 Ib 进"深饱和"——代价不是电流变了——
        是退出饱和变慢（存储时间）——开关应用要处理的

设计者的全部工作：让三极管待在这段窄路里（偏置设计）
```

### 伏安特性的两条温度经验规则——正向区和反向区的两个切面

伏安特性曲线最值钱的部分不是形状——是它的两条温度规则。都是 Shockley 方程的直接推论，工程上天天用：

```
温度 ↑1°C          正向压降 ↓2~2.5mV      （规则一——做温补用的）
温度 ↑10°C         反向电流 ×2            （规则二——做功耗预算用的）
```

**规则一：正向压降 -2 到 -2.5mV/°C。** 从 V ≈ n·V_T·ln(I/I_s) 看——温度升高，V_T 线性增大（+0.086mV/°C，小头），但 I_s 指数级暴涨（大头），ln(I/I_s) 被拉下来——净效果是 V 每度降 2mV 左右。硅管取 -2mV/°C，有些教材写 -2.5。这也意味着**二极管本身就是一个线性温度计**——测它的正向压降就能读温度。

**规则二：反向电流每升 10°C 翻一倍。** 从 I_s ∝ n_i² ∝ e^(-E_g/kT) 看——E_g=1.12eV 塞进指数里，温度每动一点，漏电流就指数级动。10°C 翻倍是经验值，实际硅管大致在这个量级（锗管更敏感）。

```
正向区（规则一）                      反向区（规则二）
───────────                       ───────────
切的是 V ≈ n·V_T·ln(I/I_s)         切的是 I_s ∝ e^(-E_g/kT)
每度降 2mV——线性                    每 10°C 翻倍——指数
用途：温度补偿                      用途：功耗预算
```

两条规则就是伏安特性曲线的两个切面——一个切正向区，一个切反向区。工程上全靠这两条：CTAT 温补是规则一的逆向操作；电源待机功耗估算看规则二——温度一高，漏电翻倍，电池待机时间缩水。这也是为什么之前说"0.6V 不是常数"——它是规则一在跑。

### 雪崩击穿与齐纳击穿——同一个反向区，两条相反的温漂

反向偏置推到极限会发生击穿——电流突然暴增——但击穿不是一种机制，是两种，且对温度的态度完全相反。根子都在结宽上。

**雪崩击穿——宽结、轻掺杂——正温度系数。**

结宽，载流子在电场里能跑的距离长。反向电压拉高电场→电子在结里加速→撞晶格原子→电离出新的电子空穴对→再加速再撞→雪崩级联。

温度升高，晶格原子振动加剧（声子多），电子每走一步都被散射，攒不到足够的动能去电离。要维持同样的电离率，只能把电场拉更高——**所以温度越高，雪崩击穿电压越高。** 电压大约 7V 以上的击穿基本都是雪崩。

**齐纳击穿——窄结、重掺杂——负温度系数。**

结太窄，载流子不需要跑——直接量子隧穿。电子从价带"穿"到导带，穿过去的是势垒，概率取决于势垒厚度（结宽）和能隙宽度。

温度升高，半导体能隙 E_g 变小（负温漂），势垒变矮，隧穿更容易——同样的电压下电流变大——**所以温度越高，齐纳击穿电压越低。** 电压低于 5V 的击穿基本都是齐纳。

```
               宽结、轻掺杂                      窄结、重掺杂
               ───────────                     ───────────
击穿机制        雪崩——碰撞电离级联                 齐纳——量子隧穿
载流子        加速撞晶格——电离新对                直接穿势垒——不跑
温漂            正：T↑→声子散射↑→要更高电场         负：T↑→E_g↓→势垒变矮→更低电压就穿
温度系数        +mV/°C                           -mV/°C
典型范围        7V 以上                          5V 以下
```

**5V 到 7V 之间两种机制共存**——雪崩的正系数和齐纳的负系数互相抵消，温度系数可以压到接近零。所以精密基准稳压管都选 5-6V 档位。Widlar 当年拿 0.6V 二极管做基准是另一个解法——但"找个温漂互相抵消的档位"这个思路是一样的。

对 Feelings 的意义：AD5933 内部扫频激励和 VCCS 驱动都工作在远低于击穿电压的安全区，但 AFE 入口的 ESD 保护二极管——静电瞬间能把结推到击穿区——雪崩型的 ESD 管温漂是正的，齐纳型的温漂是负的。选型时如果只看了击穿电压没看温度系数，在 -20°C 到 +40°C 的穿戴场景里，ESD 触发阈值会漂移——本该在 12V 触发保护的，冬天可能 11.5V 就泄放了，夏天 12.5V 才动作。**击穿电压不是门槛——是一个随温度漂移的区间。**

### 反向推导——升温为什么不能用来"防雪崩"

既然雪崩击穿是要避免的，而温度升高会抬高雪崩击穿电压——那能不能反着用，主动升温来防击穿？

这是 f(x)=y 和 y=f(x) 的关系——同一个函数，但反着推出来的结论在工程上不成立。

```
正向（物理事实）                          反向（错误推论）
─────────────                          ────────────
温度升高 → 雪崩电压升高                   "那升温就能防雪崩了"
温度升高 → I_s 指数级暴涨                 "I_s 暴涨没关系，反正击穿电压高了"
```

反向推导漏掉的正是正向推导里那个指数项。温度升高确实把雪崩击穿电压抬上去了——但同一时间，I_s 在指数级暴涨（Shockley 方程里就是它）。漏电流变大→功耗变大→结温再升→I_s 再涨——正反馈循环，最终触发**热失控（热击穿）。**

```
降温                                温度升高
────                               ──────
雪崩电压 ↓                          雪崩电压 ↑——看似"更难击穿"
漏电流 I_s 小                       漏电流 I_s 指数级暴涨 ← 真正致命的
器件安稳                            功耗↑→结温↑→I_s↑→功耗↑……正反馈 → 热击穿
```

雪崩击穿本身是可逆的——电压撤了结就恢复。热击穿是不可逆的——结被烧穿，器件直接报废。把温度当"防雪崩手段"等于用枪伤换子弹穿膛——躲过了碰撞电离，没躲过热失控。

工程上避免雪崩的正道是**降额设计**——留电压裕量，工作点远低于击穿电压。热永远是半导体最该防的东西，不是该利用的东西。真正"利用"雪崩的只有 TVS/ESD 管——故意工作在击穿区的器件——靠它快速泄放和可恢复——但也只有那一瞬间允许，持续功耗照样烧。

### V 与 Uon——电源给多少，二极管要多少

新手最容易混的两个量：电源电压 V 和导通压降 Uon。它们是两个完全不同来源的东西：

```
V      电源电压——电路给的——设计输入——"我提供多少"——所以电路图上必须标
Uon    导通压降——器件自带的——固有属性——"二极管要拿走多少"——硅管≈0.7V是常识，图上不标
```

**关系就是一条最简单回路的算账：**

```
V = 5V，R = 1kΩ，硅管 Uon = 0.7V

电流 = (V - Uon) / R = (5 - 0.7) / 1000 = 4.3mA

电源先付掉二极管要的 0.7V，
剩下的 (V - Uon) 才轮到电阻去产生电流。
```

图纸只标设计输入（V），Uon 隐含在器件型号里——1N4148、1N4007 全是硅管，默认 0.7V，查手册或凭常识就知道。**用万用表量任意一个导通的硅二极管，两端永远 ≈0.7V——量到的不是电源给的，是器件自己"咬住"的那一口。** V 必须大于 Uon 电路才能工作——V < Uon，一滴电流都过不去（1.5V 电池推不动蓝光 LED，蓝光 Uon≈3V）。

### 直流叠加与工作点——两套坐标系，两种"移动"

"直流和交流能不能在同一个电路里"——能。任何一点的电压 = 直流分量 + 交流分量 = 平均值 + 波动。但**叠加的"移动方向"取决于你在哪张图里看**：

```
时域波形 v(t)-t       直流叠加 → 波形整体上下平移（横轴=时间，加的是纵轴）
伏安特性 I-V          直流偏置 → 工作点在横轴上"左右"选位置（横轴=电压）
```

**时域图里**：v(t) = Vdc + Vac·sin(ωt)——正半周加、负半周减，每时每刻在算账——但结果写在纵坐标上，所以曲线整体上下移动。铁证：Vdc=5V、Vac=±3V，波形在 2V~8V 之间，永远碰不到 0V 以下——如果是左右（相位）移动，波形应该还在原来的电压范围里。**判据一句话：看波形和 0V 线的距离变了没——变了=上下（叠加），没变=左右（相位/延迟）。**

**伏安特性图里**：横轴是电压、纵轴是电流，二极管的曲线在 Uon 处向右上拐（指数上升段）。直流偏置 = 在横轴上左右移动工作点 Q；交流 = 工作点沿曲线来回滑动——输入电压左右摆，输出电流上下跳。**曲线越陡，同样一点电压摆动产出的电流波动越大——陡峭度就是增益。** 这就是"工作点"思想：Q 点放在拐弯处→通断切换（整流、削波）；放在陡峭直线段→线性放大（晶体管）。

**微变等效的本质 = 在 Q 点附近把曲线近似成切线**——交流小信号当它沿切线走，切线斜率就是那个"曲线有多陡"的系数（跨导）。**先定 Q 点（直流），再算切线（微变），然后交流沿切线走（动态分析）——"先静态后动态"的全部秘密。** 这也是模电课程第 05 讲（微变等效）和第 14-16 讲（Q 点稳定、共射/共集/共基分析）在算的事。

### 二极管的三大波形手术——整流、削波、钳位

二极管是"非线性的门"——单向导通 + 恒定压降——这两个性质让它能做三件事：整流、削波、钳位。串联和并联分工不同：**串联二极管管"电流能不能过"（阀门），并联二极管管"电压不能超多少"（泄压）。**

```
① 整流    串联单向阀门——正半周放行，负半周截断
           〜〜〜〜   →   ⌒⌒⌒⌒（半波）——损耗账见下一节

② 削波    并联二极管+偏置电压——电压上限——
           超过 V+0.7 的部分被泄掉，波形顶部削平（限幅）

③ 钳位    二极管+电容——直流电平移位——
           波形整体抬高/压低，形状不变（0~5V → 5~10V）
```

**稳压管 = 反向钳位**——反向击穿时把电压死死钳在击穿电压上（5.1V 稳压管 = 把电压钳在 5.1V 的专用钳位器）。整流→钳位→稳压是同一把刀的三次用法。对 Feelings：AFE 入口的 ESD 保护二极管就是并联泄压的工程形态——把静电瞬间钳在安全轨上。

### 二极管整流——把交流变直流的损耗账

二极管整流有损耗，而且严重程度看工作电压——越低越痛。损耗来源主要是正向压降：二极管导通要吃掉 0.6-0.7V（硅管）。整流桥 4 个管，导通路径上有 2 个——一次性吃掉 1.2-1.4V。

```
输出电压 = 输入峰值 - 导通路径上的二极管压降

5V 电源用桥式整流（2×0.7V=1.4V 损耗）→ 效率只剩 ~70%
230V 市电整流（1.4V vs 230V）       → 损耗 0.6%——可以忽略
3.3V 可穿戴（1.4V vs 3.3V）         → 烧掉四成——痛
```

损耗功率 = V_f × I——变成热。电流越大热越多，所以大功率整流要加散热片。

**降低损耗的三条路：**

1. **肖特基二极管**——压降 0.2-0.3V，替代硅管的 0.7V，但耐压低、反向漏电大。
2. **同步整流**——用 MOSFET 代替二极管，导通电阻毫欧级，损耗接近零——开关电源的标配。
3. **避开整流**——低压电路直接电池+LDO/DC-DC，根本不让交流进来。

对 Feelings 特别相关：3.7V 锂电池 → 3.3V 轨道，中间绝对不能串二极管（0.7V 一扣只剩 3.0V 还要 LDO 再吃一点）——必须用低压差 LDO 或 DC-DC。这就是模电课程第 48-50 讲（直流电源组成、桥式整流、稳压）要解决的核心问题。

另外注意一个概念陷阱：二极管整流不是"转换"交流成平滑直流——它只是把负半周砍掉或翻上来，输出是**脉动的直流**，后面必须跟滤波电容才变平。损耗在这里还有一笔：滤波电容充电瞬间的冲击电流。

### 555 振荡器——锁相环工程师顺手造的可调频率器件

同时期，其他厂家在技术方面也是百花齐放。就职于 Signetics 的 **Hans Camenzind** 是专门做锁相环（PLL）的，特别希望得到一种可控频率的器件。不为别的——就是为了自己用着方便。于是他做出了一种可调频率器件，命名为 **555 振荡器。** 这就是教材里 555 定时器那一章的由来——不是一个商业计划——是一个工程师为了解决自己的日常调试需求而顺手搭的电路。

### 555——35 年全球最畅销的 IC

任何一个电学专业的学生都听过用过 555。**35 年来全球最畅销的 IC，每年销售 10 亿只。** 不是为了某个大客户定制的——是一个 PLL 工程师为了自己用着方便顺手搭的——然后全世界都不愿意放手。

### 振荡器的诞生——接错线凑出来的 HP

Bill Hewlett 和 Dave Packard——别人用运放是为了防止振荡，他们一开始也是。结果接线接错了，做成了正反馈，电路振个不停。两人一合计——算了，咱们就专门做振荡器吧。于是开了公司，公司名就用两人名字缩写——**Hewlett-Packard。** 这就是教材上"信号转换和发生电路"那一章的由来——不是理论推导——是两个工程师接错线之后凑出来的。

### 振荡器的本质与用途

振荡器——不需要外部信号输入，自己产生周期性波形。正弦波、方波、三角波——自己转自己。

对 Feelings 项目的关键应用：

```
FPGA 板载晶振        → 24MHz 精密振荡器 → iCE40 和 GW1N 的心跳
AD5933 内部振荡器    → 产生扫频正弦波 → 敲门的手
DC-DC 开关电源       → 振荡器给 PWM 开关频率 → 几百 kHz-MHz → 电感储放能量
PWM 脉宽调制         → 振荡器三角波 + 比较器 → 输出占空比 → 控制压电强度
```

**负反馈接线反了 = 正反馈 = 振荡。** 别人在回避振荡——Hewlett 和 Packard 把接错的线当成了产品。

## JFET——两个 PN 结夹一条沟道的电压控制器件

### JFET 结构——两个背靠背的 PN 结

N 沟道 JFET：P 型栅极（上下两块，连在一起是 G）夹住 N 沟道——形成两个背靠背的 PN 结（栅-沟道结）。栅源之间加反偏（Ugs<0）——耗尽层向沟道内扩展——沟道变窄。

反偏不消耗栅流——输入阻抗极高——**电压控制器件**：手在栅上，Ugs 就是那只手。

### 沟道宽细的分工——Ugs 定整体，VDS 定分布

```
Ugs（栅源电压）  定整体——栅越负，耗尽层整体越厚，整条沟道一起变窄——
                 Ugs = 0 时最宽（对应饱和漏极电流 Idss）
VDS（漏源电压）  定分布——D 端更窄、S 端更宽——沿沟道的锥形分布——
                 改变不了平均宽度，只改变不均匀程度
```

机制链：D-S 加电压后，电位沿沟道从 S 到 D 逐渐升高（电流在沟道电阻上产生压降，D 端电位最高）——栅极是同一块金属（同一电位）——所以栅-沟道结的反偏电压 = 栅电位 - 沟道电位，沿沟道变化：S 端反偏小（抵消/减弱），D 端反偏大（增强）。

```
反偏电压越大 → 耗尽层越厚 → 沟道越窄
D 端反偏最大 → 耗尽层最厚 → 沟道最窄
```

注意措辞：不是"自由电子多的地方窄"——是"自由电子被耗尽得多的地方窄"。耗尽层就是自由电子被清空的空间——反偏把 N 侧电子赶走，赶走的地方变成空间电荷区不再导电。D-S 势场不是直接推 PN 结，是先改沟道电位，电位差再改 PN 结偏置——一根沟道上同时存在从弱反偏到强反偏的连续分布。

### 预夹断与饱和——缝隙越长，电流越稳

VDS 增大到一定程度，D 端耗尽层在沟道中间会合——**预夹断**。之后 VDS 继续增大，夹断区（缝隙）从 D 端向 S 端延伸——增大的电压全部落在缝隙上（耗尽区高阻、吃掉压降）——**导电沟道两端被固定在夹断临界电压**——电流稳住。

```
Ugs 更负 → 夹断更早发生（VDS,sat 更小）→ 同样的 VDS 下缝隙更长
缝隙不零流：耗尽区没有自由载流子，但电子被电场扫过——
           缝隙是高阻通道，不是断路——电流连续性
```

### 输出特性——一个 Ugs 一条完整曲线

```
可变电阻区    从原点出发按固定斜率爬——斜率 = 1/Ron（由 Ugs 定）
预夹断点      在固定电压拐弯——VDS,sat = VGS - Vp0（由 Ugs 定）
饱和区        水平延伸——Id ≈ 恒流值（由 Ugs 唯一决定）
```

"电阻"模型只在可变电阻区成立（VDS 小、缝隙未形成，沟道是纯电阻）；进入饱和区后换成"恒流源 + 缝隙"模型（电压全给缝隙，电流被 Ugs 钉死）。修正：缝隙延伸时剩余导电沟道变短——Id 会随 VDS 略微上升（沟道长度调制——输出电阻有限，不是理想恒流源）——以后看放大电路输出电阻时见到这条尾巴。

**Ugs 是唯一的主变量，VDS 只是跑龙套的**——可变电阻区它定电阻，饱和区它定电流，预夹断点它定拐弯位置——这就是"电压控制器件"的全部含义。

### Feelings 关联——高输入阻抗前端

JFET 的核心资产是输入阻抗极高（反偏栅不消耗栅流）+ 低噪声——这是生物电采集前端的标准输入级：电极和皮肤之间的接触阻抗高、信号源极弱（微伏-毫伏级）——前端必须高输入阻抗才能"不加载信号源"（采样电路分流小，信号不被吃掉）。Feelings 的 EMG/EEG 采集前端，JFET 输入级是教科书级的搭配：高阻采样 + 低噪声放大。
