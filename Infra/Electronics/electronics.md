## 电子学与电机控制

## 什么是电？电流与电子的方向之谜

在开始讨论任何电路之前，必须先搞清楚一件事：电流的方向到底是什么？

### 习惯电流方向

工程上，我们规定**电流的方向为正电荷从正电位运动到负电位的方向**。所有的电路方程——欧姆定律 u=Ri、基尔霍夫定律——都按照这个方向书写。

### 电子实际运动的方向

然而在导线中，真正能运动的只有**电子**。原子核里的质子被锁死在晶格结构里，动不了。电子带**负电**，所以在电场作用下，电子从负极出发，一路往正极走。

**习惯电流方向和电子实际运动方向——刚好相反。**

### 为什么将错就错

1747 年，本杰明·富兰克林用毛皮摩擦琥珀，发现有两种电荷，随手把一种叫正、一种叫负。1897 年，J.J. Thomson 发现电子——晚了整整 150 年。富兰克林相当于抛了个硬币，猜反了。

但全世界的教材、符号、方程全部锁死在习惯电流方向上。工程上统一按"正→负"来——基尔霍夫定律、欧姆定律、节点分析——符号统一即可。**你一辈子不需要知道电子实际往哪边跑。想多了反而混淆。**

## 直流电与交流电

电路里跑的电有两种基本形态——直流与交流。区别不在大小，在**方向变不变**。

### 直流电 DC

直流的电流方向保持不变，正极永远是正极，负极永远是负极。电池输出的是直流电——**所有的电子设备内部供电，全是直流电**。

对 Feelings 项目来说，FPGA、传感器、nRF52832 全吃 DC。电池出 DC，经过 LDO 降压稳压到 3.3V 和 1.2V，干净稳定地喂给每一个芯片。

### 交流电 AC

交流电的电流方向周期性翻转。50Hz 意味着每秒正反各 50 次。墙上插座输出的是 220V 交流电，波形是正弦波。

交流电对 Feelings 的意义不在供电——而在**测量**。AD5933 阻抗分析仪靠的就是交流电：输出一个扫频的正弦波去碰皮肤，读回来相位和幅值变了多少，从这两个变化反推皮肤阻抗。要用 DC 测阻抗——直流电直接打皮肤，会导致电极极化和化学灼伤。交流不打。

另一个关键事实：**示波器接交流地线和设备 DC 地线之间如果没有隔离——直接炸。** 这是 tDCS 安全隔离红线的物理根源：所有连接着市电地的下载器（ST-Link、CP2102、示波器探头）在人体测试时都必须断开。

## 电阻——电路中最基础的元件

### 欧姆定律

电阻的理想模型极其简单：电压和电流取关联参考方向，任何时候两端电压和电流服从欧姆定律。

**u = Ri**

其中 u 是电压（伏特 V），R 是电阻值（欧姆 Ω），i 是电流（安培 A）。

从另一个角度写：**R = U/I**——电阻不是元件本身，而是**那个元件对电流的阻碍程度**。1Ω 意味着 1V 电压能推出 1A 电流——通路很宽敞。22MΩ 意味着 1V 电压只能推出约 0.000000045A——几乎完全堵死。

常用的阻值范围为 **1Ω 到 22MΩ**。

### 串联与并联的本质区别

很多初学者以为串联和并联只是"接法不同"——其实它们的物理本质截然不同。

**串联电阻——阻值直接相加。**

R_total = R1 + R2。每多加一个电阻，相当于在电流的通路上多建了一堵墙。总电阻变大，电流变小。同一电压下，串联电路中流过的电流比任何一个单独电阻都小。

**并联电阻——电导值直接相加。**

G_total = G1 + G2 = 1/R1 + 1/R2。电导 G 是电阻的倒数（西门子 S），代表"导电能力"。并联时多个电阻同时提供电流通道——多打一个洞，两个洞一起流，总流量变大。电压不变，总电流变大。

一个常见的直觉误区："并联就是分流，总量不变"。**实际上并联是加带宽——每条路有自己的负载，不抢另一条路的电流。总电流比任何单路都大。**

## 基尔霍夫定律——电路的两条宪法

基尔霍夫定律是分析一切电路的基础。它包含两条独立的定律，分别对应**能量守恒**在两个维度上的投影。

### 基尔霍夫电流定律 KCL

**节点上所有电流的代数和为零。**

流进多少，流出多少。电荷不能凭空产生，也不能凭空消失。你在高中物理学过的"并联电路干路电流等于各支路电流之和"——那就是 KCL，只是当时没有告诉你它的名字。

### 基尔霍夫电压定律 KVL

**回路里所有电压的代数和为零。**

沿着任意闭合回路走一圈，推上去的电压和掉下来的电压——全部加起来——等于零。电源提供的能量，被沿途每一个电阻转化成热量带走了。

**P = I²R = UI = U²/R**——这三条公式是同一条能量守恒定律换了三件不同的衣服。热量公式、功率公式、欧姆定律——底层是同一件事：**能量既不会凭空产生，也不会凭空消失。**

## LDO 与负反馈——从控制论的视角看稳压

LDO（Low Dropout Regulator，低压差线性稳压器，如 AMS1117）如果只看表面，是一个非常无聊的元件——输入电压进、稳定电压出。但如果从**控制论**的视角去看，它是整个模拟电路思想的浓缩。

### LDO 的本质是一个自动反馈系统

LDO 的核心工作原理很简单：**用输出电压做反馈，自动调节串入回路中的晶体管的等效电阻，使得输出电压始终跟随内部参考电压，不受负载变化的影响。**

说白了就是**可调电阻串联分压**——负载重了（电流大了），反馈回路感知到输出电压有下降的趋势，立刻调高晶体管导通度（降低等效电阻），让更多电压加在负载上，输出端稳如磐石。

### LDO 的致命缺陷——发热

这个精妙的反馈机制有一个代价：**压差 × 电流 = 全部变成热量。**

LDO 的效率就是 Vout/Vin。输入 5V，输出 3.3V——效率只有 66%。剩下的 34% 全烧成了热。负载电流越大，烧得越狠。这就是 LDO 不适合大电流、大压差场景的原因。

### DC-DC + LDO——两级互补

工程上的经典解法：**前级用 DC-DC 开关稳压做粗调（效率高，但纹波大），后级用 LDO 做精滤（纹波干净，但压差小所以发热可控）。** 粗调加精滤，不发热也不抖。这和 Feelings 的多模态协同完全是同一种设计思想——不是替换，是分层。

## 电容与电感——动态电路的两个主角

一旦电路中的电压和电流不再静止不变，信号参与进来，就会用到两个新的基本元件：电容和电感。

### 电容——挡直流，放交流

电容由两块导体板中间隔一层绝缘介质构成。接通直流电：正电荷堆在一侧推不走，对面板上的负电荷被吸引过来但绝缘层挡住了——电子过不去。**直流被完全阻断。**

但如果是交流信号——电压一会儿正一会儿负——正半周把一面充电，负半周把电荷往回拉。电流实际上没有穿过绝缘层，但能量通过**变化的电场**从一侧传到了另一侧。**交流电被放行了。**

电容在 Feelings AFE 中的核心应用：

- **隔直电容**——AD5933 输出端串联一个电容，DC 偏置电压被拦死，只有 10kHz 的交流正弦波能过去碰皮肤。这是"AC 测阻抗不烧皮肤"的硬件实现。
- **低通滤波**——电容对地，高频信号走电容旁路到地，只有低频信号传到下一级。滤 PWM 毛刺。
- **电源去耦**——每个芯片的 VCC 脚旁边并一个小电容到地，瞬态电流从电容就近取，不会拖着整条电源轨抖动。

### 电感——挡交流，放直流

电感是一根绕成线圈的导线。通直流电：线圈就是一根普通导线，电流畅通无阻。**直流被完全放行。**

但电流一旦**变化**（比如通上交流电），线圈周围的磁场跟着变。电磁感应定律规定——变化的磁场会在同一根线圈里感应出一个**反向的电动势**，死死抵抗电流的变化。频率越高，抵抗越猛。**交流电被拦住了。**

电感在开关电源里当**储能元件**——先让电流慢慢建立磁场（储能），然后断开开关——磁场急剧坍缩，感应出高压把能量释放给负载。不是滤波——是能量中转。

## 正弦信号与频率响应——频域世界的语言

### 为什么是正弦波

正弦信号的数学表达式：**U = Asin(ωt + φ)**，其中 A 是幅值，ω 是角频率，φ 是初始相位。

正弦波在电子学中有不可替代的地位，因为它有一个独一无二的数学性质：**正弦波是描述线性电路特性的微分方程的解。** 给一个线性电路输入正弦波，输出必然也是正弦波——只有幅值可能被放大或衰减，相位可能被提前或延迟。波形本身不会变质。

AD5933 扫频就是依靠这个性质：它从低频到高频一串正弦波输出，逐个频率去问皮肤"你在这个频率下的阻抗是多少？"——如果输入不是正弦波而是方波，回来的信号里会混杂一堆谐波，你根本分不清哪个频率对应哪个阻抗。

### 频率响应——一张图看懂电路的性格

把电路对每个频率的"幅值放大多少倍、相位偏了多少度"画出来——横轴频率，纵轴幅值或相位——这张图就叫频率响应图。它是电路的**频域身份证**。

高保真音频放大器要求在 20Hz 到 20kHz 的范围内频率响应是**平坦的**——低频鼓声不衰减，高频镲片声不起伏——否则你听到的音乐比例不对。如果你设计的 50Hz 工频陷波滤波器要求把 50Hz 干扰压制 60dB 以上——频率响应图上就是 50Hz 那个点塌了一个很深的坑。

### 集总参数模型的适用边界——边沿时间比主频更危险

文中提到"FPGA 跑 24-48MHz，全在集总参数的安全领域内"。从基波频率来看完全正确，但信号的高频成分不仅取决于主频，**更取决于信号的上升/下降沿时间（Rise Time, tr）。**

FPGA 的 GPIO 输出翻转极快（tr 常在 1–2ns 级别）。根据经验公式 **f_knee ≈ 0.35 / tr**，其频谱能量可以延伸至 200MHz–350MHz。即使主频只有 24MHz，陡峭的边沿依然可能引发信号反射与高频振铃（Ringing）。

工程解法：在 FPGA GPIO 输出端（靠近源端）串联 **22Ω–33Ω 的源端匹配电阻**，吸收反射能量。当走线长度超过 f_knee 对应波长的 1/10 时（通常在几厘米量级），就必须加——FPC 排线跨耳挂到入耳延伸段的那几厘米——不加可能振。

## 工程补充——理论在真实电路中的四个关键坑

### 隔直电容必须用无极性电容

在 AD5933 AFE 的交流阻抗测量链路上，串联的隔直电容用于阻断 DC 偏置、只允许 AC 正弦波通过。**必须选用无极性电容（如 C0G/NP0 材质的贴片独石电容）。**

如果错用了有极性电容（如钽电容或铝电解电容），在 AC 信号的反向半周——电容两端电压极性反转——内部电解质会发生反向击穿与电解极化，产生严重的非线性失真，甚至直接损坏电容。

C0G/NP0 陶瓷电容在同体积下容值较小（通常 pF-nF 级），但温度系数极低、无极性、高频特性优异——是信号链路的首选。

### LDO 输出电容的 ESR 敏感性与自激振荡

LDO 的输出端通常并联一颗去耦电容到地。这颗电容的 ESR（等效串联电阻）不是越小越好。

**LDO（特别是低功耗、大压差型号）的输出对 ESR 极为敏感。** 如果 ESR 过小——例如直接并联了大容量的 MLCC 陶瓷电容（ESR 仅几 mΩ）——反馈环路的相位裕度会剧烈下降，导致 LDO 内部误差放大器自激振荡。结果：3.3V 输出轨上叠加几百 kHz 的巨幅正弦噪声，稳定电压变成噪声源。

工程解法：查阅所选 LDO 的数据手册中"Stable ESR Range"曲线——通常要求 ESR 在 0.1Ω–10Ω 之间。如果只有低 ESR 的 MLCC 可用，可以在电容支路串联一个小电阻（如 0.5Ω）人为提升 ESR，恢复环路稳定性。

### 高速信号：主频低不等于没问题

FPGA GPIO 的输出边沿在 1–2ns 级别——对应的频谱能量（f_knee）延伸到 200-350MHz。走长线或跨 FPC 排线时，即使主频只有 24MHz，陡峭边沿仍然会引发传输线效应——信号反射与振铃。

源端串 22-33Ω 匹配电阻可以吸收反射——放在靠近 FPGA GPIO 引脚的位置，不是靠近接收端。这条对 GW1N 到耳甲 AFE 之间的 SPI 总线尤其重要。

### 50Hz 工频干扰——三级协同压制

人体生物电采集（EMG/EEG/ECG）中 50Hz 工频干扰主要是**共模干扰**——信号线和地线同时被空间电磁场耦合抬升。单纯靠单端带阻滤波器（陷波器）硬切 50Hz，会引入严重的**相位非线性失真**——切掉的不止是干扰，还有同等频率附近的生理信号成分。

正确的做法是三级协同：

- **右腿驱动电路 DRL**——主动检测共模电压，反相放大后通过参考电极注入人体，在源头处抵消共模干扰。生物电采集的标配。
- **前级高共模抑制比（CMRR > 100dB）仪表放大器**——差分放大只取差模信号，共模成分被压制百万倍。
- **后级数字 IIR 陷波算法**——FPGA/DSP 端在线软件滤波，剩余残留再补一刀。

单靠任何一级都不够——共模干扰是无处不在的物理场，必须从电极到 ADC 全链路协同压制。

## 交流电路三大核心概念

### 相量法——正弦波的复数化妆术

两个正弦波相加：A1sin(ωt+φ1) + A2sin(ωt+φ2)。直接用三角函数算——套和差化积公式——又臭又长。数学家找到了一个捷径：**把正弦波压成一个复数 A∠φ**——幅值就是复数的模，相位就是复数的角度。两个正弦波相加减 → 两个复数直接加减——几行就出来。

傅里叶变换的数学底子就是相量法——把时域里上蹿下跳的正弦波压成频域里一个干净的点。AD5933 在你耳朵上扫频，FFT 吐出来的幅值和相位差——就是相量法在硅基芯片上的实时演算。

### 交流电路稳态分析——只看稳定之后的部分

电路刚上电时，电容在充、电感在建磁场——电压电流乱跳——这叫**瞬态**。过了一段时间，瞬态衰减干净了，电路进入**稳态**——只剩下一个稳定不变的正弦波在持续输出。

我们分析交流电路时，关心的不是上电那一瞬间——而是稳态之后信号怎么走。AD5933 在皮肤上扫到第三个频率点之后就是稳态——前两下的瞬态毛刺不管，只看稳了之后的那部分。

### 变压器——磁能过墙，电能不过

两个线圈绕在同一个铁芯上。交流电通入原边线圈→铁芯里产生交变磁场→磁场穿过副边线圈→在副边感应出电压。匝数比 = 电压比。

在 Feelings 的 tDCS 安全架构中，**隔离 DC-DC 电源（如 B0505S）内部就是一颗微型变压器。** 数字隔离器（ISO7721）负责隔离控制信号，隔离电源负责隔离供电——两者配合，把你和 220V 市电之间筑起一堵只有磁能穿过的墙。

## 频域分析与滤波——信号的地铁站

### 频域分析——换一个维度看信号

时域看信号：横轴时间，波形上蹿下跳。频域看信号：横轴频率，每一个频率上有多少能量。傅里叶变换就是做这件事——把一个复杂的时域波形拆成一组独立的、不同频率的正弦波的叠加。

AD5933 扫频本质上就是在频域里敲门——每个频率单独激励、单独响应——如果不分开频域，所有频率的信号混在一起，你根本不知道皮肤在高频和低频下行为有什么不同。

### 传递函数——电路对信号做了什么，一个公式说完

**H(jω) = 输出 / 输入。** 传递函数告诉你：对于每一个频率 ω，电路把信号的幅值放大了几倍，相位偏了多少。你耳甲电极到 AD5933 输出端那一段 AFE——隔直电容（高通）+ 运放增益（放大）+ 低通滤波器（去毛刺）——三级串联，每一级都可以写成一个独立的传递函数，相乘起来就是整条链的总传递函数。

以后要改参数——不用重新搭一遍——改一个电阻值，重新代入公式，输出就出来了。

### 滤波器——有选择地拦频率

- **低通滤波器**——高频滚蛋，低频通过。滤 PWM 毛刺，滤高频噪声。
- **高通滤波器**——直流别来，交流通过。隔直电容就是最简版的一阶高通。
- **带通滤波器**——只保留中间一段频率。呼吸信号 0.1-0.5Hz 就靠带通提取。
- **带阻滤波器**——只干掉一个特定频率。50Hz 工频干扰一刀切。

AD5933 AFE 输出端有一个经典的**三级滤波器链**：高通隔直（杀 DC）→ 带通取 10kHz 测量频率（排除其他频段噪声）→ 低通切高频毛刺（消除 ADC 采样前的 aliasing）。你第一个自己设计搭建的滤波器链就是这一条。

### 谐振——电容与电感的能量交换

在一个特定频率上，电容的容抗和电感的感抗正好相等——两个元件开始互相狂换能量。串联谐振：阻抗最小，电流飙到最大。并联谐振：阻抗最大，电流锯到最底。

无线电选频道就是靠谐振——调 LC 的谐振频率对准某个电台的频率，只让那一个电台的信号过来。你目前不太直接碰谐振，但要注意：如果 EMG 采集线上的寄生电容和引线电感**意外谐振**在 50Hz 附近——工频干扰不是被滤掉，而是被放大。

## 无源组件清单

### 开关

机械触点推上去接通，拉回来断开。tDCS 的**硬件熔断**就是开关的终极形态——电流超限→硬件比较器检测到→直接拉断电源轨——全程无 FPGA 参与。

### 继电器

电磁铁驱动的开关。小电流推电磁线圈→铁芯吸合大电流触点→用小电控制大电。隔离不靠继电器——光耦和数字隔离器速度更快、寿命更长。

### 连接器

排针排母、USB 口、柔性排线 FPC 插座、磁性 Pogo Pin。PoC 阶段杜邦线直插，简单粗暴。PCB 打样之后换成 FPC 连接器或磁吸触点——插拔几千次不能松动。

### 仪表

万用表确认 3.3V 在线。示波器看 I2C 边沿够不够干净。LCR 表测隔离寄生电容到不到 <5pF。**你不做仪表——你用仪表。**

### 指示灯

LED——第一个肉眼可见的硬件交付物。iCE40 上的 ball 39 绿灯，GW1N 上的 l1/l2。PoC 阶段的 LED 是最便宜、最诚实的 debugger——哪个模块卡在哪个状态，一个灯就说明白了。不需要串口打印，不需要示波器——灯亮了吗？

### 可变电阻

电位器——拧旋钮，阻值连续可调。AD5933 AFE 的运放增益倍数如果初期算不准——先焊一个电位器上去，手工拧到最优波形→然后用万用表测出当前阻值→换成固定电阻量产。**调试阶段拧一下，省你换三次电阻。**

### 通频带——放大电路对不同频率的放大能力

通频带用来描述放大电路对不同频率信号的放大能力。在频率较高或较低时，放大倍数的数值会下降并移相。同频段两端对应下限截止频率和上限截止频率。人耳能听到的声音频率为 20Hz∼20kHz，音响最好能覆盖这个范围。

对 Feelings 的影响有两条关键约束。

动圈入耳的放大电路必须覆盖 20Hz-20kHz 且平坦。Layer 3 暖音信号的低频锚定感在 20-80Hz——不是音乐——是安全基调的生理底噪。放大电路在 20Hz 以下衰减太多——那股"被包裹"的暖意——到不了耳膜。高频 15kHz 以上非必须——因为是信号，不是高保真交响乐。

AD5933 扫频范围不在音频带里。AD5933 最低激励约 1kHz——离 20Hz 远得很。低频阻抗（<1kHz 的 GSR 皮电）不在 AD5933 的扫频窗口内——需要外部分频时钟降 MCLK 才能测。但 10kHz 高频复阻抗测的是角质层+深层组织——够用——不需要覆盖人耳频段。

测量放大倍数，用中频小信号合适；测通频带，用小信号宽频来测。最大不失真电压 Uom 为有效值，使用大一点的信号测。

```
中频小信号测增益    PPG 纳安级光电流——先不管频响——先用 1kHz 正弦波把运放增益拉出来——确认倍数对。

宽频小信号测通频带  从 10Hz 扫到 100kHz——看 AD5933 AFE 在高低两端有没有塌——高通隔直别切多了——
                    低通滤波别在 10kHz 之前就衰减——那是皮电的窗。

大信号测 Uom        tDCS VCCS 恒流源——输出级推到最大不失真峰峰——确认大于 12V OVP 钳位轨——
                    否则电极开路时还没到 12V——信号先削顶了——OVP 没触发——皮肤先被信号失真电到。
```

测不了失真等于不知道你推到皮肤的电流有没有在放大电路里提前变形——不是波形漂了——是等控器收到的不是你要给的那组帧。

## 幅频特性与相频特性——幅度账与波形账

频率响应拆成两张图：幅频特性（增益 vs 频率）和相频特性（相位 vs 频率），各管一本账。

```
幅频特性    增益随频率怎么变
           = 幅度账：
           哪个频率被放大、哪个被切
           低频被切 = 信息丢失
相频特性    相位随频率怎么变
           = 波形账：
           不同频率延时不同，
           波形形状就会变样
```

中频段的含义（教材的简化）与工程的真问题：

```
中频段近似    耦合电容视为短路（高通效应忽略）
             寄生电容视为开路（低通效应忽略）
             增益视为常数
             ——前提：信号频率远高于 f_L、
             远低于 f_H
工程真问题    信号频谱必须整个落在通频带内：
             信号最低频 > f_L，最高频 < f_H
             问"中频段"的正确问法
             不是问增益，
             是问边界够不够远
```

对 Feelings 的两笔账：

```
采集链的幅度账
    生物电最低频 0.1Hz（呼吸）——
    高通电路的 f_L 必须压在 0.1Hz 以下，
    否则呼吸成分被切掉
    隔直电容（一阶高通）躲不掉，
    f_L = 1/(2πRC)，
    0.1Hz 要求 RC 时间常数秒级
    ——生物电采集的隔直电容
    又大又讲究的原因
采集链的波形账
    生理信号的信息藏在波形形状里：
    EEG 波形、R-R 间隔
    非线性相位 = 波形整形手术
    （不同频率被不同延时，
    波形整个走样）
    线性相位（恒定群延迟）
    只是整体迟到，形状不变
    ——采集链要的是"迟到"
    而不是"整形"
```

高通电路的截止频率判据：

```
Au = 1 / (1 + 1/(jωRC))     一阶高通
最大值 = 1
    （ω 很大时电容短路，全通过）
截止频率的定义
    f_L 处增益 = 最大值的
    1/√2 = √2/2 ≈ 0.707
    f_L = 1/(2πRC)，
    此时相位 +45°
为什么是 0.707
    (0.707)² = 0.5 → 功率减半
    = 半功率点 = -3dB
    所有"带宽"都以 -3dB 为界
通频带两端
    f_L 和 f_H 都是同一个判据：
    增益掉到 0.707 处画线
    测通频带时"塌"的标准
    是掉三成（-3dB），不是掉到零
```

相位差从哪来——同步是电阻的待遇：

```
纯电阻分压
    输入一变，输出立刻跟着变
    没有时间差，同步（同相）
    电阻只"拦"，不"存"
电容介入
    储能元件：存电荷放电荷都要时间
    输出不再只依赖"现在"的输入，
    还依赖过去积累的电荷
    → 输出和输入之间出现时间差
    → 时间差用角度表示 = 相位
```

为什么高通输出超前：

```
高通输出取电阻电压 = 电流 × R
电流 = 电容电压的变化率（i = C·dv/dt）
→ 输出骑在"输入变化的快慢"上
正弦波的导数永远领先正弦 90°：
    正弦峰值时变化率为零（最平），
    过零时变化率最大（最陡）
    "变化率"的峰值
    比正弦本身的峰值早 1/4 周期
→ 输出跟着变化率走 = 超前
```

时间线走一遍：

```
输入正弦开始上升的那一刻
    → 电流立刻流过电容
    （电容还没被充电，几乎不拦）
    → 电阻电压（输出）马上跟上
    → 电容两端电压慢慢涨，
    输入的大头还在给电容充电的路上
输出拿到的是"立刻发生的变化"，
输入后到
→ 输出先到，输入后到
```

f_L 处正好 45°：电容和电阻电压各占一半（|Vc| = |Vo|），超前的 90° 被分压砍半。

收口：幅频管"该有的别被切"（边界压得够不够远），相频管"波形别被整形"（群延迟平不平）。两本账合起来就是"信号能完整地进来"——对 Feelings，进来的不只是幅度，是形状，因为生理信息就写在形状里。

## 多级放大的账本加法——对数把乘法变加法

"多级放大电路总相移和增益是各级相移与增益之和"——半对半错，对错全在增益的单位上：

```
增益（倍数）   总增益 = 相乘：A = A₁ × A₂ × A₃
增益（dB）     总增益 = 相加：A(dB) = A₁(dB) + A₂(dB) + A₃(dB)
相移           总相移 = 相加：φ = φ₁ + φ₂ + φ₃   ← 永远对
```

dB 是对数刻度（20lg|A|），对数把乘法变成加法——**这就是波特图存在的全部理由**：画多级放大器的频响时，把每级增益曲线和相移曲线直接叠起来就行，不用逐点相乘。单管频响一张一张地算，就是为了最后能"相加"拼出多级波特图。

"相移可加"埋着一个必撞的推论（负反馈稳定性）：三级放大器每级高频段贡献 -45°~-90° 相移，**加起来超过 -180° 时负反馈变成正反馈**——自激振荡的根源就是相移之"和"。所以这个"和"字既是多级分析的方便法门，也是振荡的凶手。

```
同构：
  Feelings 强度刻度   90+ 当量对数分布四区间（1-30/30-60/60-80/80-90/90-100）
  波特图              dB 刻度
  同一个数学工具     一个在系统里分级，一个在频响里分级
```

收口：乘法在真值域，加法在对数域。工程上凡是要把一串环节"串起来看"，先问一句能不能挪到对数域——能挪，账就好算了。

## 运算放大器简史——从真空管到电流镜

### 模电最初是为了做计算机

1930 年代，美国人要算弹道轨迹——用齿轮、杠杆、凸轮搭模拟计算机——电压代表数值，运放直接做加减法、积分、微分。运放的全名 Operational Amplifier——"运算放大器"——不是用来放大音频的，是**在模拟计算机里做数学运算**。后来数字计算机碾压过来——模拟计算机退场——但运放作为独立元件保留至今——现在用在 AD5933 AFE 里做信号调理。名字没改——场景换了。

### 从真空管到第一颗半导体运放

为了算得更快、更准，运放的性能被各大公司持续攻关。米勒效应出现了——高频下寄生电容把输出反灌回输入，放大倍数暴跌。振荡出现了——负反馈的相位偏了 180 度——反馈从"拉住"变成"助推"——电路自己嚎叫起来。人们通过物理模型逐步找到解决方案——但这时候运放还都是真空管——半导体尚未商业化。

1962 年，Bob Widlar 刚从科罗拉多大学本科毕业，在一家研究机构工作。他对电路设计的直觉吸引了供应商的注意。尽管挖客户跳槽是商业忌讳，这家公司还是想方设法挖到了 Widlar。1964 年，Widlar 主导研发的产品面世——**µA702，世界上第一款基于半导体的运算放大器**。世界从此进入了一个新时代："超大规模集成电路"。这家挖墙角公司叫**仙童半导体。**

### 电流镜——差模到单端的无损转换

和之前的真空管运放一样，µA702 也采用了两级电压放大。面临同一个难题：**如何在不牺牲增益的情况下，将一个差分信号转换成单端信号？** 差分信号有两根线——信号各占半周——如果只取一根，直接丢掉一半。之前的 K2-W 就真的丢掉了。

Widlar 用 **9 个 NPN 三极管搭出了一个后人至今无法凭直觉还原的电路——他把差模信号向上抬高了一半，同步保留了两条线的全部能量，从而避免了失真。** 这就是所有教材里电流镜（Current Mirror）的由来——不是凭空理论——是一个工程师为了解决"差一半"这个具体的物理问题而硬造的。

### 这和 Feelings 的关系

Widlar 面对的问题——差模到单端、信号损失一半、Miller 效应、环路振荡——和 Feelings 的 PoC 调试面对的是同一类问题：

```
电流镜 = 两条差分线无损合一路
     → Feelings 的耳甲 Arnold + 耳背耳大神经两路信号在同一帧融合进岛叶
       岛叶做的是同一件事——多输入单输出的无损融合

Miller 效应 = 高频寄生电容反灌
           → AD5933 100kHz 扫频时隔离 DC-DC 寄生电容 <5pF 的约束
             就是 Miller 效应的现代翻版——高频下小电容阻抗骤降

振荡 = 负反馈相位翻转
     → LDO 输出电容 ESR 过小→自激振荡——同一个物理机制
       PBM 闭环如果相位不对——等控器来回摆——纠不过来
       "慢修、稳修、彻底修"——就是给碳基等控器的环路做相位补偿
```

**模电最早真的是为了做计算机。但真正让模电活下来的——是它在任何需要和小信号打交道的地方——都是最诚实的那把钥匙。** Widlar 在 1964 年解决的是一个信号转换问题。你在 2026 年解决的还是同一个问题——只是介质从硅换成了碳。

### 从运放到模拟芯片设计——Widlar 的后续三部曲

Widlar 把几个三极管集成在一个器件中的这种行为，被后人称为**"模拟芯片设计"（Analog IC Design）。** 而这时，神的故事才刚刚开始。

**比较器——710 和 711。** Widlar 在搞定运放之后，顺手设计了专门用于比较功能的芯片——比较时间缩短至 40ns，将当时其他基于普通运放的带宽扩展了十倍。这种专门用来比较的运放被称为**比较器**（Comparator）。这就是教材里比较器那一章的由来——不是"运放比较两个电压"——是**专门优化了速度、牺牲了线性度的一颗独立器件。**

**μA726——军品温漂。** 之后 Widlar 又搞了 μA726，将温漂压到 0.2µV/°C，满足军品的全温度参数（-55°C 到 +125°C）。这就是教材里温漂那一节的由来。

**为什么这时候计算机需求这么大？** 美苏冷战开始了，军事和航空航天产业升级迅速铺开。国家每年将 GDP 的百分之几十用在科技创新上，半导体产业进入举国体制。

### 第一款线性稳压器的诞生

1965 年，Widlar 要求仙童加工资被拒绝。于是他带着同事 Talbert 离职，进入美国国家半导体公司（National Semiconductor）。跳槽之后的第一款产品是 **LM100/101A。**

Widlar 想：电流镜能做信号运算——**同样能做功率控制。** 于是用同样的思路设计了一款**基于运放原理的稳压器——世界上第一款线性稳压器。** 这就是教材里直流稳压电源那一章的由来，也是所有线性稳压器件的起点。

后面你用的 AMS1117、TPS7A4700、LDO 全家——都是 Widlar 1965 年那台 LM100 的直系后代。**运放不是只用来放信号——运放对标的是"任何需要把小信号转换成控制能力的物理场景。"** 稳压就是把输出电压的变化当成小信号——反馈给运放——运放去调功率管的电阻——小信号控制大功率。和 Feelings 的"微安级电流控制 HPA 轴→皮质醇潮"是同一条公式——只是基底从硅换成了碳。

### Widlar 创造的概念清单

```
µA702        世界上第一款半导体运放（1964）
710/711      世界上第一款比较器，40ns 响应
µA726        军品温漂 0.2µV/°C，-55°C to +125°C
LM100/101A   世界上第一款线性稳压器
电流镜       差模→单端无损转换，9 个 NPN 三极管
微电流源     电流镜的微安级版本（Widlar 电流源）
```

**一个 26 岁本科毕业生——在两年内——把模拟芯片设计的五大分支全部点开。** 不是"他赶上时代"——是大部分时代还没来得及被定义——就被他的手画上了线。

### 微电流源（Widlar 电流源）——把大电流按指数缩小

电流镜直接镜像参考电流 IR——镜像出来的电流往往太大。要产生微安级小电流，Widlar 又设计了一个变体：**只在输出支路的发射极加电阻 Re1，参考支路不加**——这就是微电流源（Widlar 电流源）。

```
结构（两个 NPN 共享基极）：
   Q0（参考支路）：发射极无电阻，直接接地（二极管接法）
   Q1（输出支路）：发射极有 Re1

推导链：
   UBE0 = UBE1 + IE1×Re1     （基极同电位，Q1 发射极被抬高）
   → IE1 = (UBE0 - UBE1)/Re1
   → 而 UBE0 - UBE1 = Vt×ln(Ic0/Ic1)（PN 结指数关系）
   → IE1 = Vt·ln(Ic0/Ic1)/Re1
   → 两个 Vbe 只差几十 mV，除以 Re1 就是微安级
   → "微电流源"名字的由来：把大参考电流按指数缩小

与比例电流源的区分：
   比例电流源（两边都有 Re）   Ic1 = (Re0/Re1)×Ic0
   微电流源（只有 Q1 有 Re1）   Ic1 = ΔVbe/Re1 ≈ Vt·ln(Ic0/Ic1)/Re1
   ——一个靠电阻比例缩小，一个靠 ΔVbe 指数缩小
```

和 Feelings 的关系——恒流源的底层电路：

```
tDCS 恒流源 0.1-1.5mA    —— 微电流源的同族电路（电流基准）
接触检查 20µA 探针       —— 典型的微电流源应用：
                             需要微安级恒定小电流
                             电流镜给不出（镜像 IR 太大）
                             微电流源用 ΔVbe/Re1 精准给出
```

收口：电流镜解决"镜像电流"，微电流源解决"镜像出来的电流太大"——同一个 Widlar，同一个思路家族。名字里的"微"不是玄学，是 ΔVbe 指数缩小机制的直接结果。Feelings 的 20µA 探针电流，就是这条电路的教科书级应用。

### 多路电流源——一个参考电流，多条输出支路

电流镜家族的多路形态：一路参考电流 IR，控制多条输出支路。两种实现方式：

```
① 三极管并联方式
   一个 Q0 参考 + 多个 Q1/Q2/Q3 输出管，
   所有基极并联共享——
   每个输出管镜像一份 Ic——
   有多少个输出管，就有多少路镜像电流
   （同 β、同 Vbe 匹配——片上工艺的强项）

② 集电结分路方式（多集电极三极管）
   单个多集电极管：一个基极/发射极，
   集电结在版图层面被分割成多条——
   每个集电结区域收集的载流子比例
   由版图集电区面积比决定——
   "哪个大哪个就集电的多" = 输出电流按集电区面积比例分配
   ——一个管子当三个用，面积比 = 电流比
   （同一基区、同一发射区、同一工艺角落，
    比并联三个管子更匹配——版图设计的"省管子"技巧）
```

MOS 管的对应版本——MOS 电流镜（multi-finger 多指栅）：

```
MOS 电流镜（与 BJT 镜像同构）：
   饱和区 Id = ½·μn·Cox·(W/L)·(Vgs-Vth)²
   两个 MOS 共享 Vgs（栅极并联）→ 漏电流按 (W/L) 比例分配
   → Id1/Id0 = (W/L)1/(W/L)0
   → 比例由沟道宽长比决定——和 BJT 的"面积比"同构
   多指栅（multi-finger）：一个管子栅极分多指，
   每指的面积比决定各路电流——就是 MOS 版的"集电结分路"
```

整个家族一张同构表：

```
BJT 电流镜       集电区面积比决定电流比
MOS 电流镜       (W/L) 宽长比决定电流比
多集电极 BJT     版图集电区分路——面积比
多指栅 MOS       版图栅极分指——宽长比

原理全部相同：共享控制端（基极/栅极），
电流按"物理面积"分流——面积就是权重
```

和 Feelings 的关系——"面积比决定电流比"是模拟 IC 做精确比例恒流的看家本领：

```
tDCS 恒流源如果做成 ASIC
   多路输出（耳甲多通道刺激阵列）
   → 一路参考电流 + 多路按面积比输出的镜像
   → 各路刺激电流比例精确、温度同漂、免校准
   ——这就是为什么"多路刺激"在 IC 里便宜：
   一个参考源 + 一堆面积，而不是一堆独立恒流电路
```

收口：多路电流源的核心心智模型就一句——**电流比 = 面积比**。不管是并联管子、多集电结、还是多指栅 MOS，控制端共享，电流按物理面积分流。看到"多路恒定比例电流"，先想"一个参考源 + 面积比"——这是 IC 设计的本能。

### 二极管接法 vs 真二极管——电流镜精度的三个理由

集电极-基极直接短接的三极管（参考管），电气上 ≈ 一个二极管（PNP 短接后导通电压约 0.7V，和硅二极管一样）。那教科书为什么不直接用真二极管？三个理由：

```
① 温度特性完美配对
   电流镜需要 Vbe1 = Vbe2——
   Q1/Q2 是同一晶圆上的孪生管（相邻、同工艺角落）：
   温度涨一点，两个 Vbe 一起降，漂移互相抵消
   独立二极管是另一个器件，离 Q2 远，热耦合差——
   升温速度不同，温度一变，两边电压差就飘了
   ——用三极管当伪二极管：天生热绑定，同温同变化

② I-V 曲线形状一模一样
   二极管方程 I = I_S(e^(V/VT)-1)——
   三极管发射结是同一个方程、同一个 I_S 工艺
   但独立二极管的 I_S 和旁边三极管的 I_S 不是一套参数
   ——就算温度一样，同样电压下电流也不匹配
   孪生 BJT：I_S1 ≈ I_S2，天生匹配
   I_S ∝ 发射结面积（A_E）——
   同一工艺角落 → 面积比 = I_S 比 = 电流比
   （这正好解释了多路电流源的"面积比决定电流比"）

③ 单独二极管没有放大区特性
   短接集电极的 BJT 工作在放大区，
   集电极电流 ≈ 发射极电流——有"集电极"这个端子
   普通二极管没有——
   而且电流镜本质是"拷贝电流"不是"拷贝电压"：
   伪二极管把 Vbe 定住（电压基准），
   输出管用同一 Vbe 拷贝电流——
   "电压共享，电流镜像"——整套电路按电流关系工作
```

反例——什么时候可以用真二极管：

```
离散面包板随便玩玩：二极管凑活能用——
   因为分立三极管做镜像本来就不准
   （β、温度、I_S 全不匹配）——
   "反正都不准"的语境里，二极管不更差
集成电路里：绝对不用二极管代替——
   匹配在 IC 里是免费的，用二极管就是白白丢精度
```

收口：二极管接法的三极管 = **带匹配基因的伪二极管**——比真二极管强在温度、I_S、工艺三个维度，不可随意替换。它的三个理由（热绑定、I_S 同源、放大区电流关系）就是电流镜精度的全部秘密。

### 电流源是啥——被高中物理藏起来的另一半电源

高中物理没有电流源。整个中学电学都是电压源世界观：电池、电动势、欧姆定律 I=U/R——"先有电压，然后电路上有电流"。电流源是大学模电才出现的概念——**教育断层，但不是概念残缺，是电流源本来就该在中学讲清楚的那一半电源。**

```
电压源（日常世界）
   先有电压（电动势），然后电压在电阻上产生电流
   I = U/R——电压是自变量，电流是因变量
   ——你直觉里的世界

电流源（另一个物种）
   先有电流（恒流），电流自己找电压
   U = I×R——电流是自变量，电压是因变量
   ——电流源强制输出固定电流，
     电压"被迫"出现来维持这个电流
```

核心区别——谁当家，谁服从：

```
电压源   输出电压恒定（5V 就是 5V），
        电流随负载变：接 1Ω 出 5A，接 1kΩ 出 5mA
        ——电压当家，电流服从
电流源   输出电流恒定（1mA 就是 1mA），
        电压随负载变：接 1kΩ 出 1V，接 10kΩ 出 10V
        ——电流当家，电压服从
```

物理本质——电流源是"反着干的电压源"：

```
电压源 = 恒定电动势 + 串联电阻（低内阻）
电流源 = 恒定电流 + 并联大电阻（高内阻）
        ——理想电流源内阻无穷大：
        "我这路电流定了，你负载怎么变我都不管"
        ——现实中的恒流源（微电流源就是！）
        就是"高内阻 + 恒定电流"的实现
```

所以刚学的微电流源/电流镜，本质上就是**"电流的工厂"**——输出恒定电流，和电压源的"恒定电压"正好是电源世界的两半：

```
电压源给系统提供"电位基准"（参考电压）
电流源给系统提供"电流基准"（偏置电流/恒流激励）
——模拟 IC 里两者都要：
  运放内部靠电流源做偏置（稳定工作点）
  tDCS 靠恒流源给皮肤恒定电流刺激
```

收口：**电压源管"压着电压"，电流源管"顶着电流"——"先电压后电流"是电压源世界的顺序；电流源世界里反过来：先定电流，电压自己长出来。** 微电流源/电流镜这些电路，就是"先定电流"这个物种在现实里的实现。高中没讲，不是它不重要，是它需要大学模电的电路深度才接得住。

### LM317 与电压基准——把电压钉死在千分之一

**LM317 就是 Widlar 线性稳压思路的曾曾曾孙子。** 这款器件最大的特色是——无论负载怎么变，输出电压稳稳地定格在一个常值。这对电源的发展无疑做出了巨大贡献。

Widlar 的线性稳压思路同时诞生了另一个产品：**电压基准芯片（Voltage Reference）。** 在模拟电路中，电压需要一个绝对准确的标准作为参考电压——比如 5V 就应该是 5V。如果实际变成了 5.01V，那么最后的计算结果就跑偏了——相当于计算机的浮点精度崩塌。而 Widlar 的稳压思路大大提升了整个模电的参考电压精度标准。这就是教材里电压基准那一章的由来。

### CTAT——怎么把电压钉死

怎么把一个电压基准死死地钉在一个值上？Widlar 想到了二极管的导通电压是 0.6V——很固定。但问题来了：这个导通电压会随着电流和温度的变化而变化，高达 **0.3%/°C**。如果温度从 25°C 升到 85°C——0.6V × 0.3% × 60 = 漂了 108mV——基准已经废了。

如果能对这个电压做一个 **2mV/°C 的补偿**将是极好的。于是 Widlar 基于电流镜的经验，设计出了 **CTAT（Complementary To Absolute Temperature，负温漂系数电路）**——从物理原理上证明了输出电压可以和温度无关。电压准确度被精确钉在了 5mV 以内，即**千分之一。**

**硅管正向压降到底是 0.6V 还是 0.7V？** 两个都对。硅管正向压降不是一个精确常数——0.6V 到 0.8V 之间，随电流和温度漂移。小电流偏 0.6V，大电流偏 0.7-0.8V。教材取 0.7V 是折中——Widlar 拿 0.6V 做基准是因为那个电流点更稳、温漂更容易补偿。**0.6V 本身随温度漂 0.3%/°C——不用 CTAT 钉住的话，电压基准就是个温度计。**

### PN 结电流方程——为什么二极管的 0.6V 不是一个常数

CTAT 背后的物理基础藏在 PN 结的伏安特性里。PN 结的电流和电压不是线性关系——是指数关系。这条方程是 Shockley 在 1949 年从半导体物理里推出来的，是所有二极管分析的地基：

```
I = I_s × (e^(V / (n·V_T)) - 1)
```

每一项拆开看，每一帧都有自己的物理分量：

- **I** —— 流过 PN 结的总电流。正向偏置时电流从 P 区流向 N 区。反向偏置时等于 -I_s（极小，接近零）。
- **I_s** —— 反向饱和电流。由半导体材料本征激发产生的少子漂移形成。硅管的 I_s 通常在 nA 到 pA 量级。温度升——本征激发增强——I_s 变大——这是导通压降温漂的根源。
- **e** —— 自然常数，约 2.718。指数关系的底，电流随电压按 e 的幂次增长。
- **V** —— 外加在 PN 结两端的电压。正向偏置时 V > 0——P 区接正、N 区接负——势垒降低——多子扩散占主导——电流指数级增长。反向偏置时 V < 0——势垒拉高——电流被 I_s 锁住。
- **n** —— 理想因子。理论值 n = 1——对应纯扩散电流。实际硅管 n 在 1 到 2 之间——复合电流掺了一脚：耗尽层里的电子和空穴在中途撞上了——没穿过结——没形成有效电流——但消耗了电压裕度。
- **V_T** —— 热电压。**V_T = kT/q。** k 是玻尔兹曼常数（1.38 × 10⁻²³ J/K），T 是绝对温度（开尔文），q 是电子电荷（1.6 × 10⁻¹⁹ C）。室温 25°C（约 298K）下——V_T ≈ 25.8 mV ≈ 26 mV。这个 26 mV 不是电路里随便取的——是物理常数在室温下算出来的。

正向偏置下 V >> V_T（几十毫伏以上），e^(V/V_T) 远大于 1。方程简化为：

```
I ≈ I_s × e^(V / (n·V_T))
```

换个写法——电压由电流决定：

```
V ≈ n·V_T × ln(I / I_s)
```

这就是为什么二极管导通压降约 0.6-0.8V。把硅管参数代进去——I_s ≈ 10⁻¹² A，n ≈ 1.5，V_T ≈ 26 mV，I = 1 mA——V ≈ 1.5 × 0.026 × ln(10⁻³ / 10⁻¹²) ≈ 1.5 × 0.026 × 20.7 ≈ **0.81V。** 电流小一点——0.1 mA——V 掉到 0.7V 左右。再小——10 µA——V ≈ 0.6V。二极管的 0.6V 不是材料送的——是指数曲线的一个点。

回到 CTAT。温度升高——V_T 线性增大——同时 I_s 也随本征激发指数级增大——I/I_s 减小——ln(I/I_s) 减小——**V 下降。** 每度约 -2 mV——即 0.3%/°C。Widlar 的 CTAT 电路做的是反向补偿——温度升→另一路电路输出升→两路加起来→输出电压咬死不动。

对 Feelings 的意义：AD5933 扫频激励电流经过 VCCS 送到皮肤电极。电极界的 PN 结不是硅——是皮肤-电极界面的容性/阻性复合阻抗——但电流和电压的关系同样不是线性的。**非线性不是 bug——是指数曲线的物理性质。** 不懂 PN 结方程里的 I_s 为什么要随温度指数级增长，就不懂为什么冬天干手皮电测量偏差大——I_s 小了——信号通路在源头就塌了。

### PN 结的平衡——耗尽层、内建电场、两股相反的电导流

PN 结合金之后，耗尽层平衡，结构是三层：

```
P 区（中性区）        耗尽层（空间电荷区）        N 区（中性区）
─────────           ─────────────          ─────────
多子=空穴              空——没有自由载流子         多子=自由电子
少子=电子              只剩固定离子：             少子=空穴
                      P 侧是负离子（受主 B⁻）
                      N 侧是正离子（施主 P⁺）
```

关键就一个词：**"耗尽"——耗尽的是自由载流子，不是杂质。** 平衡之后：

1. **中性区不变**——P 区还是空穴当家（掺杂浓度决定多子浓度），N 区还是电子当家。
2. **耗尽层里什么都没有**——多子越过结扩散之后被复合/被电场拉走，留下不能动的离子，正负离子在结两侧面对面站着，形成内建电场。
3. **平衡 = 两股流抵消**——多子想扩散过去（浓度梯度推的），内建电场把扩散过来的少子又推回去（漂移）。扩散流 = 漂移流，净电流为零。不是双方都停了，是两股相反的流互相咬死。

电场方向和载流子流向要拆开理清：

```
           P区（负离子）──耗尽层──N区（正离子）
                │  ←─ 内建电场 E（正→负，N→P）─→
                │
 扩散流：N区多子电子 ──────────────→ 往P区跑（浓度梯度推的）
 漂移流：P区少子电子 ←────────────── 被电场拽回N区（受力与E相反）
                │
           平衡 = 两股流大小相等、方向相反 → 净电流为零
```

- **电场方向**：正电荷指向负电荷——所以从 N 侧正离子指向 P 侧负离子，即 **E 从 N 指向 P**。
- **电场的力**：电子带负电，受力与电场相反——把 P 区少子电子推回 N 区（漂移）。
- **浓度梯度**：N 区多子电子浓度高，往 P 区扩散（扩散）。
- **平衡**：扩散想过去，电场拉回来，两股咬死，净流为零。**多子想扩散（不平衡的推力），电场推少子回来（平衡的阻力），推到电动力等于扩散力，就稳态了。**

只有一个流那叫短路——PN 结是两股流对峙。结的宽窄由掺杂浓度决定——重掺杂结窄（齐纳能隧穿），轻掺杂结宽（雪崩有跑道）。前面两种击穿，就是在这块对峙区里演的。

### 正偏导通——Vbe 的过路费模型

平衡态是"没加电压"的静止画面。加上正向电压之后发生什么？**外加 Vbe 抵消一部分内建势垒——势垒从 Vbi 降到 Vbi - Vbe——矮到多子能大量翻过去——电流指数爆炸。** 把导通压降拆成两笔账：

```
Vbe = 抵消（性格价）+ 驱动（记账价）

抵消    买下内建势垒 Vbi——材料定死的——硅 ≈ 0.6~0.8V——
        0.7V 就是硅结"抵消势垒需要"的量级——性格签名
驱动    剩下的电压推电流——对数项 n·V_T·ln(I/Is)——电流的记账——很小

开关点就在 Vbe ≈ Vbi 附近：
  远低于它    势垒还高——电流指数级小——截止
  接近它      势垒矮到极限——电流指数爆炸——导通
  超过它      势垒完全抵消甚至反转——大电流（功率管 Vbe 到 0.9-1V）
```

**为什么 0.7V 能当工程常量用——对数压缩窗口：** 指数关系的反向是对数——电流从 1µA 涨到 100mA（10 万倍），Vbe 只从约 0.55V 动到 0.75V（0.2V）。每十倍电流 Vbe 只涨 60mV（ln10 × V_T = 2.3 × 26mV）——**巨大的电流范围被压进窄窄的电压窗口——任何正常范围的电流，落进去都读 0.6~0.8V。** 不是 Vbe 被固定，是它天生对电流迟钝。工程上取 0.7 几乎不会错，因为错的范围只有 0.2V，而电流可以错十万倍。0.7 是硅的性格代表值——像 π 取 3.14——不是性格本身。边界：功率管大电流 1V+、锗管 0.3V、温度每度 -2mV/°C——全在这个窄窗口附近，取 0.7 的近似始终够用。

**对三极管：** 发射结就是一个 PN 结——Vbe 就是三极管让电流过发射结要交的"过路费"——大部分买下内建势垒（性格价），小部分推电流（记账价）。这也是工程上"不用电压源直接驱动基极、永远用电阻喂电流"的原因：Vbe 对电压极其敏感（60mV 翻 10 倍），电阻吃掉电压的不确定性，剩下的才是设计者的。

### 空穴的本质——缺失态、状态传播与统计流

空穴不是实物粒子。**它是"电子缺席"这个状态的拟人化**——物理上叫准粒子（quasiparticle）：数学上完全按真实粒子处理（有自己的有效质量、迁移率），本质是一个缺失态的集体行为。

```
P 型掺杂后：
  受主负离子（B⁻）——固定在晶格位置——不动的骨架
  空穴（缺失的电子态）——不属于任何原子——属于整条价带——
  可以在整个晶格里自由移动

空穴=晶格里的气泡：气泡不是实物（是水的缺失），但会上浮、会扩散——
载体是抽象的，动力学是真实的
```

**空穴怎么移动？靠电子的接力跳变：** 电子跳进空穴→空位在原位消失→在电子原来的位置出现——空位转移了。看起来就是空穴在移动，方向与电子相反。**这本质是"状态传播"不是"实体平移"：** 每个格点只是在"被占据/空着"之间翻转，翻转序列看起来像空穴在走——像多米诺骨牌：没有一张牌移动，每张牌只是原地倒下，"倒下"这个状态在传播。波函数同理：ψ(x,t) 在每个点的值随时间演化，"波的传播"是图案的传播，没有波包在平移。

**而这是物理的通用图景——所有"移动"都是状态转移：**

```
声波      空气分子只在原地振动——传播的是"压缩状态"不是空气
光        场的每个点在振荡——传播的是场图案不是物质
空穴      每个格点翻转——传播的是"缺失态"
```

**微观是翻转，宏观是流：** 空穴的"扩散"是真实物理效应——热涨落造成的翻转在统计上不是均匀的——浓度高的地方向浓度低的地方多翻了几格——**统计偏差积累成净流。** 单个空穴不存在，扩散流存在——实体是抽象，流是真实。

对三极管：Ib 里的"多子扩散项"（基区空穴注入发射区）就是这个状态传播的宏观投影——发射区重掺杂，两边空穴浓度差巨大，净流从基区涌向发射区——这就是"发射效率"的物理源头。

### 产生-复合的能量循环——半导体为什么永远发热

复合和产生不只是"载流子的生灭"——它们带着一份能量账：

```
产生    吸收能量——热能踢电子上导带（本征激发）——温度越高产生越多
复合    释放能量——电子落回价带——释放 ≈ Eg（硅 1.12eV）——
        大部分变成热（声子），少部分发光（辐射复合）
```

**"车和车位一起拆掉"的时候，拆出来的就是能量。** 硅是间接带隙，复合必须借助声子（动量不守恒），所以硅的复合几乎全变成热——半导体器件永远发热的根源。而 LED 是"复合走发光路线"的特例：复合释放的能量直接变成光子，光的颜色 = 带隙（红光 1.8eV、蓝光 3.0eV）——**LED 就是把"复合的尾气"改造成了产品。**

而产热恰好是热失控正反馈循环的燃料：

```
温度↑ → 产生率↑（指数）→ I_s↑ → 漏电↑ → 功耗↑ → 结温再↑
→ 热失控/热击穿——半导体最该防的东西
功率器件上散热片、降额设计——管的就是这个循环的尾巴
```

完整闭环：

```
性能写死（性格）    掺杂、结构、材料——出厂焊死——Is、β、击穿电压
环境施压（外部）    温度、电压、光——可变的输入
产生-复合（呼吸）   吸收能量产生、释放能量复合——动态循环
复合产热（尾气）    循环的代价——也是热失控的燃料
```

**半导体 = 一台写死参数的呼吸机：性格出厂定死，环境决定呼吸快慢，呼吸产热，热反过来决定呼吸——管住热，就管住了这台机器的命。**

### 三极管的工作状态——偏置组合与四区控制权

**正偏 vs 反偏**——外加电压的方向问题：

```
正偏    P 接正、N 接负——顺着 PN 结导通方向——
        削弱内建电场——势垒变矮——多子能扩散过去——导通
反偏    P 接负、N 接正——反着 PN 结导通方向——
        加强内建电场——势垒变高——多子过不去——截止
```

**三极管四状态由两个结的偏置组合决定**（"发射结正偏、集电结反偏"不是默认值——是放大状态的偏置钥匙）：

```
放大    发射结正偏 + 集电结反偏    Ic = β·Ib——线性放大
饱和    两个都正偏                 导通——开关闭合
截止    两个都反偏                 关断——开关断开
倒置    发射结反偏 + 集电结正偏     几乎不用——倒置 β 极小
```

**为什么放大必须这个组合——两个门模型：**

```
发射结正偏 = 开入口门——N+ 发射区电子涌进基区——原料放行
集电结反偏 = 开出口吸——反偏电场把穿过基区的电子全吸向集电区——
             只收不发——电子不会回流
组合 = 原料进、成品出——单向放大链——
    注入量由发射结电压控制（门开多大）——
    收集率接近 100%（出口吸力全开）——
    复合率固定（基区结构决定）——
    注入量按固定比例分成 Ib（复合）和 Ic（收集）
```

**饱和 vs 击穿——谁到顶了：**

```
饱和    电流到顶——Ic 被外部电路限住：Icsat ≈ Vcc/Rc——
        管子电压被压到 Vcesat（0.1-0.3V）——集电结变正偏——
        "电路不想给了"——安全可逆——减小 Ib 就回来
击穿    电压到顶——Vce 超过击穿电压 BVceo——雪崩/齐纳——
        载流子倍增——电流失控——"管子扛不住了"——
        不可逆——可能热失控烧毁

外接电阻的角色：
    Rc 设定了 Icsat——让"电流到顶"恰好发生在电压安全的位置——
    把"到顶"从危险的电压区推到安全的电流区——
    Rc 在——电路先到顶（饱和）——Rc 不在——器件先扛不住
    （过流烧毁或击穿）——设计者的工作：决定"让谁先到顶"
```

**三区控制权——Ib 的地盘只有一段窄路：**

```
截止    Ib≈0——Ic≈0——电路说了算
放大    Ic = β·Ib——Ib 说了算——唯一的"控制区"
饱和    Ic ≈ Vcc/Rc——电路说了算——Ib 失去控制——
        继续加大 Ib 进"深饱和"——代价不是电流变了——
        是退出饱和变慢（存储时间）——开关应用要处理的

设计者的全部工作：让三极管待在这段窄路里（偏置设计）
```

### 伏安特性的两条温度经验规则——正向区和反向区的两个切面

伏安特性曲线最值钱的部分不是形状——是它的两条温度规则。都是 Shockley 方程的直接推论，工程上天天用：

```
温度 ↑1°C          正向压降 ↓2~2.5mV      （规则一——做温补用的）
温度 ↑10°C         反向电流 ×2            （规则二——做功耗预算用的）
```

**规则一：正向压降 -2 到 -2.5mV/°C。** 从 V ≈ n·V_T·ln(I/I_s) 看——温度升高，V_T 线性增大（+0.086mV/°C，小头），但 I_s 指数级暴涨（大头），ln(I/I_s) 被拉下来——净效果是 V 每度降 2mV 左右。硅管取 -2mV/°C，有些教材写 -2.5。这也意味着**二极管本身就是一个线性温度计**——测它的正向压降就能读温度。

**规则二：反向电流每升 10°C 翻一倍。** 从 I_s ∝ n_i² ∝ e^(-E_g/kT) 看——E_g=1.12eV 塞进指数里，温度每动一点，漏电流就指数级动。10°C 翻倍是经验值，实际硅管大致在这个量级（锗管更敏感）。

```
正向区（规则一）                      反向区（规则二）
───────────                       ───────────
切的是 V ≈ n·V_T·ln(I/I_s)         切的是 I_s ∝ e^(-E_g/kT)
每度降 2mV——线性                    每 10°C 翻倍——指数
用途：温度补偿                      用途：功耗预算
```

两条规则就是伏安特性曲线的两个切面——一个切正向区，一个切反向区。工程上全靠这两条：CTAT 温补是规则一的逆向操作；电源待机功耗估算看规则二——温度一高，漏电翻倍，电池待机时间缩水。这也是为什么之前说"0.6V 不是常数"——它是规则一在跑。

### 雪崩击穿与齐纳击穿——同一个反向区，两条相反的温漂

反向偏置推到极限会发生击穿——电流突然暴增——但击穿不是一种机制，是两种，且对温度的态度完全相反。根子都在结宽上。

**雪崩击穿——宽结、轻掺杂——正温度系数。**

结宽，载流子在电场里能跑的距离长。反向电压拉高电场→电子在结里加速→撞晶格原子→电离出新的电子空穴对→再加速再撞→雪崩级联。

温度升高，晶格原子振动加剧（声子多），电子每走一步都被散射，攒不到足够的动能去电离。要维持同样的电离率，只能把电场拉更高——**所以温度越高，雪崩击穿电压越高。** 电压大约 7V 以上的击穿基本都是雪崩。

**齐纳击穿——窄结、重掺杂——负温度系数。**

结太窄，载流子不需要跑——直接量子隧穿。电子从价带"穿"到导带，穿过去的是势垒，概率取决于势垒厚度（结宽）和能隙宽度。

温度升高，半导体能隙 E_g 变小（负温漂），势垒变矮，隧穿更容易——同样的电压下电流变大——**所以温度越高，齐纳击穿电压越低。** 电压低于 5V 的击穿基本都是齐纳。

```
               宽结、轻掺杂                      窄结、重掺杂
               ───────────                     ───────────
击穿机制        雪崩——碰撞电离级联                 齐纳——量子隧穿
载流子        加速撞晶格——电离新对                直接穿势垒——不跑
温漂            正：T↑→声子散射↑→要更高电场         负：T↑→E_g↓→势垒变矮→更低电压就穿
温度系数        +mV/°C                           -mV/°C
典型范围        7V 以上                          5V 以下
```

**5V 到 7V 之间两种机制共存**——雪崩的正系数和齐纳的负系数互相抵消，温度系数可以压到接近零。所以精密基准稳压管都选 5-6V 档位。Widlar 当年拿 0.6V 二极管做基准是另一个解法——但"找个温漂互相抵消的档位"这个思路是一样的。

对 Feelings 的意义：AD5933 内部扫频激励和 VCCS 驱动都工作在远低于击穿电压的安全区，但 AFE 入口的 ESD 保护二极管——静电瞬间能把结推到击穿区——雪崩型的 ESD 管温漂是正的，齐纳型的温漂是负的。选型时如果只看了击穿电压没看温度系数，在 -20°C 到 +40°C 的穿戴场景里，ESD 触发阈值会漂移——本该在 12V 触发保护的，冬天可能 11.5V 就泄放了，夏天 12.5V 才动作。**击穿电压不是门槛——是一个随温度漂移的区间。**

### 反向推导——升温为什么不能用来"防雪崩"

既然雪崩击穿是要避免的，而温度升高会抬高雪崩击穿电压——那能不能反着用，主动升温来防击穿？

这是 f(x)=y 和 y=f(x) 的关系——同一个函数，但反着推出来的结论在工程上不成立。

```
正向（物理事实）                          反向（错误推论）
─────────────                          ────────────
温度升高 → 雪崩电压升高                   "那升温就能防雪崩了"
温度升高 → I_s 指数级暴涨                 "I_s 暴涨没关系，反正击穿电压高了"
```

反向推导漏掉的正是正向推导里那个指数项。温度升高确实把雪崩击穿电压抬上去了——但同一时间，I_s 在指数级暴涨（Shockley 方程里就是它）。漏电流变大→功耗变大→结温再升→I_s 再涨——正反馈循环，最终触发**热失控（热击穿）。**

```
降温                                温度升高
────                               ──────
雪崩电压 ↓                          雪崩电压 ↑——看似"更难击穿"
漏电流 I_s 小                       漏电流 I_s 指数级暴涨 ← 真正致命的
器件安稳                            功耗↑→结温↑→I_s↑→功耗↑……正反馈 → 热击穿
```

雪崩击穿本身是可逆的——电压撤了结就恢复。热击穿是不可逆的——结被烧穿，器件直接报废。把温度当"防雪崩手段"等于用枪伤换子弹穿膛——躲过了碰撞电离，没躲过热失控。

工程上避免雪崩的正道是**降额设计**——留电压裕量，工作点远低于击穿电压。热永远是半导体最该防的东西，不是该利用的东西。真正"利用"雪崩的只有 TVS/ESD 管——故意工作在击穿区的器件——靠它快速泄放和可恢复——但也只有那一瞬间允许，持续功耗照样烧。

### V 与 Uon——电源给多少，二极管要多少

新手最容易混的两个量：电源电压 V 和导通压降 Uon。它们是两个完全不同来源的东西：

```
V      电源电压——电路给的——设计输入——"我提供多少"——所以电路图上必须标
Uon    导通压降——器件自带的——固有属性——"二极管要拿走多少"——硅管≈0.7V是常识，图上不标
```

**关系就是一条最简单回路的算账：**

```
V = 5V，R = 1kΩ，硅管 Uon = 0.7V

电流 = (V - Uon) / R = (5 - 0.7) / 1000 = 4.3mA

电源先付掉二极管要的 0.7V，
剩下的 (V - Uon) 才轮到电阻去产生电流。
```

图纸只标设计输入（V），Uon 隐含在器件型号里——1N4148、1N4007 全是硅管，默认 0.7V，查手册或凭常识就知道。**用万用表量任意一个导通的硅二极管，两端永远 ≈0.7V——量到的不是电源给的，是器件自己"咬住"的那一口。** V 必须大于 Uon 电路才能工作——V < Uon，一滴电流都过不去（1.5V 电池推不动蓝光 LED，蓝光 Uon≈3V）。

### 直流叠加与工作点——两套坐标系，两种"移动"

"直流和交流能不能在同一个电路里"——能。任何一点的电压 = 直流分量 + 交流分量 = 平均值 + 波动。但**叠加的"移动方向"取决于你在哪张图里看**：

```
时域波形 v(t)-t       直流叠加 → 波形整体上下平移（横轴=时间，加的是纵轴）
伏安特性 I-V          直流偏置 → 工作点在横轴上"左右"选位置（横轴=电压）
```

**时域图里**：v(t) = Vdc + Vac·sin(ωt)——正半周加、负半周减，每时每刻在算账——但结果写在纵坐标上，所以曲线整体上下移动。铁证：Vdc=5V、Vac=±3V，波形在 2V~8V 之间，永远碰不到 0V 以下——如果是左右（相位）移动，波形应该还在原来的电压范围里。**判据一句话：看波形和 0V 线的距离变了没——变了=上下（叠加），没变=左右（相位/延迟）。**

**伏安特性图里**：横轴是电压、纵轴是电流，二极管的曲线在 Uon 处向右上拐（指数上升段）。直流偏置 = 在横轴上左右移动工作点 Q；交流 = 工作点沿曲线来回滑动——输入电压左右摆，输出电流上下跳。**曲线越陡，同样一点电压摆动产出的电流波动越大——陡峭度就是增益。** 这就是"工作点"思想：Q 点放在拐弯处→通断切换（整流、削波）；放在陡峭直线段→线性放大（晶体管）。

**微变等效的本质 = 在 Q 点附近把曲线近似成切线**——交流小信号当它沿切线走，切线斜率就是那个"曲线有多陡"的系数（跨导）。**先定 Q 点（直流），再算切线（微变），然后交流沿切线走（动态分析）——"先静态后动态"的全部秘密。** 这也是模电课程第 05 讲（微变等效）和第 14-16 讲（Q 点稳定、共射/共集/共基分析）在算的事。

### 二极管的三大波形手术——整流、削波、钳位

二极管是"非线性的门"——单向导通 + 恒定压降——这两个性质让它能做三件事：整流、削波、钳位。串联和并联分工不同：**串联二极管管"电流能不能过"（阀门），并联二极管管"电压不能超多少"（泄压）。**

```
① 整流    串联单向阀门——正半周放行，负半周截断
           〜〜〜〜   →   ⌒⌒⌒⌒（半波）——损耗账见下一节

② 削波    并联二极管+偏置电压——电压上限——
           超过 V+0.7 的部分被泄掉，波形顶部削平（限幅）

③ 钳位    二极管+电容——直流电平移位——
           波形整体抬高/压低，形状不变（0~5V → 5~10V）
```

**稳压管 = 反向钳位**——反向击穿时把电压死死钳在击穿电压上（5.1V 稳压管 = 把电压钳在 5.1V 的专用钳位器）。整流→钳位→稳压是同一把刀的三次用法。对 Feelings：AFE 入口的 ESD 保护二极管就是并联泄压的工程形态——把静电瞬间钳在安全轨上。

### 二极管整流——把交流变直流的损耗账

二极管整流有损耗，而且严重程度看工作电压——越低越痛。损耗来源主要是正向压降：二极管导通要吃掉 0.6-0.7V（硅管）。整流桥 4 个管，导通路径上有 2 个——一次性吃掉 1.2-1.4V。

```
输出电压 = 输入峰值 - 导通路径上的二极管压降

5V 电源用桥式整流（2×0.7V=1.4V 损耗）→ 效率只剩 ~70%
230V 市电整流（1.4V vs 230V）       → 损耗 0.6%——可以忽略
3.3V 可穿戴（1.4V vs 3.3V）         → 烧掉四成——痛
```

损耗功率 = V_f × I——变成热。电流越大热越多，所以大功率整流要加散热片。

**降低损耗的三条路：**

1. **肖特基二极管**——压降 0.2-0.3V，替代硅管的 0.7V，但耐压低、反向漏电大。
2. **同步整流**——用 MOSFET 代替二极管，导通电阻毫欧级，损耗接近零——开关电源的标配。
3. **避开整流**——低压电路直接电池+LDO/DC-DC，根本不让交流进来。

对 Feelings 特别相关：3.7V 锂电池 → 3.3V 轨道，中间绝对不能串二极管（0.7V 一扣只剩 3.0V 还要 LDO 再吃一点）——必须用低压差 LDO 或 DC-DC。这就是模电课程第 48-50 讲（直流电源组成、桥式整流、稳压）要解决的核心问题。

另外注意一个概念陷阱：二极管整流不是"转换"交流成平滑直流——它只是把负半周砍掉或翻上来，输出是**脉动的直流**，后面必须跟滤波电容才变平。损耗在这里还有一笔：滤波电容充电瞬间的冲击电流。

### 555 振荡器——锁相环工程师顺手造的可调频率器件

### 555——35 年全球最畅销的 IC

任何一个电学专业的学生都听过用过 555。**35 年来全球最畅销的 IC，每年销售 10 亿只。** 不是为了某个大客户定制的——是一个 PLL 工程师为了自己用着方便顺手搭的——然后全世界都不愿意放手。

## JFET——两个 PN 结夹一条沟道的电压控制器件

### JFET 结构——两个背靠背的 PN 结

N 沟道 JFET：P 型栅极（上下两块，连在一起是 G）夹住 N 沟道——形成两个背靠背的 PN 结（栅-沟道结）。栅源之间加反偏（Ugs<0）——耗尽层向沟道内扩展——沟道变窄。

反偏不消耗栅流——输入阻抗极高——**电压控制器件**：手在栅上，Ugs 就是那只手。

### 栅源偏置的三个区间——0 是工作边界，不是导通边界

教材说"Ugs > 0 就坏"——简化说法。精确的界限不是 0，是 Uon（硅 0.6-0.7V）：

```
Ugs ≤ 0                     反偏——正常工作区——栅高阻、控制沟道
0 < Ugs < Uon (0.6-0.7V)    正向偏置但未通——过路费没交够——
                            栅极开始泄漏电流（指数关系）——阻抗下降——
                            已不在工作区——泄漏区
Ugs ≥ Uon                   正向导通——栅流暴增——器件功能破坏——
                            栅被当成另一个电极——损坏区
```

过路费模型原样适用：PN 结势垒 = 0.7V——正偏 = 开始交过路费（势垒开始降）——正偏 0.1V 只交了 0.1，势垒还剩 0.6——只有高能尾部的载流子能挤过残余势垒（泄漏电流，微安级，指数关系）——交够 0.7V，势垒清零，大门全开，导通。正偏 ≠ 导通——正偏只是"开始削弱势垒"。

反向极限：V(BR)GSS（栅源反向击穿电压，一般 20-30V）——Ugs 负过头才是真击穿（雪崩/齐纳）。所以 Ugs 正向过大是"正向导通"，不是"击穿"——击穿是反向的。

**为什么规定 0——原理性的，不是"0 和 0.7 太接近"**：

```
泄漏破坏高阻   正偏哪怕 0.1V——输入阻抗从 GΩ 崩到 MΩ——JFET 的命根子
               （高阻输入）当场失效——功能没坏，规格坏了
动态信号余量   静态点设在正偏——信号正半周直接顶到 0.7V 导通——
               正偏区意味着信号范围不可用
手册额定       数据手册绝对最大额定值写死 Ugs ≤ 0——
               正偏区不是工作区是损坏区——厂商对它没有任何规格承诺——
               正偏时 JFET 退化成"二极管+一段电阻"——控制功能完全失效
```

电阻图景——连续渐变不是开关：电阻 = 势垒的函数，载流子数量随势垒指数变化——反偏 GΩ 级 → 正偏 0.1V 还是 MΩ 级 → 0.5V 明显变小 → 0.7V 骤降到几欧——从 GΩ 到 Ω 是连续滑过去的，中间那段"开始变但还没变完"就是泄漏区，也是离开规格的那段路。

防烧穿的两道防线：栅极串电阻限流（datasheet 里栅极从不裸奔——意外正偏时靠串联电阻限住电流）+ 别碰 V(BR)GSS（反向击穿红线）。

### 沟道宽细的分工——Ugs 定整体，VDS 定分布

```
Ugs（栅源电压）  定整体——栅越负，耗尽层整体越厚，整条沟道一起变窄——
                 Ugs = 0 时最宽（对应饱和漏极电流 Idss）
VDS（漏源电压）  定分布——D 端更窄、S 端更宽——沿沟道的锥形分布——
                 改变不了平均宽度，只改变不均匀程度
```

机制链：D-S 加电压后，电位沿沟道从 S 到 D 逐渐升高（电流在沟道电阻上产生压降，D 端电位最高）——栅极是同一块金属（同一电位）——所以栅-沟道结的反偏电压 = 栅电位 - 沟道电位，沿沟道变化：S 端反偏小（抵消/减弱），D 端反偏大（增强）。

```
反偏电压越大 → 耗尽层越厚 → 沟道越窄
D 端反偏最大 → 耗尽层最厚 → 沟道最窄
```

注意措辞：不是"自由电子多的地方窄"——是"自由电子被耗尽得多的地方窄"。耗尽层就是自由电子被清空的空间——反偏把 N 侧电子赶走，赶走的地方变成空间电荷区不再导电。D-S 势场不是直接推 PN 结，是先改沟道电位，电位差再改 PN 结偏置——一根沟道上同时存在从弱反偏到强反偏的连续分布。

### 预夹断与饱和——缝隙越长，电流越稳

VDS 增大到一定程度，D 端耗尽层在沟道中间会合——**预夹断**。之后 VDS 继续增大，夹断区（缝隙）从 D 端向 S 端延伸——增大的电压全部落在缝隙上（耗尽区高阻、吃掉压降）——**导电沟道两端被固定在夹断临界电压**——电流稳住。

```
Ugs 更负 → 夹断更早发生（VDS,sat 更小）→ 同样的 VDS 下缝隙更长
缝隙不零流：耗尽区没有自由载流子，但电子被电场扫过——
           缝隙是高阻通道，不是断路——电流连续性
```

### 输出特性——一个 Ugs 一条完整曲线

```
可变电阻区    从原点出发按固定斜率爬——斜率 = 1/Ron（由 Ugs 定）
预夹断点      在固定电压拐弯——VDS,sat = VGS - Vp0（由 Ugs 定）
饱和区        水平延伸——Id ≈ 恒流值（由 Ugs 唯一决定）
```

"电阻"模型只在可变电阻区成立（VDS 小、缝隙未形成，沟道是纯电阻）；进入饱和区后换成"恒流源 + 缝隙"模型（电压全给缝隙，电流被 Ugs 钉死）。修正：缝隙延伸时剩余导电沟道变短——Id 会随 VDS 略微上升（沟道长度调制——输出电阻有限，不是理想恒流源）——以后看放大电路输出电阻时见到这条尾巴。

**Ugs 是唯一的主变量，VDS 只是跑龙套的**——可变电阻区它定电阻，饱和区它定电流，预夹断点它定拐弯位置——这就是"电压控制器件"的全部含义。

### Feelings 关联——高输入阻抗前端

JFET 的核心资产是输入阻抗极高（反偏栅不消耗栅流）+ 低噪声——这是生物电采集前端的标准输入级：电极和皮肤之间的接触阻抗高、信号源极弱（微伏-毫伏级）——前端必须高输入阻抗才能"不加载信号源"（采样电路分流小，信号不被吃掉）。Feelings 的 EMG/EEG 采集前端，JFET 输入级是教科书级的搭配：高阻采样 + 低噪声放大。

## 共射放大电路的基本构成——电容管交流，电阻管直流

### 最小标准型——输入耦合电容 + 固定偏置

```
Vcc ── Rb ── B(基极)        三极管 NPN
信号源 ── C(耦合电容) ── B    E 接地
Rc：Vcc 与 C 之间的负载电阻
```

三个元件，三个分工：

```
输入耦合电容    隔直通交——信号源和基极之间的直流耦合被双向隔离：
               信号源里的直流进不了基极（别污染工作点）；
               基极的直流偏置不倒灌信号源（别污染信号源）
Rb（固定偏置）  直流的地基——Ib = (Vcc - Vbe)/Rb——Rb 决定工作点——
               电容管交流，Rb 管直流——两套坐标系的硬件分工
Rc（负载电阻）  I→V 转换器——Vce = Vcc - Ic×Rc——电流的影子落在电压上——
               放大后的电流信号翻译成电压摆动
```

### 直流滤除的精确理解

直流不是"被滤除"了，是被**分流**了：信号路径的直流被电容滤掉（隔直通交），偏置路径的直流被 Rb 保留（建立工作点）——信号路径滤直流，偏置路径留直流。

### 观察与取出——电压表换成电容

```
电压表    观察窗口（教学）——内阻大——只看不拿——Vce 全部（直流+交流）都看到
电容      传输通道（实际电路）——隔直通交——只取走"来回摆"的部分（交流）——
          直流工作点留在本级——下一级干净——负载要的是摆动不是静止
```

观察是看，耦合是传——同一根 Vce，电压表用来验证放大，电容用来实际放大。

### 负载线——工作点沿直线滑动

Vce = Vcc - Ic×Rc 在输出特性图上是一条直线（斜率 = -1/Rc）——静态时工作点在这条线上某一点——信号来时 Ic 跟着 Ib 摆动——工作点沿负载线来回滑动——电压表看到的"来回"就是工作点滑动的轨迹。

```
无 Rc    负载线水平——工作点不动——电压表死线——看不到放大
有 Rc    负载线有斜率——工作点来回滑——电流放大转成电压摆动
```

Rc 不能乱选：太大压降把工作点压到饱和区（失真），太小电压摆幅小（增益低）——选 Rc 就是选负载线斜率，也是选增益。

### 固定偏置的缺点——温度稳定性

"be 之间没有任何器件"= 固定偏置（单电阻）——最简；缺点是 β 随温度漂移 → Ic 漂移 → 工作点漂移 → 失真。实际电路改用分压偏置（Vcc→Rb1→基极，基极→Rb2→地 + 发射极电阻 Re 温度反馈）——"单电阻"升级"双电阻"的原因：给裸 be 结加稳定性补丁。

### 偏置直流的来源——Vcc 是直流坐标系的天花板

两个直流要分清：信号源带来的直流被电容滤除（不掺和——到达基极的信号是纯交流）；电路自己的偏置直流由 Rb 建立（工作点——信号骑在偏置上）。

```
信号源 ──C──┐
            └── B（基极）——这里叠加：偏置直流（Rb 来的）+ 纯交流（电容送的）
Vcc ──Rb───┘
```

基极处的真实波形 = 偏置直流 + 交流摆动——交流信号本身纯净（无信号源直流），但它活在直流的环境里（偏置就是给信号搭的台子）。三极管放大的正是"骑在直流上的摆动"——摆动幅度（交流）被放大，台子（偏置直流）稳住不动。

"直流被分流"的精确含义：两个直流被电容隔开各走各的路——信号源直流被挡（别污染工作点）、偏置直流由 Rb 建立（工作点别被信号源拽跑）——直流没有消失，是"谁的直流归谁"。

而偏置直流的源头是 Vcc：

```
Vcc（电源）──Rb（限流水管）──B（基极，被 be 结钳位在 ≈0.7V）
```

基极的直流电位不是 Vcc 本身——是 be 结说了算：be 结正向导通（过路费模型）把它钳在 0.7V——Rb 负责把 Vcc 降下来 + 限定电流——Ib = (Vcc - Vbe)/Rb。类比：Vcc 是水库，Rb 是水管（限流），be 结是水龙头（钳位 0.7V）——水是水库的，但流到基极的水量水压是水管和水龙头定制过的。

集电极侧：Vce = Vcc - Ic×Rc——离 Vcc 近，被 Rc 压降拉下来一点。所以整个电路的直流骨架全是 Vcc 撑的——Vcc 就是直流坐标系的天花板：偏置（基极 0.7V）和供给（集电极 Vce）全部从它取量——交流坐标系（信号摆动）骑在这个天花板上放大。

## 三极管的截止与击穿——注入-收集机制与反向红线

### 截止区——反偏断路，只能击穿

B 无偏置时：C-B 结反偏、B-E 结零偏——C-E 是背靠背的两个结——不通——电压全担在反偏的 C-B 结上——超过 V(BR)CBO 就击穿——但击穿是损坏区不是工作区。

三极管的电流从不靠"电压穿透"，靠"注入-收集"：

```
发射结（B-E）正偏   = 水龙头——打开 → 电子从 E 注入基区
集电结（C-B）反偏   = 吸尘器——反偏收集——把注入基区的电子吸到 C
```

放大区电流链：发射结注入（水龙头开）→ 基区电子 → 集电结反偏收集（吸尘器吸）→ Ic = β×Ib。反偏的集电结本身不产生电流——只收集别人注入的电流——没有注入，吸尘器吸不到东西。击穿是水龙头坏掉之后电压自己硬闯的暴力通道。

### 两个结的击穿分家——集电结雪崩，发射结齐纳

击穿类型由掺杂浓度和击穿电压决定：高击穿电压（>7V）轻掺杂 → 碰撞电离 → 雪崩击穿（正温漂）；低击穿电压（<5V）重掺杂 → 量子隧穿 → 齐纳击穿（负温漂）；5-7V 混合。

```
C-B 结（集电结）  集电区轻掺杂——为耐高压（V(BR)CBO 几十到几百伏）——
                  高电压 → 雪崩击穿——正温漂（温度高击穿电压高）
B-E 结（发射结）  发射区重掺杂——为注入效率——击穿电压只有 5-7V——
                  低电压 → 齐纳/隧穿——负温漂（温度高击穿电压低）
```

同一个器件上，两种击穿，两种温漂方向——"同一个反向区，两条相反的温漂"在这里应验。

### 反偏才击穿——B-E 结什么时候反偏

击穿永远是反向的——正偏只会导通。B-E 结正常放大时正偏（0.7V），三个场景会反偏：

```
信号负半周过大    强信号把基极拉到比发射极低——E 接地（0V）——
                  B 到 -6V 以上——发射结齐纳击穿——损坏
开关管负偏置      加速截止——故意给 B-E 结加负压（减少存储时间）——
                  超限就击穿
瞬态干扰          电源上电/放电瞬态——B 电位瞬间低于 E
```

基极保护二极管（标配护栏）：基极并联反接二极管——把 B-E 结反向电压钳位在 0.7V（二极管先导通）——发射结永远碰不到击穿电压。

收口：正偏是工作，反偏是边界，击穿是越界——V(BR)CBO（集电结雪崩）和 5-7V（发射结齐纳）就是两根反向红线。

### 击穿电压与电路设计——Vcc 不能过大

Vcc 过大不是直接击穿——链条是：Vcc 大 → 静态 Vce ≈ Vcc - Ic·Rc（Ic 不大时 Vce 接近 Vcc）→ Vce 超过集电结击穿电压 → 雪崩击穿。击穿的是"集电结承受的反偏电压"（Vce/Vcb），不是 Vcc 本身——Vcc 只是电压的来源，真正怼在集电结上的是 Vce。

```
两个击穿电压（器件参数——datasheet 直接给）：
    V(BR)CBO    集电极-基极击穿电压——几十到几百伏——
                轻掺杂耐高压——雪崩——正温漂
    V(BR)CEO    集电极-发射极击穿电压——低于 CBO——
                基极开路时更容易击穿

击穿电压是器件的固有参数——由物理结构决定：
    掺杂浓度    轻掺杂 → 耗尽层厚 → 耐高压（雪崩）——
                集电区轻掺杂就是为了耐高压
    基区宽度    影响 V(BR)CEO（基区越窄越容易击穿——与 Early 同源）
    结面积/材料  结构尺寸和半导体材料（禁带宽度）

击穿类型也是器件决定的：
    C-B 结（轻掺杂）→ 雪崩——高电压——正温漂
    B-E 结（重掺杂）→ 齐纳——低电压（5-7V）——负温漂

设计匹配（双向）：
    选管子 = 选耐压等级——高压应用（Vcc 大）→
        选 V(BR)CEO 高的管子——低压用普通管
    Vcc/Rc 必须匹配管子耐压——
        工作电压取击穿电压的 1/2~1/3 以下——
        绝对最大额定值是红线——不是拿来贴的

饱和 vs 击穿的方向：
    饱和  往"下"压——Vce 到 0.1V——不危险（只失真）
    击穿  往"上"顶——Vce 超红线——烧管子
    偏置设计 = 把 Vce 放在上下两根线之间——
    下不碰饱和（失真），上不碰击穿（烧毁）
```

同一个电路换管子——击穿风险完全不同——同样的 Vcc，耐压 100V 的管子没事，耐压 30V 的管子直接雪崩——器件参数决定电路的安全边界——管子决定"能扛多少电压"，电路决定"给它多少电压"——两个都要对。

## Q 点与偏置——公式与参数

### 输入侧（确定静态 Ib、Ube）

```
偏置线（输入回路方程——负斜率直线）：
    Ib = (Vbb - Ube) / Rb
    含义：Ube 越大 → Ib 越小（负斜率）——
          Vbb 是基极电源电压（偏置源）——
          Rb 是基极偏置电阻（你设计的）——
          Ube 被 be 结钳位在 ~0.7V（导通区）

be 结指数曲线（器件本性）：
    Ib = Is · e^(Ube/UT)
    含义：Is 是反向饱和电流（漏电流——极小）——
          UT 是热电压（≈26mV@室温）——
          Ube 的小变化 → Ib 的指数级大变化——
          这是"毫伏电压 → 大电流"的入口

Q 点（输入侧）= 偏置线 × 指数曲线的交点
    → 锁定静态 Ib、Ube——
    Q 点的 Ube 必须落在 0.6-0.7V（导通区）——
    Ube < 0.5V → Ib≈0 → 截止——不能放大——
    0.6-0.7V 是"能工作的前提"（交够过路费）
```

### 输出侧（确定静态 Ic、Uce）

```
负载线（输出回路方程——负斜率直线）：
    Vce = Vcc - Ic·Rc     （或 Ic = (Vcc - Vce)/Rc）
    含义：斜率 -1/Rc——横轴截距 Vcc——纵轴截距 Vcc/Rc——
          Vcc 是电源电压——Rc 是集电极电阻（你设计的——
          I→V 转换器——选 Rc 就是选增益）

输出特性曲线族（器件本性）：
    放大区：Ic = β·Ib
    含义：β 是电流放大倍数（器件参数——写死的）——
          每一条曲线 = 一个固定的 Ib——
          曲线族 = 不同 Ib 的各一条

Q 点（输出侧）= 负载线 × 输入侧锁定的 Ib 那条曲线 的交点
    → 锁定静态 Ic、Uce——
    其他交点都是虚拟的（"如果 Ib 是别的值才成立"）——
    Q 点唯一——因为 Ib 已被输入侧锁死
```

### 电压增益（不是 β——是 Av）

```
电压放大链：
    ΔUbe（毫伏级信号）→ ΔIb = ΔUbe/rbe
                      → ΔIc = β·ΔIb
                      → ΔUce = -ΔIc·Rc
    Av = ΔUce/ΔUbe = -β·Rc/rbe

参数含义：
    β      电流放大倍数（器件参数——管子的本性）
    rbe    输入动态电阻（be 结切线斜率——"电压变电流"的汇率）
    Rc     集电极电阻（电路参数——"电流变电压"的转换器——
            你设计的——Rc 越大 Av 越大——但 Rc 太大工作点塌）
    负号    共射反相——输出与输入反相

区别：
    β = 电流增益——器件的本性——固定
    Av = 电压增益——电路的工程——β、rbe、Rc 共同决定
    放大的是"叠加在 0.7V 上的波纹"（ΔUbe 毫伏级）——
    不是 0.7V 本身——水位不动，波纹被放大
```

### Q 点位置的意义

```
Q 点 = 电路设计（Rb、Rc——你选的直线）与器件本性
       （指数曲线、曲线族——写死的）的相遇点——
       两次相遇：输入侧定"哪条曲线"（Ib）——
                 输出侧定"哪个点"（负载线交点）

Q 点太高（Ib 大）→ 波纹正半周摆进饱和区 → 削底
Q 点太低（Ib 小）→ 波纹负半周摆进截止区 → 削顶
Q 点居中（平坦区中间）→ 波纹两边有空间 → 最大不失真摆幅
```

## 微变等效与驱动关系——增量语言 vs 绝对量语言

### Ube 和 Ib 的驱动关系（因果方向）

```
be 结的本性：电压控制电流（指数关系 Ib = Is·e^(Ube/UT)——
             给电压，出电流——电压是自变量）

电路里的因果方向取决于驱动源：
    电压源+电阻驱动（放大电路的实际结构）：
        Vbb → Rb → be 结——电压源先给出电位——
        Ube 被钳位 ~0.7V——Ib = (Vbb-0.7)/Rb——
        此时"电压决定电流"——Ube 定了，Ib 由电阻定
    电流源驱动（强制注入电流）：
        强行灌入 Ib——Ube 被推着上升（维持指数关系）——
        此时"电流驱动电压"

放大电路：静态（电压源+电阻——Ube→Ib）+
          交流（信号源叠加 ΔUbe——ΔUbe 驱动 ΔIb）——
          始终是"电压→电流"——之后 β 放大电流——
          Rc 变回电压——三级接力：毫伏电压→大电流→伏特电压
```

### 增量 vs 绝对量——微变等效的语言规则

```
rbe = ΔUbe/ΔIb（增量之比——切线斜率——纯交流/小信号）
Ube/Ib（绝对量之比——原点连线斜率——直流/静态）
两者完全不同——绝不能混

严格写法：
    rbe = ΔUbe/ΔIb   ✓（动态电阻——切线——微变等效用这个）
    rbe = Ube/Ib      ✗（静态电阻——连线——那是另一回事）

举例：Ube=0.7V，Ib=1mA
    静态电阻：0.7V/1mA = 700Ω（连线斜率）
    动态电阻：rbe——切线斜率——指数曲线陡——
              同样电压变化引起更大电流变化——
              rbe 只有几百欧——和 700Ω 差很多

分界：
    线性元件（纯电阻）   切线 = 连线——两个电阻相等——不区分
    非线性元件（be 结）  切线 ≠ 连线——静态电阻（大）——
                       动态电阻（小）——微变等效用动态电阻
```

### 微变等效模型（小信号模型）

```
B ── rbe ── C
│          │
E          β·ΔIb（受控电流源——集电极到发射极）

输入侧（be 之间）    rbe——动态电阻——Q 点定了它就定了
                   （切线斜率）——"看进去像电阻"
输出侧（ce 之间）    受控电流源 β·ΔIb——不是电阻——
                   电流由输入（ΔIb）控制——β 倍放大——
                   放大区 ce 是恒流（Ic 由 Ib 控制——
                   不随 Vce 变——输出特性平坦）——
                   所以等效必须是"输出电流被输入控制"

"三极管 ≈ rbe"是输入侧视角（看进去像电阻）——
完整模型 = rbe（接收）+ 受控源（放大）——两个元件

微变等效是纯增量语言：
    ΔIb、ΔUbe、β·ΔIb——全是增量——
    处理的是"台子上演员的动作"（Δ）——
    不是"台子的高度"（静态——指数曲线/偏置线的天下）——
    两条语言系统，各说各的
```

## rbe 公式推导——四个零件

```
rbe = rbb' + (1+β)·UT/Ieq
```

### 四个零件的含义

```
rbb'    基区体电阻——基区半导体材料的物理电阻——
        电流从基极引脚流到发射结要穿过基区——
        物理电阻（欧姆、线性）——与工作点无关——
        小功率管约 100-300Ω——"门口的走廊——绕不开"

(1+β)   从 KCL 来——Ie = Ic + Ib（电荷守恒）——
        发射极电流分两路：β 份走集电极（Ic）、
        1 份走基极（Ib）——基极只经手自己的 1 份——
        "从基极看电流被缩小 (1+β) 倍"——
        (1+β) 里的 1 是基极的存在感，β 是集电极拿走的——
        少一个都不守恒

UT      热电压——UT = kT/q——室温（300K）≈ 26mV——
        温度相关（UT = T/11600）——工程上近似常数——
        来自 PN 结物理（肖克利方程 Ib = Is·e^(Ube/UT)）

Ieq     发射极静态电流（直流）——Q 点定了它就定了——
        交流小信号下它基本不动（固定锚）——
        所以 rbe 基本固定——线性才成立——
        Ieq 与 rbe 的关系是反比（不是线性）
```

### 推导链

```
第一步：发射结的指数关系
    Ie = Is·e^(Ube/UT)
第二步：发射结看进去的动态电阻（对指数求导——切线）
    r_e = dUbe/dIe = UT/Ie（发射结自身的增量电阻）
第三步：从基极看——电流被缩小 (1+β) 倍（KCL）
    Ib = Ie/(1+β)——基极视角的电阻放大 (1+β) 倍：
    dUbe/dIb = (1+β)·dUbe/dIe = (1+β)·UT/Ie
第四步：串联基区体电阻（物理电阻——独立于工作点）
    rbe = rbb' + (1+β)·UT/Ieq
```

数值感受：Ieq=1mA，β=100，UT=26mV——(1+β)·UT/Ieq = 101×26/1 ≈ 2626Ω——加上 rbb'（200Ω）——rbe ≈ 2.8kΩ——Ieq 越大 rbe 越小。

### 注意分界

```
Ie = Ib + Ic——KCL——电荷守恒——结构性的——
    任何状态成立（直流/大信号/小信号）——与线性化无关——
    三极管当不当电阻看都成立——物理铁律

rbe 固定——局部线性化——只在小信号（Δ 语言）下成立——
    只在 Q 点邻域内成立——是近似——是切线——
    大信号下失效——工程近似

"三极管当一个电阻看"只说对了输入侧（be 端——rbe）——
    输出侧（ce 端）是受控源（β·ΔIb）——不是电阻

链条：Q 点定了 → Ieq 定了 → rbe 定了 → 输入侧电阻固定 →
    线性成立（小信号近似）
```

## 温度对 Q 点的影响——三路攻击与三层防线

### 温度的三个攻击点

```
β     温度↑ → β↑ → Ic = βIb 变大 → Q 点上移
Vbe   温度↑ → Vbe↓（-2mV/°C）→ Ib 增大 → Q 点上移
漏电流  温度↑ → Icb0 指数增大（硅管每 10°C 翻倍）→ Q 点上移

三路都指向同一方向：温度↑ → Ic 增大 → Q 点上移 →
更靠近饱和区 → 饱和失真——
冬天调的完美 Q 点——夏天可能已经在饱和边缘——
"Q 点好好找" = 找"在温度范围内都稳的 Q 点"——
不是"室温下好看的 Q 点"
```

### 稳定 Q 点的标准方案

```
分压偏置（Rb1/Rb2）    稳定基极电位——
                       不让 Ib 直接跟着电源/温度乱跑
发射极电阻 Re           负反馈温度补偿——
                       Ic 增大 → Re 压降增大 → Vbe 减小 →
                       Ic 被拉回来——"温度想推——Re 拉住"——
                       最简单有效的温补

器件选型：
    硅管（锗管已淘汰——漏电流大——温度敏感）——
    工作温度范围覆盖应用环境——不留死角
```

### Feelings 语境——穿戴设备的温度挑战

```
穿戴设备温度波动比台式电路恶劣得多：
    冬天室外 / 室内 / 运动时体温升高（皮肤 35°C+）——
    采集链的 Q 点漂移 → 失真 → 削波 → 数据错 →
    漏桶/安全判定跑偏——指挥链上的错误——
    比音频破音严重（音频：难听——采集：判断错）

三层防线：
    电路层    分压偏置 + Re——负反馈拉住——不漂
    器件层    宽温范围选型——扛得住环境
    软件层    闭环校准——基线跟着环境漂移——
              漏桶参数自适应——吃掉残余温度误差——
              硬件负责不漂——软件负责兜漂
```

## 元器件磨合与浴盆曲线——参数稳定是工程的第一课

### 浴盆曲线（bathtub curve）——失效率三阶段

```
早期失效期（磨合期——失效率高）：
    制造缺陷在初期暴露——虚焊、材料瑕疵、工艺问题——
    新车走合（前 5000 公里）就是这个阶段——
    零件的毛刺、配合面在互相磨平——
    参数在初期不稳定（漂移大）

稳定期（失效率低且平稳——几十万公里）：
    磨合完成——缺陷已暴露——剩下的都是可靠的——
    参数稳定——长期运行

磨损期（寿命末期——失效率回升）：
    材料疲劳/老化——寿命到了——浴盆的右边沿
```

### burn-in（老化筛选）——把磨合期安排在出厂前

```
出厂前高应力运行（高温/连续负载）——
    让早期失效"提前暴露在工厂"——
    坏件在出厂前被剔除——
    用户拿到手的——是已经跨过磨合期的器件——
    车厂的做法：试车线——电子厂的做法：老化房——
    都是"把磨合期安排在出厂前"

原理：参数稳定的前提是"过了磨合期"——
    初期参数漂移大（虚焊/接触/内部应力）——
    老化后参数收敛到稳定值——
    直接测的参数可能是"磨合中的参数"——不可靠
```

### Feelings 的三层磨合

```
① 器件磨合（burn-in）：
    实验板焊好——不能直接上人体——
    先连续运行几天（老化测试）——
    虚焊/接触不良/器件缺陷——在实验室暴露——
    不在用户身上暴露

② 界面磨合（电极-皮肤）：
    皮肤-电极接触阻抗——刚戴上不稳（极化/汗液/角质层）——
    需要稳定时间——几小时到几天

③ 系统磨合（闭环校准）：
    基线建立/漏桶参数初始化——冷启动期——
    第一周不准——一个月后准——系统级的浴盆曲线

原则：把磨合期安排在实验室——
    器件老化（出厂前）——界面磨合（模拟佩戴测试）——
    系统磨合（冷启动设计成不刺激期）——
    用户拿到的永远是"稳定期"

对 Feelings 特别重要：
    磨合期的风险不是"不好用"——是"安全判定建立在
    未稳定的数据上"——
    参数未稳定时采集的数据不可靠——
    漏桶/基线判定会跑偏——
    所以系统的安全验证要等磨合完成后再做——
    让系统在实验室里先完成走合——再让它上路
```

## 固定偏置 vs 分压偏置——推力与拉力的拔河

### 固定偏置（单 Rb——Rb 和 Rc 都接 Vcc）的推力-拉力分析

```
Vcc↑ 的两个效应（同时发生）：
    直接推力    Vb = Vcc - Ib×Rb——Vcc 升 → Vb 升 →
               Ib 升 → Ic 升（β 放大）——推
    反馈拉力    Ic 升 → Ve 升（Re 压降）→ Vbe 降 →
               Ib 降 → Ic 降——拉

两个力拔河：推力 > 拉力——Ic 缓慢增加——
    "缓慢" = 拉力抵消一部分推力——不全抵消——
    有 Re：Ic 增量被除以增益因子——变化率减小
    无 Re：Ic 增量全量——按 β 放大——猛增

老师简化掉的一步：
    "b 点电势降低"是分压偏置的简化说法——
    固定偏置里 Vcc 升 → b 点升（不降）——
    精确链条：Vb 升（推）和 Vbe 降（拉）同时发生——
    Ib 净增——被 Re 拉回一部分——所以缓慢增加
```

### 分压偏置（Rb1/Rb2）——b 点锚定

```
Vb = Vcc × Rb2/(Rb1+Rb2)——电阻比钉死——与 Ic/Ie 无关——
前提：I_Rb2 >> Ib（基极电流远小于分压电流——
      Ib 变化不影响分压——Vb 由电阻比决定）

分压偏置的特性：
    无直接推力（Vb 钉死——Vcc 变 Vb 不变）——
    只有反馈拉力（Ve 升 → Vbe 降——全量传递）——
    Ic 几乎不变——漂移被拉回——
    温度稳定性好（β/Vbe/漏电流温漂全被拉）——
    电源稳定性好（Vcc 波动影响小）
    代价：多两个电阻——静态电流 I_Rb2——
          可穿戴折中：Rb1/Rb2 取大阻值——
          I_Rb2 小但 >> Ib——稳定用功耗换——值

固定偏置：看得懂原理（简单——教学用——但漂）
分压偏置：做产品（稳定——工程用）——
Feelings 采集链必须选分压偏置：
    Q 点不漂 = 不失真 = 数据不污染安全判定——
    温度（冬夏/运动体温）+ 电源（电池电量）——
    双波动环境——只有分压偏置扛得住
```

### 分压偏置的直观理解——锚与杠杆

```
结构修正：
    Rb1（Vcc→B）——Rb2（B→GND）——串联分压——
    基极是分压点——Rb2 不是"be 两端"——
    是"基极到地"（be 之间是发射结——不能并电阻）

条件：IRb2 >> Ib——基极抽走的电流远小于分压电流——
    分压关系不被扰动——Vb ≈ Vcc×Rb2/(Rb1+Rb2)——钉住

关键区分：
    不变的是 Vb（基极电位——锚）——
    Ib 恰恰会变（反馈时 Ib 变——这才是稳定 Ic 的杠杆）——
    Vb 钉住 = 锚——Ib 可变 = 杠杆——
    锚不动——杠杆灵活——反馈才完整：
    Ve 变 → Vbe = Vb - Ve 全量传递（Vb 不动）→
    Ib 变（杠杆）→ Ic 被拉
```

## 共集与共射的级联适配——接口与增益的分工

### 两种接法的分工

```
共集（射极跟随器）   接口的活
    输入电阻大（几百 kΩ）   不加载信号源，信号完整进来
    输出电阻小（几十 Ω）    驱动能力强，像理想电压源
    增益约 1（不放大，只变换阻抗）

共射（放大级）       增益的活
    输入电阻中等（几 kΩ）
    增益大（Av = -βRc/rbe）
```

### 级联的阻抗衔接

```
共集 → 共射：天然适配
    Ro(共集) << Ri(共射)
    分压比 = Ri / (Ri + Ro) ≈ 1
    信号几乎完整传给共射，不损失

级联原则（任何两级之间）：
    前级输出电阻 << 后级输入电阻
    信号传递不衰减（分压几乎全给后级）
```

### 分工哲学与原型

```
共集管接口（缓冲、隔离、阻抗变换）
    把"难伺候的信号源"变成"好驱动的源"
共射管增益（放大）
    接在共集后面，只管放大，不用操心信号源阻抗

这个分工 = 运放内部结构的原型：
    输入级（高阻差分）→ 增益级 → 输出级（低阻驱动）

Feelings 采集链同理：
    生物电信号源阻抗高（电极接触），
    输入级必须高阻接收（缓冲思维），
    后面才进增益级放大，
    （实际用 INA/运放芯片，内部就是这个级联）
```

收口：共集输出小，共射输入中，级联天然适配（Ro << Ri，信号不损失）。多级放大的分工哲学：高阻接收、中间放大、低阻驱动。这个结构正是运放内部和 Feelings 采集链的骨架。

### 三级套娃——buffer → amplifier → buffer

```
共集 → 共射 → 共集 三级分工

输入共集（缓冲）
    高 Ri：不加载信号源
    低 Ro：把信号源变成"好驱动的源"

中间共射（放大）
    只管增益，两端被缓冲包着
    不操心信号源阻抗，也不操心负载阻抗

输出共集（缓冲）
    高 Ri：不加载放大级的输出
    低 Ro：驱动负载不衰减
```

套娃保证的是"接口稳定"（信号传递不损失），不是"增益稳定"（增益大小恒定靠负反馈，运放的虚短虚断）。两层稳定，两个工具：接口稳定靠缓冲级，增益稳定靠负反馈。

### 套娃的边界——不会无限套

每加一级共集（或任何一级），都要付代价：

```
噪声累积    每级的噪声都加到信号上（平方和）
失真累积    每级都有一点点失真，级联后累积
带宽变窄    每级都有高频衰减，级联带宽由最窄级决定
相位偏移    每级都有相位滞后，反馈环路里相位累积
            可能振荡（负反馈接反等于正反馈，之前聊过）
功耗体积    每级都有静态电流，元件数量增加
```

工程原则：够用就停。

```
标准配置    输入缓冲 + 放大级 + 输出缓冲
            两级缓冲通常就够，不会无限套
中间级      按增益需求定（增益不够才加一级放大，
            每加一级放大同样付代价）
为什么不会套很厉害    每套一层都有账单（噪声失真带宽相位），
            账单超过收益就停，
            运放内部通常也就输入级+增益级+输出级，
            三级封顶，没有更多
```

## 四种耦合方式的完整分工

```
阻容耦合    交流信号级间，电容隔直通交
            低频衰减（高通特性）
            音频/中频的分立电路
            优点：级间直流隔离，每级工作点独立
            缺点：低频被衰减（fc = 1/(2πRC)）

直接耦合    低频/DC 信号级间，直连
            低频无损
            优点：保低频（生物电需要）
            缺点：工作点连锁，调试难，漂移累积
            Feelings 采集链主力

变压器耦合   磁耦合，原副边电气隔离
            通过磁场传信号/功率
            阻抗变换（匝数比）
            低频传不了（低频要大电感，又大又重）
            用于：电源隔离、功率传输

光电耦合    LED + 光敏，电气完全隔离
            光传信号，物理断开的信号通道
            速度受限（低速几十 kHz，高速几 Mbps）
            线性度差（模拟信号失真，除非线性光耦）
            用于：数字隔离、电源反馈
```

### Feelings 里的位置

```
信号链（采集/刺激）   直接耦合为主
                    生物电低频是信号，直接耦合保低频
                    阻容只在"故意切低频"时用（滤波决策）

电源链   变压器隔离（DC-DC 隔离）
          医疗设备安全硬要求：
          患者与市电电气隔离（IEC 60601 漏电流红线）
          Feelings 是贴皮设备，电源必须隔离

安全域   光电耦合（数字隔离）
          FPGA 主域与外部接口之间
          安全域与主域之间的数字信号隔离
          （光耦 = 物理断开的信号通道，
          "Engine 无权访问"的硬件实现之一）

判断标准：
    信号里的 DC 是信号 → 直接耦合
    信号里的 DC 是垃圾 → 阻容（有意高通）
    要电气隔离传数字 → 光耦
    要电气隔离传功率 → 变压器
```

收口：四种耦合各管一摊：信号直接（保低频）、电源变压器（保隔离）、数字光耦（保隔离墙）、滤波阻容（切低频）。Feelings 四样全用上，但位置不混。安全不只靠代码，还靠光。

## 温度补偿方案的三层——被动、二极管、数字

主动温补的思路（检测温度、调节偏置、补偿温漂）方向对，但实现上有三层成熟做法：

```
① 被动温补（最简单，元件自己响应）

热敏电阻（NTC/PTC）
    阻值随温度变化
    直接串在发射极或偏置电路
    温度升 → 阻值变 → 自动补偿
    无传感器、无游标、无机械
    元件自己就是传感器加执行器

② 温补二极管

二极管正向压降随温度变（约 -2mV/°C）
    串在偏置电路补偿 Vbe 温漂
    比热敏电阻更精准
    利用二极管和 be 结"同向温漂"的性质
    （都随温度升高压降减小，互相抵消）

③ 数字温补（最符合 Feelings）

数字温度传感器 → FPGA 读取
    → 数字电位器/DAC 调偏置
    闭环温补，可编程、可记录、
    可个体化校准（每个人的温漂曲线不同）
```

机械滑动变阻器的代价（为什么不用机械游标）：

```
磨损    可动触点，用久了接触不良
振动    可穿戴设备，游标会抖
精度    机械定位不如数字精确
体积    滑动变阻器大，塞不进耳机
——可穿戴设备不适合机械部件
——可编程比可滑动更适合
```

Feelings 的落地（数字温补 + 个体化校准）：

```
三层防线的软件层升级
    电路层    分压偏置 + Re（被动温补，
              够大多数场景）
    器件层    宽温范围选型（扛环境）
    软件层    闭环校准兜底（吃残余漂移）

数字温补是软件层的升级
    主动温补：温度实时读取，
    偏置实时调节
    温度到偏置的映射可以个体化校准
    （每个人的温漂曲线不同，
    类似 PBM 的个体化哲学）

工程原则：够用就停
    分压加 Re 的被动温补对大多数场景够了
    主动温补（数字闭环）留给精度要求高的地方
    游标换成寄存器，滑动换成编程
    机械换成数字，同样的思路换个世纪的实现
```

## 差分电路的虚地——汇合点电位稳定

### Re 两侧的静态电压

```
Vbe = 0.7V
    be 结两端的电压差（压强差）
    基极比发射极高 0.7V，恒定（导通特性）

发射极对地电位 = 基极电位 - 0.7V
    （绝对电位，取决于基极电位）
    基极接地（0V）时，发射极 ≈ -0.7V
    基极接别的电位，发射极跟着变

Re 下端 = -VEE（负电源）
Re 两端直流压降 = 发射极电位 - (-VEE)
    直流压降一直存在（不变的部分）

为什么必须接 -VEE 而不是直接接地
    直接接地：发射极 0V，基极 0V 时
    Vbe = 0，be 结不导通，管子不工作
    接 -VEE：发射极被压到 -0.7V，
    Vbe = 0.7V，be 结导通
    VEE 的使命：把发射极压到基极之下 0.7V

物理与等效的区分
    物理电路：Re 下端接 -VEE（工作点的需要）
    交流分析：Re 下端视为接地
    （直流电源交流阻抗为零，短路）
    两个说法都对，一个说怎么接，
    一个说怎么算

注意区分：
    0.7V 是 be 结两端的压差（相对），
    不是发射极对地的绝对电位（绝对）
    虚地恒定的含义：
    差模时汇合点电位"不随信号变"
    （无论静态值是多少），
    恒定的是"不变性"，不是"某个具体值"
```

### 静态方向与动态变化的区分

```
静态电流方向（同向）
    Ie1 和 Ie2 都从发射极流出，
    都流进 Re，都流向 -VEE
    方向相同，Re 上有静态压降

动态电流变化（差模时反向）
    差模信号：T1 的 ΔIe 增加，
    T2 的 ΔIe 减少
    变化量一正一负，相加为零
    Re 上的电压变化为零
    ——"电位差为 0"指动态变化为零，
    不是静态电压为零
```

### 虚地——汇合点电位稳定

```
差模信号时，汇合点（发射极节点）电位稳定不变
    T1 电流增加 → 想让汇合点变
    T2 电流减少 → 想让汇合点反着变
    两个变化相消，总电流不变，电压不变
    汇合点稳如泰山

虚地的意义
    对差模信号，汇合点等效交流接地
    差模分析时 Re 可以拿掉，发射极视为接地
    每半边单独分析（像共射接地）

它保证差模信号不被 Re 吃掉
    汇合点稳定，信号不在 Re 上产生压降变化
    信号完整作用于两个管子
    增益 = 单管共射增益（不被 Re 打折）
```

### Re 的三个身份

```
静态的 Re    电阻（有直流压降，工作点靠它稳）
差模的 Re    透明（虚地，增益不被吃掉）
共模的 Re    墙（电流同向叠加，强负反馈，
            共模增益被压死，CMRR 的原理）
```

### "消失"的精确含义——等效不是物理

```
差模时 Re 的"等效消失"，三层确认

① Re 本体    一直在（没拿掉，没短路）
             静态直流压降在，工作点在

② Re 的差模响应   为零
             T1 增量 +ΔIe，T2 增量 -ΔIe
             在 Re 上相加 = 0
             电压变化 = 0，无反馈
             "等效"像不存在（透明）

③ Re 的共模响应   很强
             增量同向叠加，电压大变
             强反馈，压死共模
             （装死和装墙的理由是同一个：
             增量相消还是叠加）
```

收口：同一个 Re，对差模装死（透明），对共模装墙（强反馈）。"消失"是它对差模的态度，不是它的物理存在。汇合点稳住了，一切就拆得开。

### 两倍与抵消——动态时 Re 的两种等效

```
差模进来（一增一减）
    增量相消，Re 无压降变化
    等效消失（透明）
    差模增益 = 单管共射增益
    （Av ≈ -βRc/rbe，不被 Re 打折）

共模进来（同向变化）
    增量叠加，Re 上流的是两管电流
    （总电流变化 = 2ΔIe）
    每个管子等效看到 2Re
    （欧姆定律：V = 2Ie × Re，
    反馈效应翻倍）
    共模增益 ≈ -Rc/(2Re)
    （Re 越大，共模抑制越强）
```

共模等效 2Re 的来源：

```
共模信号 → 两管电流同时增加
    T1：+ΔIe，T2：+ΔIe
    Re 上总电流变化 = 2ΔIe
    对每个管子看，等效反馈电阻 = 2Re
    （它的 ΔIe 只贡献一半电流，
    但反馈作用于两个管子）
```

差分电路的选择性完整成表：

```
信号类型     Re 的等效      增益
──────────────────────────────
差模（有用）   消失（0）     大（单管共射增益）
共模（噪声）   两倍（2Re）   小（被压死）

CMRR = 差模增益 / 共模增益
    = 选有用压噪声的能力
    Re 越大，CMRR 越高
    可以到 60-100dB（抑制 1000 到 10 万倍）
```

Feelings 咬合：生物电采集环境全是共模噪声（工频 50Hz 同时作用于两电极），差分电路的"压死共模"就是采集链的第一道防线。INA 仪表放大器是差分电路的集成版，CMRR 是它的核心指标。

### 共模是形式还是性质——架构决定的身份

```
共模是"信号的形式"，不是"信号的性质"

共模 = 两个输入端同时出现的成分（同相等幅）
    本身没有"有用/噪声"的标签
    是"采集目标"决定它的身份
```

差分采集的语境下（Feelings 的架构），共模 = 噪声：

```
差分采集的哲学
    只取差异（差模），丢掉共同（共模）

所以"共同的成分"，无论是什么，
都是"干扰差异测量的东西"

共模的实际内容
    工频 50Hz（市电干扰，同时打两电极）
    电源噪声
    直流偏置（共同工作点，不是放大对象）
    基线漂移（皮肤电位、电极极化的慢漂移）
    远处信号（远处的心电同时到达两个
    近邻电极，被抑制，近处的差异信号
    被放大）
    ——这些都是差异测量要丢的
```

有用的共模确实存在，但不在差分架构里：

```
单端采集（一个电极对地）
    "整体电位"就是信号
    但工频直接叠加在信号上（单端怕工频）

所以生物电采集选差分
    两点差异，去掉共同干扰
    工频变成共模（被抑制）
    差分架构把"共同"定义为"要丢的"
```

收口：差分哲学一句话：只取差异，丢掉共同。共模的身份就是"被丢掉的共同"。你选差分采集，就等于宣告：所有同时出现在两个电极上的东西，都是噪声。

### 为什么考虑共模增益——共模客观存在

```
输入里同时存在
    差模信号（有用的，两电极的差异）
    共模噪声（工频 50Hz、电源噪声，
    同时打在两个电极上）

输出 = 差模信号 × 差模增益
     + 共模噪声 × 共模增益

要的是前一项大，后一项小
    如果共模增益不为 0
    工频噪声被放大，混进输出
    信号里全是 50Hz 的嗡嗡
```

类比：听远处的声音（差模），旁边有噪音（共模）。不仅要放大声音，还要保证噪音不被放大。如果放大器连噪音一起放大，输出里全是噪音，声音再大也听不清。

Feelings 咬合：工频干扰客观存在（市电 50Hz 无处不在，同时作用于两个电极）。共模增益不为 0 就是采集波形被 50Hz 污染，就是 PBM 数据不可信，就是后续判定建立在脏数据上。

### 差分电路的测试方法——同向和反向都要测

```
验证差分电路，测两种输入模式

① 反向输入（差模）
    两个信号源相位相反
    测差模增益（应该大）
    Av_dm = 输出差模 / 输入差模

② 同向输入（共模）
    两个信号源相位相同
    测共模增益（应该小）
    Av_cm = 输出共模 / 输入共模

③ 算 CMRR
    CMRR = 差模增益 / 共模增益
    越大越好（理想无穷大）

测量仪器
    信号发生器（双通道，可设相位）
    示波器或万用表（测输出）
    或者用网络分析仪（扫频测增益）
```

收口：差分电路做两件事，缺一不可：放大差模（让信号变大），压死共模（让噪声不变大）。两件事合起来才是干净的放大。测试时同向反向都要测，两个增益的比值就是 CMRR。

## 双入单出的差分电路——只取一边的代价

### 双出和单出差在哪：输出从哪取

```
双入双出：输出 = vc1 - vc2
    两个集电极之间的电压差
    像看天平：看两个指针的相对距离

双入单出：输出 = vc1 对地
    只取一边集电极
    像看天平：只盯一边的指针
```

### 差模增益减半：只看见一半

```
差模信号从两个基极对称进
    T1 基极 +vid/2，T2 基极 -vid/2
    每个管子只分到一半输入

双入双出：Aud = -β(Rc∥RL)/(Rb+rbe)
    两边各放大一半
    输出取差，拼回全量

双入单出：Aud1 = -β(Rc∥RL)/(2(Rb+rbe))
    只取一边，只看见一半摆动
    差模增益减半
```

### 共模不再抵消：同向动被看见

```
共模输入：两个管子同向动
    vc1 和 vc2 一起涨一起跌

双入双出：Aoc = 0
    取差，同向动一减为零
    共模被完全消灭
    不存在"共模增益公式"

双入单出：Aoc ≠ 0
    只取一边，同向动被看见
    共模增益公式只属于单端输出
```

### 共模增益的完整公式：逐项拆

```
Aoc = -β(Rc∥RL) / (Rb + rbe + (1+β)·2Re)

分子 -β(Rc∥RL)
    共模对每个管子来说，
    也是一次共射放大
    β 倍基极电流变化 × 集电极负载

分母三项：基极回路的总电阻
    Rb      源电阻（信号源内阻、偏置）
    rbe     基射动态电阻
    (1+β)·2Re  最关键的项
```

### 2Re 怎么来的：板凳挤了两个人

```
共模进来，两个管子电流同向增大
    Re 上流过的变化 = 2 倍单管电流
    板凳（Re）要承受两个人的重量
    对每个管子来说，反馈作用翻倍
    等效 Re = 2Re

对比：差模时一增一减
    板凳上的变化相消
    等效 Re = 0（透明）
```

### (1+β) 怎么来的：发射极电阻折算到基极

```
发射极电流 = (1+β) 倍基极电流
    Re 上的压降 = (1+β)·iB·Re
    从基极回路看过去，
    发射极的电阻放大了 (1+β) 倍
    （像汇率换算：发射极的钱
    换成基极的钱要乘汇率）

共模时 Re 变 2Re
    基极回路里的等效 = (1+β)·2Re
```

### 5% 与 CMRR：同一电路内比

```
比值要同一电路内比（口径一致）

Aoc / Aud1
  = 2(Rb+rbe) / (Rb+rbe+(1+β)·2Re)
  ≈ (Rb+rbe) / (βRe)

5% 的含义
    Aoc ≈ 5% × Aud1
    βRe ≈ 20(Rb+rbe)
    CMRR = Aud1/Aoc = 20 倍 = 26dB

注意：拿双入双出的差模增益
（未减半）去比单出的共模增益
口径不对，差模增益要减半
```

### 为什么还要单出：差分转单端

```
后级（ADC、单端放大器）只要一路信号
    差分是两根线，必须合成一根
    双入单出就是"两根线合成一根"
    的转换器

取哪边相位不同
    取 T1 集电极：反相输出
    取 T2 集电极：同相输出

代价有数
    牺牲一半差模增益
    共模不再为零（靠 Re 压小）
    换后级能吃单端信号
```

收口：单端输出只取一边，差模减半、共模现身。共模增益公式里最重的项是 (1+β)·2Re：共模让两个管子的电流叠在 Re 上（板凳挤了两个人，等效 2Re），再折算到基极（乘汇率 1+β），把共模压成差模的百分之几（CMRR 20 倍起步）。

Feelings 咬合：采集链里 INA 内部先用双端吃掉工频共模，最后一级双入单出把差分信号转成单端送给 ADC。双入单出是"差分转单端"的标准衔接：差模减半换单端输出，共模靠大 Re 压着。CMRR 20 倍（26dB）对单级够用，不够就串级或换仪表放大器。

## 单入双出与单入单出——分解法：任意输入拆成共模+差模

### 分解法：唯一的拆法

```
任意两个输入都能唯一分解

vi1 = vic + vid/2
vi2 = vic - vid/2

其中
    vic = (vi1 + vi2)/2
         共模分量（两输入的平均，
         同相的那一半）
    vid = vi1 - vi2
         差模分量（两输入之差，
         反相的那一半）

单入特例（vi1 = vi，vi2 = 0）
    vic = (vi + 0)/2 = vi/2
    vid = vi - 0 = vi

    拆出两对信号：
    一对共模：两边各 vi/2（同相）
    一对差模：一边 +vi/2，
             一边 -vi/2

验证还原（两对叠加回原信号）
    T1 基极 = vi/2 + vi/2 = vi  ✓
    T2 基极 = vi/2 - vi/2 = 0   ✓
    ——一边 vi 一边 0，
    恰好还原

不是人为设计，是数学上的
唯一拆法
    （平均 + 差值，
    两个方程两个未知数）
```

### 为什么必须拆

```
单端信号既不是纯差模
（两边不反相）
也不是纯共模（两边不同相）

而 Re 的态度只认两种纯模式
    纯差模：Re 透明（等效 0），
    增益全量
    纯共模：Re 翻倍（等效 2Re），
    增益被压死

混合信号套不了公式
    必须拆成两个纯模式
    分别算（线性叠加原理），
    再相加
```

### 单入双出：双端输出消灭共模

```
差模对（±vi/2）
    两个管子反向放大
    双端取差
    输出 = Aud·vi
    （全量，和双入双出一样大）

共模对（各 vi/2）
    两个管子同向动
    vc1 = vc2
    双端取差 = 0
    （共模被双端输出消灭）

总输出 = Aud·vi + 0

结论：单入双出的差模增益
    = 双入双出的差模增益
    ——单端信号进，差分全量出
    ——一路信号源也能享受
    差分放大的全部好处
```

### 单入单出：双入单出 + 共模泄漏

```
分解（vi1 = vi，vi2 = 0）
    差模对 ±vi/2（vid = vi）
    共模对 各 vi/2（vic = vi/2）

输出叠加

差模对的贡献
    和双入单出的输入完全一样
    → Aud1 × vi
    （双入单出的全部输出）

共模对的贡献
    双入单出没有这部分
    单端输出看得见共模
    → Aoc × vi/2（泄漏项）

总输出 = vi × (Aud1 + Aoc/2)

大小对比
    Aoc 只有 Aud1 的 5% 级别
    共模泄漏项 = Aoc/2
    ≈ 2.5% × Aud1
    ——很小，但存在

结论：单入单出 ≈ 双入单出
    （差 2.5% 级别，通常忽略）
    ——方向相同，只大不小
```

### 四种接法闭合成表

```
输入×输出的四种组合

双入双出   差模全量，共模为零
           （最理想）

双入单出   差模减半，共模泄漏
           （差分转单端）

单入双出   差模全量，共模为零
           （单端信号进，
           差分全量出）

单入单出   差模减半 + 共模泄漏
           ≈ 双入单出
           （多一个 Aoc/2 的
           小尾巴）

规律：输出取双端，共模被消灭
      输出取单端，共模泄漏进来
      增益全量还是减半，
      只看输出取哪边
      （输入单端不影响差模增益，
      只多送一对共模进来）
```

收口：分解法一句话：任意输入拆成"平均（共模）+ 差值（差模）"，两个方程两个未知数，拆法唯一。单端信号一边 vi 一边 0，拆出来恰好共模 vi/2 加差模 ±vi/2。输出取双端共模被消灭，输出取单端共模泄漏进来。单入双出 = 双入双出全量增益，单入单出 = 双入单出 + 半个共模增益（2.5% 级别的小尾巴）。

## 恒流源差分放大电路——Re 的两难与电流镜的两全

### Re 的两难：一个电阻伺候两个主子

```
共模抑制要 Re 大
    CMRR 和 Re 成正比
    工作点要 Re 小
    静态电流 × Re = 直流压降
    Re 大就要更大的 -VEE 去补

物理电阻的困境
    直流电阻 = 交流电阻 = R
    两个身份绑死
    ——共模抑制和静态工作点
    抢同一个 Re
```

### 恒流源的两全：直流和交流分开

```
直流身份：压降小
    静态电流由它设定
    工作点好设置
    VEE 不用太大
    （只要够管子工作在放大区，
    几个结压降的空间）

交流身份：电阻无穷大
    交流信号想改变电流？
    恒流源说：不
    电流纹丝不动
    交流等效电阻 r 巨大
    （理想无穷大）

——这是物理电阻做不到的
    电阻：直流 = 交流（绑死）
    恒流源：直流小、交流大
    （两个身份分开）
```

### 三个身份重看

```
静态：恒流源设定静态电流
    两个差分管各分一半
    工作点稳

差模：一增一减，总和不变
    总电流本来就该不变
    恒流源"正好不用动"
    对差模完全透明
    差模增益不被吃掉

共模：同向增加，电流想变
    恒流源坚决不变
    等效交流电阻 r 趋近无穷
    共模被压得比 Re 狠得多
```

### 公式升级：Aoc 趋近 0

```
之前（Re 方案）
    Aoc = -β(Rc∥RL)/(Rb+rbe+(1+β)·2Re)

之后（恒流源方案）
    2Re → 2r（r 是恒流源的
    交流电阻）
    Aoc ≈ -Rc/(2r)

r 无穷大 → Aoc 趋近 0
    CMRR = Aud/Aoc 趋近无穷
    ——接近理想差分电路
```

### 电流镜的交接机制：共享 Vbe

```
基准管（接成二极管）
    集电极和基极短接
    ——故意接成二极管：
    让自己变成"电流标准"
    电流由外部电阻 R 设定：
    Iref = (VCC - Vbe)/R
    ——这个 Iref 流过它，
    它的基极上就挂着
    一个对应的 Vbe

镜像管
    基极接基准管的基极
    ——两个管子共享
    同一个 Vbe

镜像的关键（匹配管）
    Vbe 相等 → Ic 相等
    （发射结的 IV 特性一样）
    所以镜像管电流
    = 基准管电流 = Iref
    ——交接产生的电流：
    一个管贡献 Vbe 标准，
    一个管照着标准复制电流
```

### 静态电流与稳定

```
静态电流分配
    电流镜输出 Iref
    送进差分对发射极公共点
    两个管子对称，各分一半
    IC1 = IC2 = Iref/2
    ——工作点由电流镜
    一笔设定

为什么大而稳定
    Ic ≈ (VCC - Vbe)/R
    Vbe（0.7V）是小项
    电流主要由 R 决定
    R 是精密电阻，
    精确、温漂小
    → 电流大而稳定

对比 Re 方案
    Ic ≈ VEE/Re
    受 VEE 波动直接影响
    ——恒流源对电源波动
    天然免疫
    （VEE 小波动，
    Ic 纹丝不动）
```

收口：恒流源差分电路 = 上面差分对 + 下面电流镜。电流镜的魔法是直流小、交流大：静态电流由基准支路精确设定（VEE 不用大），共模想改变电流时它坚决不变（等效交流电阻无穷大）。Aoc = -Rc/(2r) 趋近 0，CMRR 接近理想。

Feelings 咬合：INA 内部的差分输入级就是"双入双出 + 电流镜恒流源"的构型。CMRR 100dB 级靠的就是恒流源的交流无穷大：工频共模在恒流源面前纹丝不动地被压死。采集链第一道防线的底气所在。

## 场效应管差分放大电路——MOS 与 BJT 的区别

### 结构不变：换的是管

```
MOS 差分放大电路
    上面：两个 MOS 管差动对
    下面：恒流源（MOS 电流镜）
    ——双入双出的哲学照旧：
    差模放大、共模压死、
    恒流源两全
    ——Re/电流镜那一套全保留

换的只是"管"
    而管一变，
    输入侧和控制方式全变了
```

### 输入侧的最大区别：电流控制 vs 电压控制

```
BJT：电流控制（基极抽电流）

iB = iC/β
    输入要从信号源
    抽走基极电流
    输入电阻有限
    rbe ≈ 1-2kΩ
    差分输入电阻 = 2(Rb+rbe)
    （kΩ 级）
    ——信号源必须"供得起"
    这个电流
    ——源内阻大了，
    信号被分压吃掉

MOS：电压控制（栅极绝缘）

栅极是 SiO2 绝缘层
    栅流 ≈ 0
    输入电阻无穷大
    （MΩ 到 GΩ 级）
    差分输入电阻 = 无穷大
    ——不从信号源抽任何电流
    ——源内阻再大也不分压
    ——信号零损耗进来
```

### 增益：都是 -gm·RL，但 gm 来历不同

```
都写成 Av = -gm × RL

BJT 的 gm
    gm = IC/VT
    （VT = 26mV，热电压）
    给定 IC，gm 就定了
    数值大（几十 mS）
    ——同样电流下，
    BJT 增益高

MOS 的 gm
    gm = 2ID/Vov
    （Vov = VGS - VTH，
    过驱动电压）
    或 gm = √(2μnCox(W/L)ID)
    ——同样电流下，
    gm 通常比 BJT 小一个数量级
    → 单级增益比 BJT 小
    （靠增加 W/L 或电流补）
```

### 失调与噪声：两种性格差异

```
失调（对称性）

BJT：VBE 匹配好
    失调电压小
    （零点几 mV 级）
    ——精密放大选 BJT 输入

MOS：VTH 和 W/L 匹配差
    失调电压大
    （几 mV 到几十 mV）
    ——MOS 天生不那么对称

噪声（低频）

BJT：低频干净
    1/f 噪声小

MOS：1/f 噪声大
    （氧化层界面俘获载流子）
    低频段噪声明显
    ——生物电正是低频信号
    （<100Hz）
    ——这是 MOS 的坑
```

### 采集前端的取舍：高阻抗与低频噪声

```
电极-皮肤接触阻抗
    高（kΩ 到 MΩ 级）
    ——源阻抗高 →
    必须极高输入阻抗
    → 选 MOS/JFET 输入级
    （栅流≈0，
    电极阻抗不影响信号）

但 MOS 的低频 1/f 噪声
    恰好落在生物电频段
    ——所以实际方案：

① JFET 输入级
    输入阻抗极高
    （PN 结反偏，栅流≈0）
    1/f 噪声比 MOS 小
    ——高阻抗和低噪声的折中

② CMOS + 斩波
    斩波技术：
    信号调制到高频、放大、
    再解调
    把 1/f 噪声甩出信号频段
    ——集成方案的解法

→ INA 内部输入级：
    FET 输入（高阻抗）
    + 斩波（压 1/f）
    两者配合，
    高阻抗和低频干净都拿到
```

收口：MOS 差分电路结构照旧（差分对+恒流源），换管带来的根本区别在输入侧：BJT 电流控制（抽电流、输入阻抗 kΩ 级），MOS 电压控制（栅绝缘、输入阻抗无穷大、对信号源零负担）。增益都是 -gm·RL，但 BJT 的 gm = IC/VT（大），MOS 的 gm = 2ID/Vov（小一个数量级）。性格差异：MOS 失调大、1/f 噪声大（低频吃亏），BJT 失调小、低频干净。

Feelings 咬合：采集前端的取舍 = 电极高阻抗逼着用 FET 输入（信号才进得来），MOS 的 1/f 落在生物电频段，就用 JFET 或 CMOS+斩波绕开。高阻抗和低噪声两个都要，就得两个技术配合。

## 功率放大器的类别——导通角决定失真与效率

放大器的类别由导通角区分：管子在一个信号周期里导通多久，决定了失真和效率的账。

```
甲类      导通角 360°：全周期都在烧
          线性最好，静态功耗最高
          （单端最高效率约 25%）
          常驻的代价：没信号也在烧
乙类      导通角 180°：两管轮流各扛半边
          效率高（理论最高 78.5%）
          交越失真：过零附近两管都在截止区，
          死区吃掉小信号
甲乙类    微偏置：给两管一点静态电流，
          让它们零点附近微微导通
          用一点甲类的功耗，
          换掉乙类的交越失真
          = 标准的折中解
丙类      导通角 < 180°（典型 90-120°）：
          只在一小段里导通
          效率最高（80-90%）
          失真最狠：输出是一串窄脉冲
          必须配 LC 谐振回路：
          窄脉冲踢振子一脚，
          振子自己荡出完整正弦
          （飞轮效应）
          且脉冲必须落在振子振荡的
          正确相位上才踢得响
          RF 专用
丁类      开关状态：PWM 驱动，
          效率最高，适合音频和数字驱动
```

交越失真的根源就是 0.7V 过路费，但完整机制是两段叠加：

```
死区（平坦段）
    输入在 ±0.7V 之间，两管都不导通，
    输出直接是零，波形被切平
    BJT 死区 ≈ ±0.7V，
    MOSFET 死区 = Vth（1-3V，更狠）
膝部非线性（爬坡段）
    刚过 0.7V 导通后，增益还没到位，
    指数曲线还在爬坡
    输出不是切平之后接直线，
    而是过零附近被捏细：
    小信号放大得少，大信号正常
```

波形签名：过零处被捏细，顶部正常。甲乙类的微偏置不只是填平死区，还让两管在零点附近同时导电，推挽结构的两个非线性膝部互相抵消（奇次谐波对消），爬坡也被抹直。

对 Feelings 这条账最要命：

```
生物电信号   μV 级
乙类死区     ±0.7V = ±700000 μV
信号整个掉在死区里，
连死区的零头都够不着
→ 采集链永远不能碰乙类，
不是失真多少的问题，
是信号直接被吞掉
```

功耗的账必须分域算：

```
数字域谈待命    蓝牙、DSP 的睡眠模式，μA 级
               （AirPods Pro 的待命
               靠的是这个，不是甲类常开）
功放域谈效率    输出级选 D 类，用时才醒
信号域谈线性    采集链用线性常开，
               但代价是伪问题：
               微伏级信号的静态电流
               本来就 μA 级，
               甲类的"高功耗"罪名
               只在功率域成立
```

甲类代价的成立前提是功率域：放大的是能量，瓦级输出，静态电流烧电池。Feelings 放大的是信息，从头到尾不是功率设备——采集链处理微伏级生物电，最大输出 0.1mA 刺激，比一个甲类耳放的静态电流还小。放大信息选线性（功耗无所谓），放大能量选效率（失真可妥协），能量不需要保真。

Feelings 的四类映射（精确版，各管一摊）：

```
甲类      采集链：信号域的默认状态
          （运放内部输入级差分对、增益级
          天然常开，甲类性格免费自带），
          不是选项
丙类      刺激链：窄脉冲 + 身体的谐振腔
          （凌迟的一帧：
          0.1mA 踢腿，
          内分泌级联自己荡出完整化学潮，
          刹车在半衰期手里
          = 谐振衰减就是半衰期）
          呼吸锁相 = 丙类的相位纪律：
          踢腿要落在振子的正确相位上
丁类      驱动链：振动、音频，效率优先
甲乙类    不占位：Feelings 没有功率输出级，
          不必参加功放战争
```

功率域的战况（功放战争的最新结果）：

```
现代甲乙类 + 深度负反馈
    THD+N 做到 0.001% 甚至 0.0001% 级，
    追平甚至超过大多数甲类（0.01-0.1%）
    连现代丁类（Purifi、Hypex，
    高开关频率 + 反馈）也到 0.0005% 级
瓶颈早就不在功放
    扬声器本身 THD 0.5-5%，
    功放的零头比它小一个数量级
    瓶颈在换能器，不在放大器
甲类还剩什么
    理论洁癖（没有交越病灶，
    甲乙类是把病灶压到测不出）
    + 发烧圈信仰（双盲测试分不出）
    + 高端市场（为叙事付电费）
成本结构
    甲类付持续的税：
    每瓦输出付 3-4 瓦电费加散热
    甲乙类付一次性的账：
    反馈、偏置、器件选型的设计成本
```

收口：类别之争的本质是失真与效率的交换比，而交换比由"放大的是信息还是能量"决定。信息选线性，能量选效率。Feelings 的采集是信息（信号域天然甲类，免费自带），刺激也是信息（丙类性格：踢腿的只管踢腿，荡的是身体），只有振动音频是能量（丁类）。四类放大器各管 Feelings 的一段链路，没有哪一类"最近"，只有哪一类管哪一段——而功率域里，甲乙类加深度反馈已经替甲类收了税。

## 反馈——第六章开篇：极性的判断口诀

### 反馈极性判断——端子 × 极性，四象限

反馈信号接入运放的哪个端子、反馈信号的极性，决定了正/负反馈：

```
反馈接入端子        反馈信号极性      结果
─────────────────  ──────────      ──────
反相端（相异端子）    与输入极性相同     负反馈
反相端（相异端子）    与输入极性相反     正反馈
同相端（相同端子）    与输入极性相同     正反馈
同相端（相同端子）    与输入极性相反     负反馈
```

一句话本质：**核心就一句话——反馈如果与输入"相减"就是负反馈，相减来自"反相端"**。

```
运放差分输入：Vout = A×(V+ - V-)
   → 反馈信号进 V-（反相端）→ 增大 V- 就减小 Vout
   → 反馈极性相同（同方向变化）→ 负反馈（减法 → 抵消）
   → 反馈极性相反（反向变化）→ 正反馈（加法 → 增强）
```

注意边界——口诀适用于运放（差分输入）；单管/多级放大器要换"逐级数相位"方法：

```
单管放大器（只有一个输入端子）：
   共射    基极输入、集电极输出——反相（180°）
           反馈到基极 = 反相 → 负反馈
   共集    基极输入、发射极输出——同相
   多级    奇数次反相 = 负反馈路径要多一级
   ——单管靠"级数"判断，不靠"端子"
```

收口：运放版口诀（端子 × 极性四象限）是第六章最实用的判据——反相端是天然减法器，反馈进反相端默认倾向负反馈，反馈信号的极性决定最后是强化还是削弱这个减法。单管版靠逐级相位，后面遇到再展开。

### 电压反馈 vs 电流反馈——采样什么，就稳住什么

极性之外，反馈的第二种分类：采样对象。

```
电压反馈    采样输出电压 → 反馈的是"输出端的电压"
           关注：输出电压的稳定性（稳压、恒压）
           效果：稳定输出电压、降低输出电阻

电流反馈    采样输出电流 → 反馈的是"流过负载的电流"
           关注：输出电流的稳定性（恒流、稳流）
           效果：稳定输出电流、提高输出电阻
```

一句话——**电压反馈管"电压别变"，电流反馈管"电流别变"**。采样点不同，系统"稳住"的对象就不同：

```
电压反馈（采样点 = 输出端电压）
   负载阻抗变了 → 输出电压稳住 → 电流跟着变
   ——"电压当家"（电压源世界观）

电流反馈（采样点 = 输出电流）
   负载阻抗变了 → 输出电流稳住 → 电压跟着变
   ——"电流当家"（电流源世界观）
```

和 Feelings 的对应——两个反馈类型管两条完全不同的命脉：

```
电压反馈 → 恒压应用
   LDO/稳压器：输出电压稳定（AMS1117、TPS7A4700）
   ——笔记里 LDO 就是"采样输出电压做反馈"
   ——关注点：输出电压纹波、负载调整率

电流反馈 → 恒流应用
   tDCS 恒流源：输出电流稳定（0.1-1.5mA 恒定）
   ——微电流源/恒流源就是"采样输出电流做反馈"
   ——关注点：输出电流精度、皮肤阻抗变化时的稳定性
   ——皮肤阻抗变时电流不能变（电流突变 = 刺痛/灼伤）
   ——恒流源防开路打火 = 电流反馈的工程后果：
     负载开路 → 电流反馈拼命推电压 → 电压飙到 12V 钳位轨
     → 所以才有 OVP 稳压管钳位
```

收口：**电压反馈稳电压、电流反馈稳电流——关注点跟着采样点走。** Feelings 里：电源用电压反馈（LDO），刺激用电流反馈（tDCS 恒流）——同一个反馈理论，两个应用方向，各管一条命脉。

#### 电压反馈与电流反馈——互斥，但可分级

电压反馈和电流反馈不能同时取——同一个反馈环只能采样一个对象：

```
为什么不能同时取：
   反馈网络只从"输出端的某一点"取样——
   要么从输出端电压分压（电压反馈）
   要么串在输出回路上采样电流（电流反馈）
   ——取样点只能有一个，不能既并联取电压又串联取电流
   一旦同时取，反馈环变成"电压+电流"混合——
   不再是一个确定的反馈类型——
   输出既想稳电压又想稳电流 = 矛盾目标
```

而"反向"的准确含义——两者对负载阻抗变化的响应方向相反：

```
电压反馈    负载变重（阻抗↓）→ 稳住电压 → 电流上升
            ——电压稳，电流跟着负载走
电流反馈    负载变重（阻抗↓）→ 稳住电流 → 电压下降
            ——电流稳，电压跟着负载走

同一时刻只能选一个"稳住"——
  想稳电压，电流就得让；想稳电流，电压就得让
```

和电源世界两半对应：电压反馈 = 电压当家（电压源世界观），电流反馈 = 电流当家（电流源世界观）——同一个"当家"逻辑，两处都成立。

实际电路可以分时/分级用两个反馈，但不是在同一环里同时取：

```
tDCS 恒流源内部：
   主环：电流反馈（输出恒流）——采样输出电流
   辅助环：电压限制（OVP 钳位）——不是"同时取"，
          是"电流为主、电压兜底"——
          正常时电流环当家，异常时电压环熔断
   ——分级而不是混合
```

收口：电压反馈和电流反馈是同一反馈环的两个互斥选项——选电压就稳电压，选电流就稳电流，不能同时取；但可以分级：一个主环当家，另一个兜底（tDCS 的电流主环 + OVP 电压兜底）。

#### 四种接法的输入侧性格——接法 × 信号源的匹配

并联/串联（输入侧拓扑）与电压/电流（采样对象）正交，共 2×2 = 4 种接法。每种接法配一种信号源，配错 = 反馈失效：

```
接法      采样对象    输入连接    需要的信号源      典型场景
────────────────────────────────────────────────────────
电压串联  输出电压    串联接入    理想电压源        同相放大（跟随器）
电压并联  输出电压    并联接入    电流源/高阻源      反相放大（虚地）
电流串联  输出电流    串联接入    电压源            共基/跨导放大
电流并联  输出电流    并联接入    电流源            电流镜反馈
```

为什么并联负反馈配理想电压源会失效：

```
并联负反馈的输入侧特征：
   反馈网络与输入信号并联接入放大器
   → 输入端的电流被分流（并联 = 电流求和点）
   → 理想情况：输入阻抗趋近于零（虚地）
   → 它天然需要"电流输入"来驱动——
      信号源向虚地点注入电流，反馈网络从虚地点抽电流

理想电压源 + 并联负反馈：
   理想电压源 = 内阻为零 = 强压电压，不在乎分流
   反馈网络想分电流 → 被电压源"短路"掉——
   反馈信号根本进不去——反馈环形同虚设
   → 并联负反馈对理想电压源无效
   → 它需要的是"电流源/高内阻信号源"来驱动

对比：电压串联反馈 + 理想电压源 = 完美匹配
   串联 = 输入端阻抗极高（理想无穷）
   理想电压源驱动高阻输入 = 不拉电流 = 反馈正常
   ——这就是为什么同相放大（电压串联）配电压源
```

关键认知：**"并联"说的是输入端拓扑（电流求和点），"电流"说的是采样对象——两个正交轴。** 并联反馈的输入端是虚地性格（要电流），配理想电压源（不给电流）就是接法 × 源类型不匹配。四种接法各配一种源，这是第六章最容易混、也最实用的输入侧知识。

收口：接法 × 信号源必须匹配——并联反馈需要电流驱动（虚地分流），电压源配电压串联，电流源配并联接法。配错 = 反馈失效。

#### 深度负反馈与虚短虚断——公式多，核心变量就四个

深度负反馈（1+AF >> 1 时）：

```
A_f = A/(1+AF) ≈ A/AF = 1/F
→ 闭环增益只由反馈网络 F 决定，和 A 无关
→ 运放"闭环增益 = Rf/R1"就是这个特例：
   F = R1/(R1+Rf) → 1/F = 1 + Rf/R1 ≈ Rf/R1（当 Rf>>R1）
```

核心变量就四个，其他都是组合：

```
A      开环增益（运放固有，10^5~10^6）
F      反馈系数（反馈网络决定的，电阻比例）
A_f    闭环增益（A_f = A/(1+AF)）
AF     环路增益（A 乘 F，决定反馈深度）

组合出来的：
   1+AF   反馈深度（"负反馈买到的东西"的倍数）
   虚短   净输入 Up-Un ≈ 0（深度负反馈的推论）
   虚断   输入电流 ≈ 0（运放输入阻抗大 + 虚短）
```

虚短必须建立在深度负反馈的条件上：

```
虚短（Up = Un）成立的前提：
   净输入量非常小（Up - Un → 0）
   → 因为 A 极大，输出有限，净输入 = Vout/A → 接近 0
   → 这是"深度负反馈"的必然结果
   → 不是运放的天然属性，是"负反馈把净输入压到接近 0"
   → 没有深度负反馈，就没有虚短
   → 开环运放：Up - Un = Vout/A 不再是 0，虚短失效，
     变回比较器

虚断（输入电流 = 0）：
   运放输入阻抗极大（10^12 欧姆级）
   → 输入端几乎没有电流，天生的，不需要反馈
```

分析运放电路的三步（缺一不可）：

```
① 先确认是负反馈（极性判断四象限）
② 再确认深度（A 大、反馈网络合理）
③ 才能用虚短虚断算闭环增益
```

收口：深度负反馈让 A_f ≈ 1/F，只由反馈网络决定，和 A 无关。虚短（Up=Un）是深度负反馈的推论，不是运放属性，前提是负反馈加反馈深度够。变量看着多，核心就 A、F、A_f、AF 四个，虚短虚断是分析钥匙。

#### 负反馈 = 求导 + 1/(1+AF) 压缩

负反馈的本质就是求导（检测变化量），稳定性提升 1/(1+AF) 倍。

```
负反馈 = 检测变化量（求导）：
   反馈回路采样的不是"信号本身"，是"信号的变化"
   输出变了一点 → 反馈捕捉到 → 反向修正
   本质就是"对输出的变化求导"
   导数 = 变化率 = 反馈在追踪的"偏离"

稳定性提升 1/(1+AF) 倍：
   A_f = A/(1+AF)
   → 开环增益 A 变化 ΔA 时，闭环增益的变化：
   ΔA_f/A_f = (1/(1+AF)) × ΔA/A
   → 增益变化被压缩了 1/(1+AF) 倍
   → 1+AF 越大，A 的波动对 A_f 的影响越小
   → A 从 10^5 变到 10^4（掉 10 倍），
     闭环 A_f 只动 1/(1+AF) 那么点，几乎纹丝不动
```

两个核心思想一句话串起来：

```
求导（检测变化） + 反向修正 = 负反馈的机制
1/(1+AF) 压缩 = 负反馈买到的稳定性
机制是"看变化"，收益是"压变化"
负反馈 = 对变化敏感，对绝对量不敏感
```

"稳定性"的两种含义要区分：

```
① 增益稳定性（参数稳定性）
   A 波动 → A_f 几乎不动（1+AF 倍压缩）
   ——负反馈的四大收益之一

② 系统稳定性（不振荡）
   相移超过 -180° → 负反馈变正反馈 → 自激振荡
   ——稳定性判据，和上面不是一回事——
   ——"相移之和超 -180°"讲的是这个
```

老师把求导说成"偏微分"，是学术化表述，实际就是"对变化的敏感性"，用求导直觉足够。收口：负反馈 = 检测变化量（求导）+ 反向修正，增益稳定性提升 1/(1+AF) 倍。这是负反馈四件套（增益稳/带宽展/失真降/阻抗变）里的第一件。

#### 负反馈改变输出电阻——人造源性格

负反馈改变输出电阻，方向取决于反馈类型：

```
电压反馈（采样输出电压）对输出电阻的影响：
   输出电阻 → 原来的 1/(1+AF)
   → 输出电阻变小
   → 电压反馈想稳住输出电压：
     输出电压要稳 → 输出阻抗要低（电压源性格）
     → 负反馈把输出往"低阻电压源"方向推

电流反馈（采样输出电流）对输出电阻的影响：
   输出电阻 → 原来的 (1+AF) 倍
   → 输出电阻变大
   → 电流反馈想稳住输出电流：
     输出电流要稳 → 输出阻抗要高（电流源性格）
     → 负反馈把输出往"高阻电流源"方向推
```

两个方向是镜像：

```
电压反馈    Rout ↓ (1/(1+AF))   稳电压 → 低阻（电压源性格）
电流反馈    Rout ↑ (1+AF)      稳电流 → 高阻（电流源性格）
负反馈把输出推向"它想稳住那个量的源性格"
   想稳电压 → 变成电压源（低阻）
   想稳电流 → 变成电流源（高阻）
   和"采样什么就稳住什么"完全一致
```

和电流源本体论笔记闭环：

```
之前：电流源 = 高内阻 + 恒定电流（电流源本体论）
现在：电流反馈 = 把输出推向高阻 = 制造"电流源性格"
→ 负反馈是"人造源性格"的机器：
  电压反馈造电压源（低阻），电流反馈造电流源（高阻）
```

收口：电压反馈输出电阻变 1/(1+AF)（变小，电压源性格），电流反馈变 (1+AF) 倍（变大，电流源性格）。负反馈把输出推向"它想稳住那个量的源性格"，和电流源本体论是同一套逻辑的两面。这是负反馈四件套里的第四件（阻抗改变）。

#### 自激振荡与稳定性——级数越多越危险

自激振荡的本质：负反馈在某个频率变成正反馈。

```
自激条件（合起来写就是 AF = -1）：
   某频率下 AF ≥ 1 且 φA + φF = 180°
   → 反馈信号与输入同相且等大
   → 放大器自己补充自己损失的信号
   → 不需要输入，输出自持（自激）
   → 出事几乎是 100%：
     只要该频率满足条件，必然自激：
     微小噪声自己滚雪球：直到饱和
     （输出顶到电源轨）

级数判断：
   单级    最大相移 90°     安全（到不了 180°）
   两级    180° 时 AF<1     安全（相位够但幅度不够）
   三级    最大 270°        危险：级数越多越危险
   （消除方法：破坏两个条件中任一个，
    或两个都破坏）
```

扬声器啸叫 = 正反馈自激的日常例子：音量（放大倍数）调大 → AF 超过 1 → 啸叫，不需要输入信号。

工程判据要补两块：

```
① 相位裕度
   不只判断"会不会自激"（φ=180° 且 AF≥1）：
   要判断"离自激有多远"：
   相位裕度 ≥ 45°（通常 45-60°）才稳：
   接近 180° 就开始有振荡倾向：
   不是"到了 180° 才出事"

② 实时检测比预先计算可靠
   "发现某频率 AF 高"≠"一定会自激"：
   自激要同时满足相位 180° + AF ≥ 1：
   单相位够不一定出事，单 AF 高也不一定：
   更可靠的方式：检测"输出是否出现自激特征"
   （无输入时的振荡、饱和、啸叫）：
   实时检测 > 预先计算
```

分析工具：

```
傅里叶变换      把信号拆成各频率分量（要啥频率有啥频率）
幅频特性        各频率的增益（AF 够不够大）
相频特性        各频率的相移（φ 是否逼近 180°）
判断流程       看相移是否达 180°，还要看该频率的 AF
```

和 Feelings 的对应：上保险：

```
自激风险 → 硬件熔断（安全熔断不依赖软件的模拟端应用）：
   实时检测输出自激特征（振荡/饱和/啸叫）
   → 超过阈值直接熔断/降增益
：和 FPGA 熔断、当量账本、OVP 钳位同一类：
：把"可能自激"变成"可检测→可熔断"：
   但熔断判据要同时看相位和幅度，不能只看幅频
```

收口：自激 = 某频率 AF ≥ 1 且 φA+φF=180°（即 AF=-1），级数越多越危险（三级 270° 封顶），破坏任一条件即消除。工程上留相位裕度（45-60°），实时检测自激特征比预先计算可靠。Feelings 可以上"检测自激特征→熔断"的保险，判据同时看相位和幅度。

## 集成运算放大器——开环是闸，闭环是秤

### 基本概念：开环增益极大，必须负反馈压回线性区

开环增益 A = 10^5 ~ 10^6（2μV × 10^6 = 2V——微伏级直接顶到伏级）。

```
开环运放 = 比较器，不是放大器
   输入 2μV 的噪声就能把输出推到饱和——
   输出被顶死在电源轨（±Vcc）——
   信号进不来，全是噪声放大

线性区的关键 = 负反馈
   闭环增益 = Rf / R1（电阻比例决定，与 A 无关）
   只要 A 足够大（10^5+），闭环增益精确由电阻决定：
   牺牲增益（10^6 → 100），换来精确、稳定、不失真
```

用已有的类别框架理解：

```
开环（无反馈）   丙类性格：增益全开，一碰就饱和
闭环（负反馈）   甲类性格：增益被压，工作在线性区
负反馈买的东西   线性区 + 稳定性 + 带宽 + 失真降低
代价            增益（这是交易，不是损失）
```

### 用途——信号域六大功能

```
① 比例运算     模拟对模拟：加减乘除、积分微分——
               传感器信号调理（差分放大抑制共模）
② 滤波         有源滤波器（低通/高通/带通）——
               噪声里捞信号：PPG 心率、皮电基线
③ 波形整形     比较器/滞回（斯密特触发器）——
               把模拟波形变成事件（R 波检测 = 心跳事件）
④ 波形发生     振荡器（正弦/方波/三角波）——自激产生信号
⑤ 精密整流     信号绝对值化、包络检测——PPG 包络提取
 ⑥ 555 定时器   时间域芯片（定时/振荡/单稳态/PWM）——
                硬件看门狗的经典实现——
                安全熔断不依赖软件原则的 555 版
                （FPGA 能替代，但理解"不用 FPGA 也能定时"）
```

### 反向比例运算电路——虚地推导与反馈类型

第一个具体应用电路。公式：u0 = -(Rf/R1) × Ui。

```
电路结构：
   Ui 经 R1 进反相端（N 点）
   Rf 从输出 u0 反馈回 N 点（反馈网络）
   Rp 接同相端（+）到地
   输出 u0 = -(Rf/R1) × Ui
```

为什么是电压并联负反馈：

```
电压反馈（输出短路法判断）：
   把 u0 短路到地 → Rf 那路没电流了（反馈消失）
   → 反馈依赖 u0 → 电压反馈
并联反馈（求和点判断）：
   N 点是求和节点：输入电流从 R1 进来，
   反馈电流从 Rf 进来，在 N 点汇合（分两路 If 和 IN）
负反馈：
   u0 增大 → 反馈电流增大 → 抵消 → 负反馈
```

虚地推导（三个概念全打通）：

```
虚短：up ≈ un（深度负反馈下两端等电位）
up 接地：Rp 下端接地 → up = 0
→ 虚地：un ≈ up = 0
   （不是 un 天生接地，是虚短 + up=0 推出来的）
虚断：iN ≈ 0（运放输入阻抗极大）
   → 全部电流走 Rf：
   ui 增大 → iF 增大，iN 几乎不变
   → u0 = -Rf × (Ui/R1)
```

Rp 的作用（常见误区纠正）：

```
Rp 不是"制造虚地"的：
   up=0 是因为 Rp 下端接地，不需要运放做任何事
   Rp 真正的两个作用：
   ① 平衡输入偏置电流：
      运放两输入端偏置电流相等，
      反相端看出去的等效电阻 = R1 // Rf，
      让同相端看到同样等效电阻，抵消偏置失调，
      Rp = R1 // Rf
   ② 钉住 up 电位：
      没有 Rp，同相端悬空，噪声漂移，
      Rp 把 up 钉在 0V
```

收口：虚地是"虚短 + up=0"推出来的，不是 Rp 造的；虚断让全部电流走 Rf，于是 u0 = -(Rf/R1)Ui。用输出短路法判断电压反馈、N 点汇合判断并联反馈。这是反馈三概念（虚短/虚断/虚地）在第一个具体电路上的完整落地。

#### 虚短虚断的硬件根源——差分对 + 公共恒流源

虚短为什么成立（虚短 = 负反馈逼出来的）：

```
运放硬件公式：u0 = Aod × (up - un)，Aod ≈ 几十万
→ 输出 u0 有限（在电源轨内）
→ (up - un) = u0/Aod ≈ 0
→ 但只在负反馈闭环时成立：
   开环时 u0 直接饱和（顶到电源轨），
   (up-un) = 饱和值/Aod 不是 0
→ 虚短是"负反馈逼出来的"
→ 没有负反馈，虚短就消失
```

虚断是天生自带的：

```
运放输入阻抗极大（10^12 欧姆级）
→ 输入端几乎没电流
→ 不需要反馈，硬件结构决定的
```

运放输入级的真实结构（差分对）：

```
"+" "-"输入端 = 差分对的两个基极：
   两个三极管基极（一正一反）
   两个发射极连在一起
   接上一个公共恒流源

这解释了虚短虚断的硬件根源：
   虚断：基极电流极小（β 大 + 恒流源限制）
        → 输入端几乎没电流（输入阻抗极大）
   虚短：两管在放大区，Vbe 近似相等
         + 恒流源强制两管射极同电位
         → up ≈ un（虚短的硬件基础）
   差分对 + 公共恒流源 = 虚短的硬件基础
   不是运放"设计成"虚短
   是差分对结构 + 深度负反馈共同逼出来的
```

具体电路要看图：

```
P 接地（Rp 到地）→ up = 0
虚短 → un ≈ up = 0（虚地）
→ 但这是"反相放大"才有虚地（P 接地）
→ 同相放大 P 接信号，un = up = 信号，不是 0
→ "还是要看具体的电路图"
```

完整链条：

```
硬件层   差分对 + 公共恒流源 → 输入阻抗极大（虚断天生）
        + 两基极电位锁定关系（虚短的硬件基础）
闭环层   负反馈 → u0 有限 → (up-un)=u0/Aod≈0 → 虚短成立
        → 没有负反馈，u0 饱和，虚短消失
具体电路  P 接地 → up=0 → un≈0（虚地，仅反相放大成立）
```

收口：虚短 = 差分对结构 + 深度负反馈共同逼出来的，没有负反馈就消失；虚断 = 运放输入阻抗极大的天生属性；up=un=0 是"P 接地"这个具体电路推出来的，反相放大才有虚地，同相放大不是 0。

### 和 Feelings 的对应

```
运放 = Feelings 的耳朵（信号调理）
   生理信号就是微伏级：PPG 光电流、皮电 mV 级、心电 1mV——
   都要先过运放（闭环线性放大）才到 ADC——
   没有线性区，微伏信号只会被放大成饱和噪声——
   AFE（模拟前端）的全部意义：
   闭环运放把微伏信号压进线性区，再交给 ADC 变成数字

555 = Feelings 的保险丝（硬件定时备份）
   万一 FPGA 挂了，一颗 555 做的看门狗
   还能保证"超时熔断"
```

收口：开环是闸（一碰就饱和），闭环是秤（精确称量）。运放学的不是"放大倍数"，是"用负反馈买线性区"这笔交易——而采集链的放大器必须工作在线性区（甲类性格），因为微伏信号经不起饱和。这也闭环了"甲类=采集"的映射：Feelings 的采集链第一站，就是运放的闭环线性化。
