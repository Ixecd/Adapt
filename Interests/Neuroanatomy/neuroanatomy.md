## 神经解剖学

### 一、神经系统总论与发育

#### 发育链条（神经板 → 神经管/神经嵴）

```
外胚层 → 神经板（增厚）
       → 神经沟（内陷）
       → 神经管（沟闭合卷成管）→ 中枢神经系统（脑+脊髓）
       → 神经嵴（沟闭合时背侧缘细胞迁移出去）
                              → 周围神经系统（主要）

神经褶（neural fold）= 神经沟两侧的隆起
    → 神经管的"前体壁"，不是 PNS 来源
神经嵴（neural crest）= 从神经褶背侧缘分离迁移的细胞群
    → 周围神经系统的主要发育原基
       （感觉神经节、自主神经节、施万细胞）
```

#### 对 Feelings 的意义：神经嵴是外周靶点的源头

```
迷走神经耳支、耳大神经的神经元/施万细胞 → 神经嵴来源
神经嵴还分出自主神经节（交感链、副交感节）
→ 理解"为什么 Feelings 刺激的是外周传入、
   交感/副交感走向这么复杂"的根源在神经嵴
→ 外周神经系统 = 神经嵴的分化产物
```

#### 中枢 vs 外周（发育角度）

```
神经管 → CNS（脑 + 脊髓）——深在、被保护，经皮够不到
神经嵴 → PNS（神经节、神经干、末梢）——体表可达
→ Feelings 的刺激靶点全部在外周（PNS）
→ 中枢（CNS）只作为"靶点的上游"被理解，不作为靶点
```

### 二、脊髓——中枢神经系统的低级中枢

#### 为什么"低级中枢"

```
"低级" = 层级低 + 整合程度低 + 处于执行端，不是不重要

① 整合程度最低
   脊髓只做最基础反射（膝跳、缩手）
   刺激 → 感觉 → 脊髓 → 运动，环路全在脊髓内
   → 不需要大脑参与，甚至大脑不知道
② 是"执行终端"
   大脑随意运动指令 → 皮层脊髓束 → 脊髓前角 → 肌肉
   脊髓把"我要动"翻译成"哪块肌肉收缩多强"
   → 脊髓损伤 → 命令传不下去 → 瘫痪
     （大脑还清醒但动不了 = 执行层断）
③ 进化上先出现
   脊髓是底座，大脑皮层是后加盖的顶层

类比：大脑=决策层，脑干/基底节=中层，脊髓=基层执行
```

#### 脊髓截瘫 = 断了长不回来

```
高位截瘫 = 颈段脊髓损伤 → 损伤点以下断联
   ① 物理断裂（纤维束断）
   ② 功能断联（运动命令下不去、感觉传不上来）
   ③ 不可再生（中枢轴突断了基本不重建）

为什么中枢不能再生（对比外周）：
   外周（PNS）：能长 —— 施万细胞提供"导轨"引导再生
   中枢（CNS）：长不回 —— 髓鞘抑制因子（Nogo/MAG）
                      + 胶质瘢痕物理阻挡
                      + 无导轨 + 神经元不分裂
→ 神经嵴（PNS）→ 有再生能力
  神经管（CNS）→ 不可再生
  两个来源，两种命运
```

对 Feelings 的安全含义：

```
刺激外周（迷走/耳大）→ 可逆、可恢复
误伤中枢 → 不可逆、永久
→ 安全设计"宁保守勿激进"的生理依据
→ "凌迟的一帧"要精度不要强度的原因：
  刺激要准不能误伤，因为中枢损伤不可逆
```

#### 神经工程"枢轴"——外部设备接续电信号

```
核心思想（用户推演）：
   截瘫本质 = 电信号传导断了
   → 若能用外部设备当中继，跨过断裂接续信号
   → 恢复功能

真实世界进展：
   ① 脊髓旁路（EPFL Courtine）
      损伤上下电极 + 电子桥，跨断点接续
      灵长类恢复行走 + 人体临床（STIMO）
   ② 脑机接口（Neuralink）
      读运动皮层 → 解码 → 驱动下方
      终极目标 = 旁路脊髓
   ③ 硬膜外电刺激
      不桥接，直接激活下方脊髓的行走程序（CPG）
      → 即使无大脑输入也能驱动行走

本质难点（不是接线，是翻译）：
   神经信号不是通/断，是编码的
   （spike train：频率/时序/空间分布编码意图+力量+精细度）
   外部设备要：解码上游 → 重编码 → 注入下游
   → 是"翻译官"不是"放大器"

边界：
   运动（下行）相对容易 → 已人体实现
   感觉（上行）更难 → 需双向接续
   侵入式（植入）→ 与经皮非侵入不同量级
```

对 Feelings 的层级：

```
Feelings（经皮非侵入）= 添加输入（调节，不动手术）
脊髓旁路（侵入式）= 替代通路（重建，要植入）
→ 共同底层：神经信号本质是电，外部电子设备能与神经"对话"
→ Feelings 是"对话的输入端"，脊髓旁路是"对话的替代通道"
```

### 三、灰质与白质——命名的由来

#### 灰质为什么灰

```
灰质 = 神经元胞体 + 树突 + 毛细血管 + 无髓鞘（或薄髓鞘）纤维

颜色来源：
    神经元胞体密集 → 没有"白色髓鞘"覆盖
    → 暴露细胞体的本色：灰粉/灰红
    （毛细血管丰富、代谢高，带血色）
→ 灰质是"胞体的颜色"，名字字面真实
```

#### 白质为什么白

```
白质 = 有髓鞘的轴突（神经纤维束）
    髓鞘 = 脂质（脂肪），天然白色
    → 像电线的白色绝缘皮
→ 白质白 = 髓鞘的白

对比：
    灰质 = 胞体（灰，无髓鞘覆盖）
    白质 = 轴突 + 髓鞘（白）
→ 颜色差异来自"有没有髓鞘"
```

#### "软糯"是误会

```
软糯是脑组织共性（含水多，像果冻/豆腐脑），不是灰质独有
→ 命名原因是"颜色"，不是"质地"
  灰质叫灰因为它灰，白质叫白因为它白
```

#### 有用的延伸

```
灰质 = 处理（胞体 = 计算单元，CPU）
白质 = 传导（髓鞘化轴突 = 线路，总线）
→ 切面一眼分辨：外圈灰（皮层）+ 里面白（传导束）
→ 中枢的"灰=算、白=传"是理解神经通路的基础
```

对 Feelings 的意义：

```
外周神经（迷走/耳大）本质是"白质的延伸"（轴突为主）
   → 有髓/无髓混合的纤维束
   → 刺激的是"传导"（白质性格），不是"计算"（灰质）
→ 理解灰白之分：
   中枢里灰质做处理、白质做传导
   外周全是"传导线"（轴突）
   → Feelings 刺激的是"线"，不是"CPU"
   → 刺激改变的是信号的传导/发放，
     不是直接改写大脑的"计算"
```

### 四、脑泡发育——神经管头端的膨大

#### 三个脑泡 → 五个脑泡

```
神经管头端膨大（形态像精子：头大身细）：
    前脑泡 → 端脑 + 间脑
    中脑泡 → 中脑
    菱脑泡 → 后脑 + 末脑
              ↓
    后脑 → 脑桥 + 小脑
    末脑 → 延髓
    后面细长的管 → 脊髓

名字记忆：
    菱脑泡 = rhomb 菱形（英文 rhombus），不是"零"脑泡
    端脑 = 在头端，间脑 = 在中间
```

#### 小脑的位置

```
小脑附着在脑干的背面（背侧）
    → 脑干后面、枕叶下方
    → 由菱脑泡的后脑发育而来
    → 与脑桥/延髓在同一发育段
→ 小脑不是独立大脑结构，是"脑干背面的附属"
  （所以叫"小脑"= 脑的背面小体）
```

#### 对 Feelings 的意义

```
迷走神经的起源：
    迷走是"延髓"发出（末脑/菱脑泡产物）
    孤束核（NTS）、迷走背核都在延髓
→ 前脑泡管高级（端脑/间脑 = 意识/情绪/内感受）
  菱脑泡管脑干基础（延髓 = 迷走的起源地）
→ 迷走从"低级脑干"出发，却调节"高级"的情绪/自主
  这个"低级脑干 → 高级功能"的反差，
  正是 tVNS 能影响情绪的原因之一
→ 小脑在脑干背面（附着位置）：
   与迷走通路同段发育，但小脑管协调/平衡，
   不是迷走靶点，了解位置即可
```

### 五、十二对脑神经

#### 分组记忆

```
感觉性（纯传入）：
    Ⅰ 嗅神经（嗅觉）
    Ⅱ 视神经（视觉）
    Ⅷ 位听神经（听觉/平衡）—— 耳部神经

运动性（纯传出）：
    Ⅲ 动眼、Ⅳ 滑车、Ⅵ 外展（眼球运动）
    Ⅺ 副神经（胸锁乳突肌/斜方肌）
    Ⅻ 舌下（舌肌）

混合性（感觉 + 运动）：
    Ⅴ 三叉（面部感觉 + 咀嚼）
    Ⅶ 面（面部表情 + 味觉）
    Ⅸ 舌咽（咽部 + 味觉 + 唾液）
    Ⅹ 迷走（咽/喉/内脏 + 自主神经）—— Feelings 靶点

记忆锚点：
    1-2 头部的"管"（嗅/视）
    3-4-6 管眼球（动眼/滑车/外展）
    5-7-9-10 混合型（面/咽/内脏）
    8 耳部（位听）
    11-12 颈部/舌（副/舌下）

口诀：一嗅二视三动眼，四滑五叉六外展，
      七面八听九舌咽，迷走副神舌下全。
```

#### 对 Feelings 的关键点

```
X 迷走（靶点）：
    混合性 + 自主神经
    运动纤维（咽/喉肌）
    感觉纤维（耳支 Arnold → 刺激的就是它）
    副交感纤维（支配心/肺/胃肠）
    → "管内脏 + 管耳朵"：
      耳支是迷走伸到体表的部分
      刺激耳支 = 刺激整条迷走的传入
    → 这就是 tVNS 的解剖基础

IX 舌咽（兄弟神经）：
    与迷走相邻、功能相似（咽部感觉 + 副交感）
    → tVNS 文献：耳支与舌咽支相邻，刺激可能同时涉及

Ⅷ 位听（耳部相关但注意区分）：
    管听觉/平衡，不是迷走靶点
    → 耳朵里有两种神经：
      位听（听）+ 迷走耳支（内脏传入）
      别混淆
```

### 六、耳大神经——体表辅助 vs 迷走主功能

#### 耳大神经的分叉

```
耳大神经（颈丛 C2/C3 分支）
    绕胸锁乳突肌后缘上行 → 耳垂下方 → 分叉：

    前支 → 耳垂下方、耳前/面下部皮肤
    后支 → 耳廓背面、耳后乳突区皮肤
→ 支配耳廓及周围皮肤感觉（皮肤感觉神经，非深部）
```

对电极设计：

```
① 覆盖两个分支：
   耳背电极（后支区）+ 耳垂下方电极（前支区）
   挂耳只贴耳背 = 只刺激后支
   想全覆盖 → 电极沿耳廓背面 + 耳垂下缘分布
② 个体变异：分叉位置/粗细因人而异 → 逐人校准
```

#### 耳大 vs 迷走——辅助 vs 主功能

```
耳大神经（辅助，体表感觉）：
    感受：耳垂、耳下脖子发麻刺痛
    纯皮肤感觉（C2-C3），无内脏传入，不直达 NTS
    作用：体表触觉/存在感，辅助体验
    → "手能摸到的东西"，有感觉

迷走耳支（主功能，内脏传入）：
    感受：可能无明显感觉（或轻微）
    直通孤束核（NTS）→ 蓝斑/自主神经
    作用：调节情绪/自主/免疫（深度）
    → "手摸不到的东西"，没感觉但变化

关键区分：
    迷走刺激没体感 ≠ 没效果
    耳大刺激有体感 ≠ 深度调节
    "有感觉"和"有效果"是两回事
```

#### 对 Feelings 的分工

```
耳大神经 = 辅助/体验层
    体表触觉、存在感、陪伴感
    → 让用户"感觉到"设备在工作
    提升体验，不是深度调节

迷走耳支 = 主功能/深度层
    自主神经/情绪/免疫调节
    → 让用户"变化"（心率/状态/睡眠）
    主功能，核心价值

设计权重：
    迷走 = 疗效，耳大 = 体验，主次分明
    迷走电极（耳甲）是心脏，耳大电极（耳后/耳垂）是点缀
```
