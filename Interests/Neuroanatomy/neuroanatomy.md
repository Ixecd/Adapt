## 神经解剖学

### 一、神经系统总论与发育

#### 发育链条（神经板 → 神经管/神经嵴）

```
外胚层 → 神经板（增厚）
       → 神经沟（内陷）
       → 神经管（沟闭合卷成管）→ 中枢神经系统（脑+脊髓）
       → 神经嵴（沟闭合时背侧缘细胞迁移出去）
                              → 周围神经系统（主要）

神经褶（neural fold）= 神经沟两侧的隆起
    → 神经管的"前体壁"，不是 PNS 来源
神经嵴（neural crest）= 从神经褶背侧缘分离迁移的细胞群
    → 周围神经系统的主要发育原基
       （感觉神经节、自主神经节、施万细胞）
```

#### 对 Feelings 的意义：神经嵴是外周靶点的源头

```
迷走神经耳支、耳大神经的神经元/施万细胞 → 神经嵴来源
神经嵴还分出自主神经节（交感链、副交感节）
→ 理解"为什么 Feelings 刺激的是外周传入、
   交感/副交感走向这么复杂"的根源在神经嵴
→ 外周神经系统 = 神经嵴的分化产物
```

#### 中枢 vs 外周（发育角度）

```
神经管 → CNS（脑 + 脊髓）——深在、被保护，经皮够不到
神经嵴 → PNS（神经节、神经干、末梢）——体表可达
→ Feelings 的刺激靶点全部在外周（PNS）
→ 中枢（CNS）只作为"靶点的上游"被理解，不作为靶点
```

### 二、脊髓——中枢神经系统的低级中枢

#### 为什么"低级中枢"

```
"低级" = 层级低 + 整合程度低 + 处于执行端，不是不重要

① 整合程度最低
   脊髓只做最基础反射（膝跳、缩手）
   刺激 → 感觉 → 脊髓 → 运动，环路全在脊髓内
   → 不需要大脑参与，甚至大脑不知道
② 是"执行终端"
   大脑随意运动指令 → 皮层脊髓束 → 脊髓前角 → 肌肉
   脊髓把"我要动"翻译成"哪块肌肉收缩多强"
   → 脊髓损伤 → 命令传不下去 → 瘫痪
     （大脑还清醒但动不了 = 执行层断）
③ 进化上先出现
   脊髓是底座，大脑皮层是后加盖的顶层

类比：大脑=决策层，脑干/基底节=中层，脊髓=基层执行
```

#### 脊髓截瘫 = 断了长不回来

```
高位截瘫 = 颈段脊髓损伤 → 损伤点以下断联
   ① 物理断裂（纤维束断）
   ② 功能断联（运动命令下不去、感觉传不上来）
   ③ 不可再生（中枢轴突断了基本不重建）

为什么中枢不能再生（对比外周）：
   外周（PNS）：能长 —— 施万细胞提供"导轨"引导再生
   中枢（CNS）：长不回 —— 髓鞘抑制因子（Nogo/MAG）
                      + 胶质瘢痕物理阻挡
                      + 无导轨 + 神经元不分裂
→ 神经嵴（PNS）→ 有再生能力
  神经管（CNS）→ 不可再生
  两个来源，两种命运
```

对 Feelings 的安全含义：

```
刺激外周（迷走/耳大）→ 可逆、可恢复
误伤中枢 → 不可逆、永久
→ 安全设计"宁保守勿激进"的生理依据
→ "凌迟的一帧"要精度不要强度的原因：
  刺激要准不能误伤，因为中枢损伤不可逆
```

#### 神经工程"枢轴"——外部设备接续电信号

```
核心思想（用户推演）：
   截瘫本质 = 电信号传导断了
   → 若能用外部设备当中继，跨过断裂接续信号
   → 恢复功能

真实世界进展：
   ① 脊髓旁路（EPFL Courtine）
      损伤上下电极 + 电子桥，跨断点接续
      灵长类恢复行走 + 人体临床（STIMO）
   ② 脑机接口（Neuralink）
      读运动皮层 → 解码 → 驱动下方
      终极目标 = 旁路脊髓
   ③ 硬膜外电刺激
      不桥接，直接激活下方脊髓的行走程序（CPG）
      → 即使无大脑输入也能驱动行走

本质难点（不是接线，是翻译）：
   神经信号不是通/断，是编码的
   （spike train：频率/时序/空间分布编码意图+力量+精细度）
   外部设备要：解码上游 → 重编码 → 注入下游
   → 是"翻译官"不是"放大器"

边界：
   运动（下行）相对容易 → 已人体实现
   感觉（上行）更难 → 需双向接续
   侵入式（植入）→ 与经皮非侵入不同量级
```

对 Feelings 的层级：

```
Feelings（经皮非侵入）= 添加输入（调节，不动手术）
脊髓旁路（侵入式）= 替代通路（重建，要植入）
→ 共同底层：神经信号本质是电，外部电子设备能与神经"对话"
→ Feelings 是"对话的输入端"，脊髓旁路是"对话的替代通道"
```
