## 生理学

### 内环境稳态——全部内容的中心主题

生理学的全部内容，都在回答一个问题：内环境稳态怎么维持。

```
内环境（细胞外液）
    细胞的直接生活环境
    细胞不与外界直接接触
    一切交换都通过细胞外液完成
    营养进来，废物出去，全走内环境
```

### 各系统围绕稳态的分工

```
消化系统    物质入口
            食物 → 营养 → 进血液
呼吸系统    气体入口
            O2 进，CO2 出
泌尿系统    物质出口 + 精细调节
            代谢废物排出
            水、电解质、酸碱平衡
循环系统    运输总线
            心脏血管血液
            把营养和 O2 运给细胞
            把废物运到泌尿和呼吸
细胞        消费者
            从内环境取能量，排代谢废物
神经系统    协调中枢
            检测偏差，发出调节指令
内分泌      体液调节
            激素，另一套慢调节系统
```

循环系统 = 心血管系统（心脏+血管+血液），是运输总线。泌尿和呼吸是物质出入口，组织液是内环境的一部分。

### 稳态 = 负反馈（与模电同构）

```
稳态 = 生理版的负反馈
    设定点（体温 37°C，血糖 5mmol/L）
    检测偏差（感受器）
    纠偏（效应器）

就是模电里的：
    Q 点稳定（Re 负反馈拉回漂移）
    勒夏特列原理（系统抵抗扰动）
    恒温器（设定点 + 偏差 + 纠偏）

体系咬合：
    神经系统 = 等控器（偏差检测 + 纠偏中心）
    内环境 = 服务器环境
    稳态 = 服务器保持稳定运行
    各系统 = 维持稳定运行的服务
```

### 骨骼肌与内环境——客户关系

骨骼肌不是直接调节器官（不像肾直接管水电解质、肺直接管气体），但它有三个真实关系：

```
① 产热执行器（体温稳态的关键）
    人体最大的产热器官
    安静时占产热约 20%，运动时占 90%
    寒冷时战栗产热（不随意收缩）
    体温稳态的最重要效应器

② 代谢负担源（内环境的压力来源）
    最大的葡萄糖和氧气消耗组织
    运动时产生大量 CO2、热、乳酸
    全倒进内环境
    让呼吸、循环、泌尿忙起来
    内环境最大的客户，消耗最多，排放最多

③ 肌肉泵（循环的辅助）
    骨骼肌收缩挤压静脉，促进静脉回流
    维持心输出量的前负荷
    长期卧床肌肉萎缩的人，循环也变差
```

骨骼肌的精确位置：不是调节器，是效应器 + 扰动源。

```
调节器（管稳态的）    神经系统、内分泌
                     （检测偏差，发指令）

效应器（执行指令的）  骨骼肌、平滑肌、腺体
                     （产热、运动、分泌）

扰动源（给稳态加压的） 骨骼肌运动时的代谢产物
                     （CO2、热、乳酸，
                     倒进内环境让各系统忙起来）
```

收口：骨骼肌不维护内环境，但它是内环境最大的消费者、最大的产热器、最大的扰动源。客户不修水管，但客户用水量决定修水管的人忙不忙。

### 稳态的相对性——稳定是相对的，水平是可变的

```
稳态不是"绝对固定"，是"相对稳定"
    内环境的理化性质不是固定值
    是在一定范围内波动（正常值范围）
    血糖 3.9-6.1 mmol/L，不是钉死在 5.0

稳定的水平是可变的（设定点可变）
    发热：体温设定点上移
    （下丘脑把设定点调高，
    发热是设定点变了，不是调节失灵）
    运动训练：静息心率下降
    （心血管设定点长期下移）
    适应海拔：红细胞增多
    （氧运输的设定点重设）

正确理解：
    不是"不变"
    是"在设定点附近的小范围波动
    + 设定点本身可移动"
    相对稳定 = 围绕设定点稳
    水平可变 = 设定点可以重设
```

与模电同构：

```
Q 点稳定不是 Q 点不动
    是 Q 点在温度范围内不漂
    但 Q 点本身可以重新设定
    （换偏置电阻 = 换设定点）

稳态同构：
    围绕设定点稳定（负反馈拉回偏差）
    设定点可以重设（适应、发育、疾病）
    两个层次：稳定性 + 可调性
    （对应 Feelings 的基线：
    基线不是永久不变，
    基线可以漂移更新，
    周内波动是正常漂移，
    持续变化是基线更新）
```

### 正反馈的分类——爆发型与渐进型

```
正反馈分两种

爆发型（推到底）
    排尿、分娩、动作电位、凝血
    快速推到终点，一次性完成
    级联放大，不收敛

渐进型（推到平台）
    专注、平静、心流
    缓慢自我强化，推到一个平台饱和
    专注不能无限深，平静不能无限静
    有上限，饱和后停止强化
```

专注与平静的正反馈环：

```
专注环    投入 → 效率 → 成就感 → 更投入
          （心流就是这条环）

平静环    放松 → 副交感激活 → 更平静 → 更深放松
          （冥想就是这条环）

静默的位置
    达到目标 → 静默 → 身体自己维持平静
    → 更深平静（正反馈环还在转，
    只是不需要设备再推）
    静默不是"没反馈"，
    是"反馈环由身体自己接管"
```

### 成瘾——正反馈的失控版

```
成瘾螺旋
    奖赏刺激 → 多巴胺 → 追求更多刺激
    → 耐受 → 需要更强刺激 → 更追求
    → 螺旋加深，停不下来
    （阈值递增、欲望的阶梯，
    全是这条失控环）
```

Feelings 防作弊的防线：

```
漏桶（不应期）     能量记账，超限保护，
                   不能连续"一直爽"
耐受轮换          同一靶点效果衰减，自动轮换，
                   单点成瘾路径被切断
0 输出设计        专注时不打扰，静默是设计状态，
                   不给持续刺激的默认通道
强度红线          高强度刺激被硬件上限卡死
反依赖哲学        终点是用户不再需要它，
                   不是让用户离不开
分级模式          消费级保守默认参数，
                   激进参数不开放
架构僭越红线      绕过安全层改参数 = 最重违规
```

收口：正反馈的合法用途只有两种：爆发型（一次性过程，推到终点）和渐进型（有限平台，推到饱和）。非法用途是失控螺旋（成瘾，停不下来）。Feelings 对正反馈的态度是关在笼子里：该爆的爆（凌迟的一帧），该平的平（专注平静的平台），该拦的拦（漏桶不应期、耐受轮换、0 输出、红线）。
