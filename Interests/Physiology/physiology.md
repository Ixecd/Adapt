## 生理学

### 内环境稳态——全部内容的中心主题

生理学的全部内容，都在回答一个问题：内环境稳态怎么维持。

```
内环境（细胞外液）
    细胞的直接生活环境
    细胞不与外界直接接触
    一切交换都通过细胞外液完成
    营养进来，废物出去，全走内环境
```

### 各系统围绕稳态的分工

```
消化系统    物质入口
            食物 → 营养 → 进血液
呼吸系统    气体入口
            O2 进，CO2 出
泌尿系统    物质出口 + 精细调节
            代谢废物排出
            水、电解质、酸碱平衡
循环系统    运输总线
            心脏血管血液
            把营养和 O2 运给细胞
            把废物运到泌尿和呼吸
细胞        消费者
            从内环境取能量，排代谢废物
神经系统    协调中枢
            检测偏差，发出调节指令
内分泌      体液调节
            激素，另一套慢调节系统
```

循环系统 = 心血管系统（心脏+血管+血液），是运输总线。泌尿和呼吸是物质出入口，组织液是内环境的一部分。

### 稳态 = 负反馈（与模电同构）

```
稳态 = 生理版的负反馈
    设定点（体温 37°C，血糖 5mmol/L）
    检测偏差（感受器）
    纠偏（效应器）

就是模电里的：
    Q 点稳定（Re 负反馈拉回漂移）
    勒夏特列原理（系统抵抗扰动）
    恒温器（设定点 + 偏差 + 纠偏）

体系咬合：
    神经系统 = 等控器（偏差检测 + 纠偏中心）
    内环境 = 服务器环境
    稳态 = 服务器保持稳定运行
    各系统 = 维持稳定运行的服务
```

### 骨骼肌与内环境——客户关系

骨骼肌不是直接调节器官（不像肾直接管水电解质、肺直接管气体），但它有三个真实关系：

```
① 产热执行器（体温稳态的关键）
    人体最大的产热器官
    安静时占产热约 20%，运动时占 90%
    寒冷时战栗产热（不随意收缩）
    体温稳态的最重要效应器

② 代谢负担源（内环境的压力来源）
    最大的葡萄糖和氧气消耗组织
    运动时产生大量 CO2、热、乳酸
    全倒进内环境
    让呼吸、循环、泌尿忙起来
    内环境最大的客户，消耗最多，排放最多

③ 肌肉泵（循环的辅助）
    骨骼肌收缩挤压静脉，促进静脉回流
    维持心输出量的前负荷
    长期卧床肌肉萎缩的人，循环也变差
```

骨骼肌的精确位置：不是调节器，是效应器 + 扰动源。

```
调节器（管稳态的）    神经系统、内分泌
                     （检测偏差，发指令）

效应器（执行指令的）  骨骼肌、平滑肌、腺体
                     （产热、运动、分泌）

扰动源（给稳态加压的） 骨骼肌运动时的代谢产物
                     （CO2、热、乳酸，
                     倒进内环境让各系统忙起来）
```

收口：骨骼肌不维护内环境，但它是内环境最大的消费者、最大的产热器、最大的扰动源。客户不修水管，但客户用水量决定修水管的人忙不忙。

### 稳态的相对性——稳定是相对的，水平是可变的

```
稳态不是"绝对固定"，是"相对稳定"
    内环境的理化性质不是固定值
    是在一定范围内波动（正常值范围）
    血糖 3.9-6.1 mmol/L，不是钉死在 5.0

稳定的水平是可变的（设定点可变）
    发热：体温设定点上移
    （下丘脑把设定点调高，
    发热是设定点变了，不是调节失灵）
    运动训练：静息心率下降
    （心血管设定点长期下移）
    适应海拔：红细胞增多
    （氧运输的设定点重设）

正确理解：
    不是"不变"
    是"在设定点附近的小范围波动
    + 设定点本身可移动"
    相对稳定 = 围绕设定点稳
    水平可变 = 设定点可以重设
```

与模电同构：

```
Q 点稳定不是 Q 点不动
    是 Q 点在温度范围内不漂
    但 Q 点本身可以重新设定
    （换偏置电阻 = 换设定点）

稳态同构：
    围绕设定点稳定（负反馈拉回偏差）
    设定点可以重设（适应、发育、疾病）
    两个层次：稳定性 + 可调性
    （对应 Feelings 的基线：
    基线不是永久不变，
    基线可以漂移更新，
    周内波动是正常漂移，
    持续变化是基线更新）
```

### 正反馈的分类——爆发型与渐进型

```
正反馈分两种

爆发型（推到底）
    排尿、分娩、动作电位、凝血
    快速推到终点，一次性完成
    级联放大，不收敛

渐进型（推到平台）
    专注、平静、心流
    缓慢自我强化，推到一个平台饱和
    专注不能无限深，平静不能无限静
    有上限，饱和后停止强化
```

专注与平静的正反馈环：

```
专注环    投入 → 效率 → 成就感 → 更投入
          （心流就是这条环）

平静环    放松 → 副交感激活 → 更平静 → 更深放松
          （冥想就是这条环）

静默的位置
    达到目标 → 静默 → 身体自己维持平静
    → 更深平静（正反馈环还在转，
    只是不需要设备再推）
    静默不是"没反馈"，
    是"反馈环由身体自己接管"
```

### 成瘾——正反馈的失控版

```
成瘾螺旋
    奖赏刺激 → 多巴胺 → 追求更多刺激
    → 耐受 → 需要更强刺激 → 更追求
    → 螺旋加深，停不下来
    （阈值递增、欲望的阶梯，
    全是这条失控环）
```

Feelings 防作弊的防线：

```
漏桶（不应期）     能量记账，超限保护，
                   不能连续"一直爽"
耐受轮换          同一靶点效果衰减，自动轮换，
                   单点成瘾路径被切断
0 输出设计        专注时不打扰，静默是设计状态，
                   不给持续刺激的默认通道
强度红线          高强度刺激被硬件上限卡死
反依赖哲学        终点是用户不再需要它，
                   不是让用户离不开
分级模式          消费级保守默认参数，
                   激进参数不开放
架构僭越红线      绕过安全层改参数 = 最重违规
```

收口：正反馈的合法用途只有两种：爆发型（一次性过程，推到终点）和渐进型（有限平台，推到饱和）。非法用途是失控螺旋（成瘾，停不下来）。Feelings 对正反馈的态度是关在笼子里：该爆的爆（凌迟的一帧），该平的平（专注平静的平台），该拦的拦（漏桶不应期、耐受轮换、0 输出、红线）。

### 排尿正反馈——启动后可中止性差的完整案例

排尿的正反馈环：

```
膀胱充盈 → 牵张感受器 → 骶髓排尿中枢
→ 逼尿肌收缩 → 内括约肌开 → 尿流
→ 尿流刺激尿道感受器（正反馈入口）
→ 逼尿肌更强收缩 → 完全排空
```

两个阶段的控制力完全不同：

```
启动前（憋尿）   皮层按住骶髓，可以维持
                  （"现在不方便"，忍得住）
                  = 意志的战场

启动后（排尿中） 正反馈接管，很难中止
                  （"尿到一半憋回去"，非常难受）
                  = 反射的洪流

分界线：尿流开始的那一刻
```

憋尿场景的产品案例（用户声明的接地气用法）：

```
场景    用户戴着 Feelings 憋尿，
        深度放松刺激会导致括约肌松弛，
        憋尿难度上升

解法    用户声明："我在憋尿，别乱搞"
        教练收到，调整策略：
        该场景不给深度放松帧，或者静默

设计验证
    身体状态（膀胱充盈）设备测不到
    （没有膀胱传感器）
    但用户知道，一句话补齐
    "测得到的靠传感器，测不到的靠嘴"
    用户声明 = 状态机的第一触发源
```

与 Feelings 的同构（正反馈的共性）：

```
凌迟的一帧（激素级联）
    一帧点火 → 皮质醇全喷 → 化学潮
    刹车在半衰期手里，信号切断了激素照烧
    启动后可中止性差，和排尿同构

正反馈的使用纪律
    要么别启动（确保不误触发）
    要么启动了让它跑完（别试图拦）

产品启示
    点火权必须是最重的权
    漏桶（引爆要节制）
    不应期（不能连续触发）
    红线（强度上限卡死误触发）
    脆弱帧不注入（状态不对不点火）
    ——全是为了"正反馈只在该爆的时候爆"
```

### 稳态 = spec = desired state——三层统一

```
稳态 = spec = desired state
    不是恒等，是区间
    （血糖 3.9-6.1，不是钉死 5.0）
    设定点可重设

负反馈 = 维持 spec（拉回区间）
正反馈 = 破坏 spec（推动过程完成）
```

三层的完整对应：

```
生理层
    spec     稳态（设定点）
    谁设     进化设的（基因）
    维持     负反馈（设定点+检测+纠偏）
    改变     正反馈（过程触发），设定点重设（适应）

Feelings 层
    spec     用户的基线（desired state）
    谁设     用户设（和教练沟通，声明）
    维持     闭环校准（反复逼近基线）
    改变     刺激（凌迟的一帧，级联引爆）

治理层
    spec     合约（底线 = 不可协商的 spec）
    谁设     独裁者 + 用户（底线不可协商，
             补充合约可叠加）
    维持     每帧校准（水位维护，信任额度）
    改变     修订（防滑坡流程），申诉失败（标签叠加降级）
```

关键：用户能和教练沟通设置 spec。这是感受主权的 K8s 版本：你的身体，你的 desired state，你有权声明它。身体给不了你定义稳态的权利（spec 是进化焊的），Feelings 能给你（用户声明，教练执行）。合约和补充合约，就是把对稳态的定义权写进系统的方式。

### 滞后性的控制心法——让子弹飞一会

滞后性系统的正确姿势，三段：

```
打之前（瞄得准）
    采集够准，判断到位
    时机对（脆弱帧不注入的敬畏）
    子弹打出去之前，一切把握都在这一瞄里

打出去（不犹豫）
    刺激给了，级联启动了
    引爆帧负责精确触发，一帧就是引爆

飞的时候（不慌）
    不急着反应，不急着纠偏
    剩下的交给时间
    化学潮的刹车不由信号管，
    由肝脏的代谢速度管（半衰期自己烧）

命中的时候（再决定）
    效果出现了，生理响应出来了
    评估，然后决定下一步
    等命中，再开下一枪
```

两种做法的对比：

```
急反应（滞后期内反复纠偏）
    子弹还没飞到，手就抖
    反复调整 = 振荡 = 过山车
    （波动性，用户感觉被调而不是被稳）

让子弹飞（等命中再动）
    打之前想清楚，打之后有耐心
    滞后期是"系统自己跑"的时间
    稳定，不打扰（静默）
```

与体系的咬合：

```
凌迟的一帧    引爆帧精确触发，一帧就是引爆
              化学潮的刹车不由信号管
              引爆后交给时间，等烧完再评估
漏桶不应期    刺激后进入不应期
              不应期就是"让子弹飞"的时间
              等生理响应完成，再考虑下一次
每帧校准的修正  校准节奏由生理滞后决定
              不是由采样帧率决定
              打一枪，等命中，评估，再打下一枪
              不是每帧都在打枪
静默（0 输出）  子弹在飞的时候，系统安静
              不打扰，等效果
```

收口：打之前瞄得准，打之后有耐心。子弹在飞的时候手不要抖（急纠偏必振荡），命中的时候再决定下一枪（等效果再评估）。采集够准是前提：瞄得准才敢让子弹飞，瞄不准的人才会慌，慌了才在滞后期内乱调，乱调才会振荡。

### 前馈——负反馈滞后性的解药

```
前馈 vs 负反馈

负反馈（事后纠偏）
    偏差出现 → 检测 → 纠偏
    慢，但精确
    问题：滞后（等偏差出现才动）

前馈（事前预调）
    干扰预期 → 预先调整
    快，但可能不准（预测有误差）
    解决：滞后（不等偏差，提前动）
```

热身就是前馈的日常案例：

```
比赛前热身（前馈）
    比赛还没开始
    身体预先进入状态
    体温升高、心率加快、肌肉激活
    正式比赛时身体已经就位
    不需要起跑时才启动

生理前馈（同一结构）
    看到食物 → 唾液和胃液提前分泌
    运动前 → 心率呼吸提前加快
    巴甫洛夫的狗 → 铃声 → 唾液
    （条件反射 = 前馈）
```

前馈 + 负反馈的组合：

```
前馈管预计（热身）
    干扰还没来，先调
    快，但不准

负反馈管纠偏（临场调整）
    偏差出现了，再修
    慢，但精确

组合 = 热身 + 临场调整
    热身让起跑就快
    临场调整应对意外
    一个管大概，一个管精确
```

与 Feelings 的咬合：

```
场景切换的预调节（前馈）
    用户声明"我要开会了"
    教练预调，进入前把状态调到位
    而不是开会时状态不对再纠偏

睡前的预热（前馈）
    睡前预调节，帮助入睡
    而不是躺下睡不着再调

让子弹飞的瞄（前馈）
    打之前瞄得准 = 前馈（提前判断）
    打之后等命中 = 负反馈（看结果）
```

收口：控制三件套：前馈先调（热身，快但不准），负反馈精修（临场，慢但准），让子弹飞（等待，不慌）。对应 Feelings：场景切换预调节（前馈）、闭环校准（负反馈）、滞后期静默（等待）。

### 细胞膜受体——四大家族与感受器的分子基础

```
受体四大家族（按机制分）

① 离子通道型受体
    配体结合 → 通道打开 → 离子流
    毫秒级，最快
    神经递质大多走这里
    （烟碱型乙酰胆碱、GABA、
    谷氨酸受体）

② G 蛋白偶联受体（GPCR）
    最大一族，人体 800+ 种
    配体结合 → 激活 G 蛋白
    → 第二信使（cAMP、钙）级联放大
    （肾上腺素、多巴胺、
    5-羟色胺、嗅觉受体）

③ 酶联受体
    胞内端自带酶活性（激酶）
    结合后磷酸化级联
    （胰岛素、生长因子、
    BDNF 的受体 TrkB）

④ 内吞受体
    结合后把配体吞进细胞
    （低密度脂蛋白受体）
```

受体 vs 感受器（两个词的区分）：

```
受体    分子层面的膜蛋白
        结合特定配体（激素、
        神经递质、生长因子）

感受器  结构或细胞层面
        （触觉小体、感光细胞）

感受器的分子基础
    恰恰就是膜上的受体和通道：
    热/辣椒素   TRPV1 通道
    冷/薄荷     TRPM8 通道
    触觉        Piezo 通道（2021 诺奖）
    嗅觉        400 种 GPCR
    甜/苦/鲜    GPCR
    光          视紫红质（GPCR）
    ——感受器 = 特化配置过的
    膜受体
```

Feelings 咬合：膜的分子机器就是 Feelings 信号的入口和出口。电刺激作用的是神经纤维上的电压门控离子通道（膜蛋白），采集到的生物电本质是离子通道开闭产生的电流（也是膜蛋白）。同构里"受体 = Admission Webhook"，落到分子上，执行准入控制的就是这些膜蛋白本身。

### 酶——催化剂的三个性质

```
酶的本质（绝大多数是蛋白质）

① 催化剂
    加速反应，不被消耗
    做完还是原来的酶，反复用
    只加速到达平衡，不改变平衡点

② 专一性
    只认特定底物（锁钥模型）
    一个酶一个活

③ 可调控
    磷酸化开关、抑制剂
    活性可开可关

限速酶
    一条通路里最慢的那个酶
    决定整条通路的速度
    ——代谢通路 = 酶级联
    （A 转 B 再转 C）
```

与 K8s 的同构：酶 = 插件/Webhook 这类专一转换器。常驻不消耗（做完还是它自己）、专一（只认特定资源类型）、可开关（webhook 配置）。限速酶 = 瓶颈组件（API server 限流决定集群收敛速度）。

### 神经肌肉接头与口服补剂——指令与原料的分野

运动神经末梢释放的乙酰胆碱（ACh）和市面口服的"乙酰胆碱补剂"，名字一样，机制完全不同：一个是指令，一个是原料，甚至原料都不是 ACh 本身。

```
突触 ACh（指令）
    运动神经元末梢释放 → 结合肌膜烟碱型受体（离子通道型）
    → 通道直接打开 → 去极化 → 肌肉收缩
    毫秒级，点对点
    释放后瞬间被突触间隙乙酰胆碱酯酶（AChE）水解
    精确性来自"说完就销毁"

口服补剂（原料，且不是 ACh 本身）
    真 ACh 口服：胃肠道和血浆胆碱酯酶直接水解
    + 过不了血脑屏障，到不了任何突触
    市面实装：
    胆碱前体（choline bitartrate / alpha-GPC / citicoline）
    B 族辅因子（B1 硫胺素、B5 泛酸，供乙酰 CoA）
    AChE 抑制剂（石杉碱甲，让已有 ACh 活得久一点）
```

为什么原料多了不等于指令多了——合成链条上的限速：

```
口服胆碱 → 吸收入血 → 血脑屏障转运体（可饱和）
→ 神经元内胆碱乙酰转移酶（ChAT）合成 ACh
→ 突触囊泡装载 → 释放
```

ChAT 是限速酶，多送水泥不等于楼盖得更高。ACh 系统是负反馈稳态（spec）：长期灌原料，身体下调转运体和受体——稳态用下降调回应进补。

最狠的证据是 SLUDGE：

```
如果口服 ACh 真能到达突触起效
    会当场胆碱能危象：流涎、流泪、排尿、排便、胃肠痉挛
    有机磷农药和神经毒气杀人的原理
    就是抑制 AChE 让 ACh 堆积
能泡水喝还不倒下，恰好证明它没有到达突触
```

### 桶模型与控制器模型——补充剂产业的错误前提

补充剂产业的全部逻辑建立在桶模型上：身体是个桶，缺什么倒什么。但身体不是桶，是控制器：

```
原料不足    上调吸收、动用储备、降低消耗
            进化默认环境是间歇性短缺
            身体最擅长应对缺口
原料过剩    下调转运体、下调受体、加速排泄
            ChAT 限速、AChE 兜底都是这套
```

健康的控制器不需要进补。补剂站得住的位置很窄，只有三类：

```
真缺乏症    VD（晒不到太阳）、B12（严格素食）
           铁（经期失血）、碘（缺碘地区）
           环境剥夺造成的 spec 失守
病理状态    吸收障碍（克罗恩、胃切除）、透析患者
           控制器坏了，补剂只是权宜
特殊生理期  孕期叶酸（预防神经管畸形，随机对照级别证据）
```

三类共同点：都是控制器坏了或环境剥夺，不是平时缺原料。

现代饮食的真问题不是"缺"是"偏"：能量过剩、微量失衡（隐性饥饿）。现代人需要的不是补充剂，是减剂——修好食物本身，而不是在坏食物上加药片。

收口：突触 ACh 是带时空精确度的指令，口服补剂是给反馈控制系统灌原料。身体对缺口的适应力被补充剂行业系统性低估，对过剩的代谢能力被现代饮食系统性透支。补剂的正确位置是"控制器坏了或环境剥夺"时的纠偏，不是健康人的日常。

### 钠钾与乙酰胆碱——化学同族，供应相反

钠钾离子和 ACh 补剂不是一回事，分界在合成能力上。但两者在化学上其实是同一伙的：都是水溶离子，都不溶于脂。

```
钠钾（外源元素）
    离子式易溶于水，不溶于脂质
    离子通道的存在就是证明：膜把离子挡在外面，
    通道是唯一的门，搬运的就是"过不去的东西"
    身体造不出原子，只能吃进去
    流失走水（汗、尿），流失真实发生
    → 大汗后补，合法且必要

ACh（内源分子）
    季铵盐结构，永久带正电
    同样水溶、不溶脂
    所以只能当局部神经递质（出不了突触，
    等 AChE 销毁），口服过不了血脑屏障
    身体能合成，生产被 ChAT 反馈控制
    不随汗流失，缺了会自己造
    → 口服补，被控制器无视
```

化学性质相同，供应逻辑相反：钠钾是外源元素，缺了就是真缺；ACh 是内源分子，缺了自己造。

### "好到你察觉不到好"——预防性产品的营销死穴

电解质水效果拉满的表现是：什么事都没发生。该抽的筋，没抽。

```
负反馈工作时是沉默的
    健康是症状的缺席
    电解质水的效果可测：不补抽筋，补了不抽
    因果清楚
    但不可卖："没抽筋"没法拍广告，
    没法让用户当场感受到付款价值
```

产业只能二选一：要么说谎（吹出"更有劲、更耐操"这些可见的假好处），要么卖糖水口感（把不可见的效果换成可见的甜味）。

卖"没发生"这件事，保险行业靠合同解决了；补剂行业解决不了，就只能漂移向不诚实。

收口：钠钾与 ACh 化学同族，命运相反——外源元素补的是真实缺口，内源分子补的是多余原料。而预防性产品的最深困境是它的效果就是"没发生"：沉默的负反馈没法被展示，只能被说谎，或者被换成糖水。

### 机械换能——从变形到电流

感受器的通用逻辑：把物理世界的机械能，变成神经系统读得懂的电信号。

```
机械变形 → 膜张力变化 → 通道蛋白构象变化 → 通道开放
→ 跨膜离子流动 → 离子带电荷 → 电流
```

这就是生物电的第一级来源：换能器把机械能变成电信号。三个门控方式的分工：

```
配体门控    nAChR、GABA       化学 → 电
电压门控    钠/钾/钙通道       电 → 电（动作电位的燃料）
机械门控    Piezo1/2          机械 → 电（触觉、本体感觉）
```

两个实例：

```
触觉（Piezo 通道，2021 诺奖）
    皮肤受压 → 末梢膜变形 → Piezo 通道开放
    → 阳离子内流 → 感受器电位
    分级电位：幅度与刺激强度成比例，局部衰减

听觉（毛细胞）
    声波 → 基底膜行波 → 听毛弯曲 → 顶连接拉开钾通道
    → K+ 内流 → 去极化 → 递质释放 → 听神经放电
    前庭（半规管、耳石）用同一家族毛细胞
    感受重力与加速度——平衡也是机械换能
```

耳朵有两个反常设计：

```
内淋巴高钾 + 耳蜗内电位 +80mV
    方向反了：别的细胞 Na+ 内流，毛细胞 K+ 内流
    全身最大的驱动力，由血管纹离子泵持续供电
外毛细胞电动蛋白 prestin
    膜电压变化 → 蛋白伸缩 → 给基底膜注入能量
    耳蜗放大器：安静声放大几百倍
    耳朵自己就是电压驱动的机械执行器
```

生物电的两级结构：

```
感受器电位（模拟级）
    分级、局部、幅度编码强度
动作电位（数字级）
    全或无、可传播、频率编码强度
神经系统长途运输的货币是频率不是幅度
```

两个推论：

```
耳蜗微音电位（Wever-Bray 效应）
    把耳蜗电流放大接回扬声器，放出来的就是原声
    电流就是声音的另一件衣服
耳声发射（OAE）
    耳蜗放大器是主动系统，耳朵自己会出声
    接收器官同时是发射源，收发一体
```

与模电同构：

```
Piezo 通道的 piezo- 就是"压"的词根
压电陶瓷（piezoelectric）是同一个 piezo
人体用 Piezo 蛋白把压力变成离子流
设备用压电陶瓷把电压变成压力
碳基和硅基用同一个希腊词根做了相反方向的换能
```

收口：机械门控通道是"物理世界 → 电世界"的大门，触觉的 Piezo 和听觉的毛细胞是同一套逻辑的两次应用。耳朵因为内淋巴高钾和 prestin 放大器，成了全身最反常也最精密的换能器。生物电的模拟级（感受器电位）与数字级（动作电位）都从这里开始。
