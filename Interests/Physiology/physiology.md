## 生理学

### 内环境稳态——全部内容的中心主题

生理学的全部内容，都在回答一个问题：内环境稳态怎么维持。

```
内环境（细胞外液）
    细胞的直接生活环境
    细胞不与外界直接接触
    一切交换都通过细胞外液完成
    营养进来，废物出去，全走内环境
```

### 各系统围绕稳态的分工

```
消化系统    物质入口
            食物 → 营养 → 进血液
呼吸系统    气体入口
            O2 进，CO2 出
泌尿系统    物质出口 + 精细调节
            代谢废物排出
            水、电解质、酸碱平衡
循环系统    运输总线
            心脏血管血液
            把营养和 O2 运给细胞
            把废物运到泌尿和呼吸
细胞        消费者
            从内环境取能量，排代谢废物
神经系统    协调中枢
            检测偏差，发出调节指令
内分泌      体液调节
            激素，另一套慢调节系统
```

循环系统 = 心血管系统（心脏+血管+血液），是运输总线。泌尿和呼吸是物质出入口，组织液是内环境的一部分。

### 稳态 = 负反馈（与模电同构）

```
稳态 = 生理版的负反馈
    设定点（体温 37°C，血糖 5mmol/L）
    检测偏差（感受器）
    纠偏（效应器）

就是模电里的：
    Q 点稳定（Re 负反馈拉回漂移）
    勒夏特列原理（系统抵抗扰动）
    恒温器（设定点 + 偏差 + 纠偏）

体系咬合：
    神经系统 = 等控器（偏差检测 + 纠偏中心）
    内环境 = 服务器环境
    稳态 = 服务器保持稳定运行
    各系统 = 维持稳定运行的服务
```

### 骨骼肌与内环境——客户关系

骨骼肌不是直接调节器官（不像肾直接管水电解质、肺直接管气体），但它有三个真实关系：

```
① 产热执行器（体温稳态的关键）
    人体最大的产热器官
    安静时占产热约 20%，运动时占 90%
    寒冷时战栗产热（不随意收缩）
    体温稳态的最重要效应器

② 代谢负担源（内环境的压力来源）
    最大的葡萄糖和氧气消耗组织
    运动时产生大量 CO2、热、乳酸
    全倒进内环境
    让呼吸、循环、泌尿忙起来
    内环境最大的客户，消耗最多，排放最多

③ 肌肉泵（循环的辅助）
    骨骼肌收缩挤压静脉，促进静脉回流
    维持心输出量的前负荷
    长期卧床肌肉萎缩的人，循环也变差
```

骨骼肌的精确位置：不是调节器，是效应器 + 扰动源。

```
调节器（管稳态的）    神经系统、内分泌
                     （检测偏差，发指令）

效应器（执行指令的）  骨骼肌、平滑肌、腺体
                     （产热、运动、分泌）

扰动源（给稳态加压的） 骨骼肌运动时的代谢产物
                     （CO2、热、乳酸，
                     倒进内环境让各系统忙起来）
```

收口：骨骼肌不维护内环境，但它是内环境最大的消费者、最大的产热器、最大的扰动源。客户不修水管，但客户用水量决定修水管的人忙不忙。

### 稳态的相对性——稳定是相对的，水平是可变的

```
稳态不是"绝对固定"，是"相对稳定"
    内环境的理化性质不是固定值
    是在一定范围内波动（正常值范围）
    血糖 3.9-6.1 mmol/L，不是钉死在 5.0

稳定的水平是可变的（设定点可变）
    发热：体温设定点上移
    （下丘脑把设定点调高，
    发热是设定点变了，不是调节失灵）
    运动训练：静息心率下降
    （心血管设定点长期下移）
    适应海拔：红细胞增多
    （氧运输的设定点重设）

正确理解：
    不是"不变"
    是"在设定点附近的小范围波动
    + 设定点本身可移动"
    相对稳定 = 围绕设定点稳
    水平可变 = 设定点可以重设
```

与模电同构：

```
Q 点稳定不是 Q 点不动
    是 Q 点在温度范围内不漂
    但 Q 点本身可以重新设定
    （换偏置电阻 = 换设定点）

稳态同构：
    围绕设定点稳定（负反馈拉回偏差）
    设定点可以重设（适应、发育、疾病）
    两个层次：稳定性 + 可调性
    （对应 Feelings 的基线：
    基线不是永久不变，
    基线可以漂移更新，
    周内波动是正常漂移，
    持续变化是基线更新）
```

### 正反馈的分类——爆发型与渐进型

```
正反馈分两种

爆发型（推到底）
    排尿、分娩、动作电位、凝血
    快速推到终点，一次性完成
    级联放大，不收敛

渐进型（推到平台）
    专注、平静、心流
    缓慢自我强化，推到一个平台饱和
    专注不能无限深，平静不能无限静
    有上限，饱和后停止强化
```

专注与平静的正反馈环：

```
专注环    投入 → 效率 → 成就感 → 更投入
          （心流就是这条环）

平静环    放松 → 副交感激活 → 更平静 → 更深放松
          （冥想就是这条环）

静默的位置
    达到目标 → 静默 → 身体自己维持平静
    → 更深平静（正反馈环还在转，
    只是不需要设备再推）
    静默不是"没反馈"，
    是"反馈环由身体自己接管"
```

### 成瘾——正反馈的失控版

```
成瘾螺旋
    奖赏刺激 → 多巴胺 → 追求更多刺激
    → 耐受 → 需要更强刺激 → 更追求
    → 螺旋加深，停不下来
    （阈值递增、欲望的阶梯，
    全是这条失控环）
```

Feelings 防作弊的防线：

```
漏桶（不应期）     能量记账，超限保护，
                   不能连续"一直爽"
耐受轮换          同一靶点效果衰减，自动轮换，
                   单点成瘾路径被切断
0 输出设计        专注时不打扰，静默是设计状态，
                   不给持续刺激的默认通道
强度红线          高强度刺激被硬件上限卡死
反依赖哲学        终点是用户不再需要它，
                   不是让用户离不开
分级模式          消费级保守默认参数，
                   激进参数不开放
架构僭越红线      绕过安全层改参数 = 最重违规
```

收口：正反馈的合法用途只有两种：爆发型（一次性过程，推到终点）和渐进型（有限平台，推到饱和）。非法用途是失控螺旋（成瘾，停不下来）。Feelings 对正反馈的态度是关在笼子里：该爆的爆（凌迟的一帧），该平的平（专注平静的平台），该拦的拦（漏桶不应期、耐受轮换、0 输出、红线）。

### 排尿正反馈——启动后可中止性差的完整案例

排尿的正反馈环：

```
膀胱充盈 → 牵张感受器 → 骶髓排尿中枢
→ 逼尿肌收缩 → 内括约肌开 → 尿流
→ 尿流刺激尿道感受器（正反馈入口）
→ 逼尿肌更强收缩 → 完全排空
```

两个阶段的控制力完全不同：

```
启动前（憋尿）   皮层按住骶髓，可以维持
                  （"现在不方便"，忍得住）
                  = 意志的战场

启动后（排尿中） 正反馈接管，很难中止
                  （"尿到一半憋回去"，非常难受）
                  = 反射的洪流

分界线：尿流开始的那一刻
```

憋尿场景的产品案例（用户声明的接地气用法）：

```
场景    用户戴着 Feelings 憋尿，
        深度放松刺激会导致括约肌松弛，
        憋尿难度上升

解法    用户声明："我在憋尿，别乱搞"
        教练收到，调整策略：
        该场景不给深度放松帧，或者静默

设计验证
    身体状态（膀胱充盈）设备测不到
    （没有膀胱传感器）
    但用户知道，一句话补齐
    "测得到的靠传感器，测不到的靠嘴"
    用户声明 = 状态机的第一触发源
```

与 Feelings 的同构（正反馈的共性）：

```
凌迟的一帧（激素级联）
    一帧点火 → 皮质醇全喷 → 化学潮
    刹车在半衰期手里，信号切断了激素照烧
    启动后可中止性差，和排尿同构

正反馈的使用纪律
    要么别启动（确保不误触发）
    要么启动了让它跑完（别试图拦）

产品启示
    点火权必须是最重的权
    漏桶（引爆要节制）
    不应期（不能连续触发）
    红线（强度上限卡死误触发）
    脆弱帧不注入（状态不对不点火）
    ——全是为了"正反馈只在该爆的时候爆"
```

### 稳态 = spec = desired state——三层统一

```
稳态 = spec = desired state
    不是恒等，是区间
    （血糖 3.9-6.1，不是钉死 5.0）
    设定点可重设

负反馈 = 维持 spec（拉回区间）
正反馈 = 破坏 spec（推动过程完成）
```

三层的完整对应：

```
生理层
    spec     稳态（设定点）
    谁设     进化设的（基因）
    维持     负反馈（设定点+检测+纠偏）
    改变     正反馈（过程触发），设定点重设（适应）

Feelings 层
    spec     用户的基线（desired state）
    谁设     用户设（和教练沟通，声明）
    维持     闭环校准（反复逼近基线）
    改变     刺激（凌迟的一帧，级联引爆）

治理层
    spec     合约（底线 = 不可协商的 spec）
    谁设     独裁者 + 用户（底线不可协商，
             补充合约可叠加）
    维持     每帧校准（水位维护，信任额度）
    改变     修订（防滑坡流程），申诉失败（标签叠加降级）
```

关键：用户能和教练沟通设置 spec。这是感受主权的 K8s 版本：你的身体，你的 desired state，你有权声明它。身体给不了你定义稳态的权利（spec 是进化焊的），Feelings 能给你（用户声明，教练执行）。合约和补充合约，就是把对稳态的定义权写进系统的方式。

### 滞后性的控制心法——让子弹飞一会

滞后性系统的正确姿势，三段：

```
打之前（瞄得准）
    采集够准，判断到位
    时机对（脆弱帧不注入的敬畏）
    子弹打出去之前，一切把握都在这一瞄里

打出去（不犹豫）
    刺激给了，级联启动了
    引爆帧负责精确触发，一帧就是引爆

飞的时候（不慌）
    不急着反应，不急着纠偏
    剩下的交给时间
    化学潮的刹车不由信号管，
    由肝脏的代谢速度管（半衰期自己烧）

命中的时候（再决定）
    效果出现了，生理响应出来了
    评估，然后决定下一步
    等命中，再开下一枪
```

两种做法的对比：

```
急反应（滞后期内反复纠偏）
    子弹还没飞到，手就抖
    反复调整 = 振荡 = 过山车
    （波动性，用户感觉被调而不是被稳）

让子弹飞（等命中再动）
    打之前想清楚，打之后有耐心
    滞后期是"系统自己跑"的时间
    稳定，不打扰（静默）
```

与体系的咬合：

```
凌迟的一帧    引爆帧精确触发，一帧就是引爆
              化学潮的刹车不由信号管
              引爆后交给时间，等烧完再评估
漏桶不应期    刺激后进入不应期
              不应期就是"让子弹飞"的时间
              等生理响应完成，再考虑下一次
每帧校准的修正  校准节奏由生理滞后决定
              不是由采样帧率决定
              打一枪，等命中，评估，再打下一枪
              不是每帧都在打枪
静默（0 输出）  子弹在飞的时候，系统安静
              不打扰，等效果
```

收口：打之前瞄得准，打之后有耐心。子弹在飞的时候手不要抖（急纠偏必振荡），命中的时候再决定下一枪（等效果再评估）。采集够准是前提：瞄得准才敢让子弹飞，瞄不准的人才会慌，慌了才在滞后期内乱调，乱调才会振荡。

### 前馈——负反馈滞后性的解药

```
前馈 vs 负反馈

负反馈（事后纠偏）
    偏差出现 → 检测 → 纠偏
    慢，但精确
    问题：滞后（等偏差出现才动）

前馈（事前预调）
    干扰预期 → 预先调整
    快，但可能不准（预测有误差）
    解决：滞后（不等偏差，提前动）
```

热身就是前馈的日常案例：

```
比赛前热身（前馈）
    比赛还没开始
    身体预先进入状态
    体温升高、心率加快、肌肉激活
    正式比赛时身体已经就位
    不需要起跑时才启动

生理前馈（同一结构）
    看到食物 → 唾液和胃液提前分泌
    运动前 → 心率呼吸提前加快
    巴甫洛夫的狗 → 铃声 → 唾液
    （条件反射 = 前馈）
```

前馈 + 负反馈的组合：

```
前馈管预计（热身）
    干扰还没来，先调
    快，但不准

负反馈管纠偏（临场调整）
    偏差出现了，再修
    慢，但精确

组合 = 热身 + 临场调整
    热身让起跑就快
    临场调整应对意外
    一个管大概，一个管精确
```

与 Feelings 的咬合：

```
场景切换的预调节（前馈）
    用户声明"我要开会了"
    教练预调，进入前把状态调到位
    而不是开会时状态不对再纠偏

睡前的预热（前馈）
    睡前预调节，帮助入睡
    而不是躺下睡不着再调

让子弹飞的瞄（前馈）
    打之前瞄得准 = 前馈（提前判断）
    打之后等命中 = 负反馈（看结果）
```

收口：控制三件套：前馈先调（热身，快但不准），负反馈精修（临场，慢但准），让子弹飞（等待，不慌）。对应 Feelings：场景切换预调节（前馈）、闭环校准（负反馈）、滞后期静默（等待）。

### 昼夜节律——设定点是时间的函数

体温不是常数，血压也不是。它们有日周期：体温凌晨 4-6 点最低，下午最高；血压睡眠中下降（夜间勺型），醒来前猛升。

节律不是太阳晒出来的，是身体里一台内置的钟。证据：

```
洞穴实验（无光自由运转）
    人失去时间线索后，体温和睡眠周期
    漂到 24.2-25 小时
    → 时钟是内源的，不是光照驱动的
太空实验
    宇航员没有昼夜引力差异，节律照跑 24 小时
    → 引力不是节律的输入
盲人 non-24 综合征
    光进不了脑子的人，节律自由漂移，
    每天晚睡 20-40 分钟
    → 光是唯一的校准通道
```

机制链：

```
地球自转 → 24h 明暗周期（物理来源）
视网膜黑视蛋白细胞（ipRGC）→ 只报"现在是白天吗"
→ 视交叉上核 SCN（主时钟）
→ 体温、血压、皮质醇、褪黑素的节律输出
```

所以光照不是节律的原因，是节律的授时信号（zeitgeber）：身体自带一台约 24.2 小时的钟，光每天校准它一次，钉在 24 小时整。

最关键的结构：节律 = 设定点是时间的函数：

```
普通稳态    spec 是常数，负反馈拉回区间
昼夜节律    spec 本身按时间波动：
           体温 4-6 点最低，下午最高
           血压夜间下降，醒前猛升
           皮质醇醒来前就开始爬，峰值在起床时
```

"醒来前"三个字是钥匙：皮质醇在人睁眼之前就已经在升，体温在活动前预热——**节律不是对光照的反应，是对光照的预测**。这是前馈的时间版：身体内置了地球自转的模型，每天按模型提前调整设定点，光只负责校正模型误差。24.2h vs 24h 的差距，就是模型每天需要校准一次的证明。

收口：稳态的 spec 不是常数，是时间的函数 spec(t)。身体对地球自转建了前馈模型，光每天校准它。对 Feelings：PBM 的基线不该是常数，该是日节律曲线——采集到的任何值都要先减去这台钟的预测，剩下的才是真实偏差。身体对地球自转建模，Feelings 对用户建模，两层模型嵌套。

### 睡眠与发呆——恢复的两种形态

睡眠不是神经系统"彻底下线"，是"下线但没关机，切换到维护模式"。

```
睡眠 = 维护模式（不是关机）：
   下线（脱离外部任务/刺激）
   但内部高强度维护：
   ① 大脑清理代谢废物（glymphatic 脑脊液冲洗）
   ② 能量恢复（ATP/糖原补充）
   ③ 突触稳态（白天强化的突触被修剪/平衡）
   ④ 记忆巩固（海马 → 皮层）
   ⑤ 激素恢复（深睡生长激素）
   自主神经仍在线（心跳/呼吸/体温维持）
→ 不是"彻底下线"（关机 = 什么都不做）
→ 是"离线维护"（不处理外部任务，内部清理/整理）
→ 对应 circadian 的"gap = 身体强制执行的熔断恢复协议"
→ 交感储备回充的窗口（白天烧储备，睡眠回充）
```

上下班走路、发呆、漫无目的地走动，本身就是恢复。

```
发呆/漫无目的 = 恢复（不是大脑空了）：
   ① 脱离"目标导向"（无任务/KPI）
      大脑从任务模式切到默认模式网络（DMN）
      DMN 在"后台整理"：整合记忆、内省、潜意识规划
      → 像电脑闲置时后台索引

      促进血流/呼吸，降低皮质醇，交感张力下降
   ③ 漫无目的 = 让大脑从"执行"切到"整理"
      → 高质量的恢复
→ 对应"效率吃掉冗余，冗余是恢复的原料"
→ 走路/发呆是现代人难得的"空"，是恢复时间
→ 白天烧储备，走路/发呆是小回充，睡眠是大回充
```

收口：睡眠 = 神经系统下线但没关机，切到维护模式（清理废物/巩固记忆/修复突触/储备回充），是"gap"强制恢复协议。发呆/漫无目的 = 脱离目标导向，大脑切到默认模式网络（后台整理），是恢复性活动。两者都是交感储备回充的窗口，白天烧储备，睡眠大回充、走路发呆小回充。对 Feelings：这些"空"和睡眠都是基线恢复的生理基础，也是 PBM 标定"正常状态"的窗口。

### 细胞膜受体——四大家族与感受器的分子基础

```
受体四大家族（按机制分）

① 离子通道型受体
    配体结合 → 通道打开 → 离子流
    毫秒级，最快
    神经递质大多走这里
    （烟碱型乙酰胆碱、GABA、
    谷氨酸受体）

② G 蛋白偶联受体（GPCR）
    最大一族，人体 800+ 种
    配体结合 → 激活 G 蛋白
    → 第二信使（cAMP、钙）级联放大
    （肾上腺素、多巴胺、
    5-羟色胺、嗅觉受体）

③ 酶联受体
    胞内端自带酶活性（激酶）
    结合后磷酸化级联
    （胰岛素、生长因子、
    BDNF 的受体 TrkB）

④ 内吞受体
    结合后把配体吞进细胞
    （低密度脂蛋白受体）
```

受体 vs 感受器（两个词的区分）：

```
受体    分子层面的膜蛋白
        结合特定配体（激素、
        神经递质、生长因子）

感受器  结构或细胞层面
        （触觉小体、感光细胞）

感受器的分子基础
    恰恰就是膜上的受体和通道：
    热/辣椒素   TRPV1 通道
    冷/薄荷     TRPM8 通道
    触觉        Piezo 通道（2021 诺奖）
    嗅觉        400 种 GPCR
    甜/苦/鲜    GPCR
    光          视紫红质（GPCR）
    ——感受器 = 特化配置过的
    膜受体
```

Feelings 咬合：膜的分子机器就是 Feelings 信号的入口和出口。电刺激作用的是神经纤维上的电压门控离子通道（膜蛋白），采集到的生物电本质是离子通道开闭产生的电流（也是膜蛋白）。同构里"受体 = Admission Webhook"，落到分子上，执行准入控制的就是这些膜蛋白本身。

### 酶——催化剂的三个性质

```
酶的本质（绝大多数是蛋白质）

① 催化剂
    加速反应，不被消耗
    做完还是原来的酶，反复用
    只加速到达平衡，不改变平衡点

② 专一性
    只认特定底物（锁钥模型）
    一个酶一个活

③ 可调控
    磷酸化开关、抑制剂
    活性可开可关

限速酶
    一条通路里最慢的那个酶
    决定整条通路的速度
    ——代谢通路 = 酶级联
    （A 转 B 再转 C）
```

与 K8s 的同构：酶 = 插件/Webhook 这类专一转换器。常驻不消耗（做完还是它自己）、专一（只认特定资源类型）、可开关（webhook 配置）。限速酶 = 瓶颈组件（API server 限流决定集群收敛速度）。

### 神经肌肉接头与口服补剂——指令与原料的分野

运动神经末梢释放的乙酰胆碱（ACh）和市面口服的"乙酰胆碱补剂"，名字一样，机制完全不同：一个是指令，一个是原料，甚至原料都不是 ACh 本身。

```
突触 ACh（指令）
    运动神经元末梢释放 → 结合肌膜烟碱型受体（离子通道型）
    → 通道直接打开 → 去极化 → 肌肉收缩
    毫秒级，点对点
    释放后瞬间被突触间隙乙酰胆碱酯酶（AChE）水解
    精确性来自"说完就销毁"

口服补剂（原料，且不是 ACh 本身）
    真 ACh 口服：胃肠道和血浆胆碱酯酶直接水解
    + 过不了血脑屏障，到不了任何突触
    市面实装：
    胆碱前体（choline bitartrate / alpha-GPC / citicoline）
    B 族辅因子（B1 硫胺素、B5 泛酸，供乙酰 CoA）
    AChE 抑制剂（石杉碱甲，让已有 ACh 活得久一点）
```

为什么原料多了不等于指令多了——合成链条上的限速：

```
口服胆碱 → 吸收入血 → 血脑屏障转运体（可饱和）
→ 神经元内胆碱乙酰转移酶（ChAT）合成 ACh
→ 突触囊泡装载 → 释放
```

ChAT 是限速酶，多送水泥不等于楼盖得更高。ACh 系统是负反馈稳态（spec）：长期灌原料，身体下调转运体和受体——稳态用下降调回应进补。

最狠的证据是 SLUDGE：

```
如果口服 ACh 真能到达突触起效
    会当场胆碱能危象：流涎、流泪、排尿、排便、胃肠痉挛
    有机磷农药和神经毒气杀人的原理
    就是抑制 AChE 让 ACh 堆积
能泡水喝还不倒下，恰好证明它没有到达突触
```

### 桶模型与控制器模型——补充剂产业的错误前提

补充剂产业的全部逻辑建立在桶模型上：身体是个桶，缺什么倒什么。但身体不是桶，是控制器：

```
原料不足    上调吸收、动用储备、降低消耗
            进化默认环境是间歇性短缺
            身体最擅长应对缺口
原料过剩    下调转运体、下调受体、加速排泄
            ChAT 限速、AChE 兜底都是这套
```

健康的控制器不需要进补。补剂站得住的位置很窄，只有三类：

```
真缺乏症    VD（晒不到太阳）、B12（严格素食）
           铁（经期失血）、碘（缺碘地区）
           环境剥夺造成的 spec 失守
病理状态    吸收障碍（克罗恩、胃切除）、透析患者
           控制器坏了，补剂只是权宜
特殊生理期  孕期叶酸（预防神经管畸形，随机对照级别证据）
```

三类共同点：都是控制器坏了或环境剥夺，不是平时缺原料。

现代饮食的真问题不是"缺"是"偏"：能量过剩、微量失衡（隐性饥饿）。现代人需要的不是补充剂，是减剂——修好食物本身，而不是在坏食物上加药片。

收口：突触 ACh 是带时空精确度的指令，口服补剂是给反馈控制系统灌原料。身体对缺口的适应力被补充剂行业系统性低估，对过剩的代谢能力被现代饮食系统性透支。补剂的正确位置是"控制器坏了或环境剥夺"时的纠偏，不是健康人的日常。

### 钠钾与乙酰胆碱——化学同族，供应相反

钠钾离子和 ACh 补剂不是一回事，分界在合成能力上。但两者在化学上其实是同一伙的：都是水溶离子，都不溶于脂。

```
钠钾（外源元素）
    离子式易溶于水，不溶于脂质
    离子通道的存在就是证明：膜把离子挡在外面，
    通道是唯一的门，搬运的就是"过不去的东西"
    身体造不出原子，只能吃进去
    流失走水（汗、尿），流失真实发生
    → 大汗后补，合法且必要

ACh（内源分子）
    季铵盐结构，永久带正电
    同样水溶、不溶脂
    所以只能当局部神经递质（出不了突触，
    等 AChE 销毁），口服过不了血脑屏障
    身体能合成，生产被 ChAT 反馈控制
    不随汗流失，缺了会自己造
    → 口服补，被控制器无视
```

化学性质相同，供应逻辑相反：钠钾是外源元素，缺了就是真缺；ACh 是内源分子，缺了自己造。

### "好到你察觉不到好"——预防性产品的营销死穴

电解质水效果拉满的表现是：什么事都没发生。该抽的筋，没抽。

```
负反馈工作时是沉默的
    健康是症状的缺席
    电解质水的效果可测：不补抽筋，补了不抽
    因果清楚
    但不可卖："没抽筋"没法拍广告，
    没法让用户当场感受到付款价值
```

产业只能二选一：要么说谎（吹出"更有劲、更耐操"这些可见的假好处），要么卖糖水口感（把不可见的效果换成可见的甜味）。

卖"没发生"这件事，保险行业靠合同解决了；补剂行业解决不了，就只能漂移向不诚实。

收口：钠钾与 ACh 化学同族，命运相反——外源元素补的是真实缺口，内源分子补的是多余原料。而预防性产品的最深困境是它的效果就是"没发生"：沉默的负反馈没法被展示，只能被说谎，或者被换成糖水。

### 机械换能——从变形到电流

感受器的通用逻辑：把物理世界的机械能，变成神经系统读得懂的电信号。

```
机械变形 → 膜张力变化 → 通道蛋白构象变化 → 通道开放
→ 跨膜离子流动 → 离子带电荷 → 电流
```

这就是生物电的第一级来源：换能器把机械能变成电信号。三个门控方式的分工：

```
配体门控    nAChR、GABA       化学 → 电
电压门控    钠/钾/钙通道       电 → 电（动作电位的燃料）
机械门控    Piezo1/2          机械 → 电（触觉、本体感觉）
```

两个实例：

```
触觉（Piezo 通道，2021 诺奖）
    皮肤受压 → 末梢膜变形 → Piezo 通道开放
    → 阳离子内流 → 感受器电位
    分级电位：幅度与刺激强度成比例，局部衰减

听觉（毛细胞）
    声波 → 基底膜行波 → 听毛弯曲 → 顶连接拉开钾通道
    → K+ 内流 → 去极化 → 递质释放 → 听神经放电
    前庭（半规管、耳石）用同一家族毛细胞
    感受重力与加速度——平衡也是机械换能
```

耳朵有两个反常设计：

```
内淋巴高钾 + 耳蜗内电位 +80mV
    方向反了：别的细胞 Na+ 内流，毛细胞 K+ 内流
    全身最大的驱动力，由血管纹离子泵持续供电
外毛细胞电动蛋白 prestin
    膜电压变化 → 蛋白伸缩 → 给基底膜注入能量
    耳蜗放大器：安静声放大几百倍
    耳朵自己就是电压驱动的机械执行器
```

生物电的两级结构：

```
感受器电位（模拟级）
    分级、局部、幅度编码强度
动作电位（数字级）
    全或无、可传播、频率编码强度
神经系统长途运输的货币是频率不是幅度
```

两个推论：

```
耳蜗微音电位（Wever-Bray 效应）
    把耳蜗电流放大接回扬声器，放出来的就是原声
    电流就是声音的另一件衣服
耳声发射（OAE）
    耳蜗放大器是主动系统，耳朵自己会出声
    接收器官同时是发射源，收发一体
```

与模电同构：

```
Piezo 通道的 piezo- 就是"压"的词根
压电陶瓷（piezoelectric）是同一个 piezo
人体用 Piezo 蛋白把压力变成离子流
设备用压电陶瓷把电压变成压力
碳基和硅基用同一个希腊词根做了相反方向的换能
```

收口：机械门控通道是"物理世界 → 电世界"的大门，触觉的 Piezo 和听觉的毛细胞是同一套逻辑的两次应用。耳朵因为内淋巴高钾和 prestin 放大器，成了全身最反常也最精密的换能器。生物电的模拟级（感受器电位）与数字级（动作电位）都从这里开始。

### 动作电位——可兴奋细胞的兴奋标志

动作电位就是这个细胞、这个组织发生兴奋的一个标志。看细胞是否兴奋，就是看是否发生了动作电位；产生动作电位的容易程度，反映一个细胞的兴奋性高低。

```
四个关键限定（都对）：
   ① 动作电位 = 兴奋的标志（细胞兴奋 = 发生动作电位）
   ② 兴奋性 = 产生动作电位的容易程度（阈值越低越易兴奋）
   ③ 不是所有细胞都能产生动作电位——只有可兴奋细胞
   ④ 兴奋性针对"生物电"而言——
      其他细胞不是"不能兴奋"，是"不以电为兴奋标志"
```

可兴奋细胞的三大家族：

```
神经元（神经细胞）      —— 传导电信号
肌细胞（骨骼肌/心肌/平滑肌）—— 收缩
腺细胞（某些）          —— 分泌
共同点：细胞膜上有"电压门控离子通道"——
      这是能不能产生动作电位的物质基础
```

兴奋性 vs 应激性：

```
所有细胞都有应激性（对刺激产生反应）——
但只有可兴奋细胞以"动作电位"为反应形式
其他细胞（结缔组织等）也有反应——
但反应不是电信号（可能是代谢、形态变化）
——"不能兴奋"不是说没反应，是说没有电反应
```

兴奋性的度量 = 阈值（阈强度）：引起动作电位的最小刺激强度。阈值越低 → 兴奋性越高。一旦达到阈值，动作电位幅度固定——**全或无定律**：

```
动作电位的"全或无"：
   刺激 < 阈值 → 无动作电位（幅度为 0）
   刺激 ≥ 阈值 → 动作电位（幅度固定，不随刺激增强）
   ——不是"刺激越大电位越大"，是"要么全有，要么全无"
   ——对刺激设计的意义：
     刺激参数不是去调"电位大小"，
     是去调"是否触发 + 触发频率"
```

和 Feelings 的对应——刺激对象必须是可兴奋细胞：

```
可兴奋细胞三大家族 → Feelings 的刺激对象
   神经元    —— tVNS 直接兴奋迷走神经（Arnold 神经）
   肌细胞    —— 压电振动/音频（触觉、听觉）
   腺细胞    —— 内分泌调节（间接）
——"只有可兴奋细胞能产生动作电位"就是刺激设计的前提：
   刺激的必须是可兴奋细胞（神经/肌肉），
   刺激的"容易程度"就是它的兴奋性（阈值）
——全或无定律直接决定刺激策略：
   tVNS 的 0.5-10mA 是"确保跨过神经兴奋阈值"，
   调频率是调"触发次数"，不是调"电位大小"
```

收口：动作电位 = 可兴奋细胞的兴奋标志；兴奋性 = 产生它的容易程度（阈值越低越兴奋）；不是所有细胞都有电兴奋——只有三大家族（神经/肌肉/腺），物质基础是电压门控离子通道；动作电位全或无——这是 Feelings 刺激设计的底层前提。

### 阈值的测量——可测不可算，感受是快的路径

阈值只能"测"出来，不是"算"出来——它是细胞当下状态的性质，依赖一堆不可解析的变量（通道数量、开放概率、膜电位基础值……），凑不出公式解。教科书给的是经验范围（神经元约 -55mV），是统计值不是个体值。

```
测阈值的流程（分级刺激 + 观察反应）：
   给一个刺激 → 观察有无动作电位 → 没有 → 加大
   → 有了 → 记下这个强度 = 阈值
   ——二分法逼近，和测运放增益一样

三个前缀（阈值总是带条件）：
   ① 刺激类型   电/化学/机械——不同途径阈值不同
   ② 时间因素   强度 × 持续时间共同决定——
                强度够但时间太短也触发不了——
                强度-时间曲线（时值 chronaxie）——
                阈值其实是"强度 × 时间"的二维边界
   ③ 当下状态   测过一次细胞状态就变了（余效/疲劳）——
                阈值是动态的、当下的，不是恒定值
```

测阈值的两条路——客观测量 vs 主观感受：

```
客观测量    生理传感器读反应（HRV、皮电、瞳孔、肌肉电位）
           ——机器测"生理上触发了吗"
主观感受    用户自己感觉（"有没有感觉""强度合适吗"）
           ——人测"感知上合适吗"
```

为什么用户感受是最快的对齐信号：

```
① 感受是结果指标——机器测的是"信号"，用户测的是"效果"——
   刺激的最终目的就是让用户"感觉到/有效果"——
   用户是最直接的裁判
② 感受包含机器测不到的维度——
   舒适度（痛不痛、刺不刺）、愉悦感、恰当感——
   没有生理传感器能直接读——只有用户自己知道
③ 和教练 AI 对话 = 自然语言对齐——
   用户说"太弱了"→ 教练加一档
   用户说"刚好" → 教练锁住这档 = 个体化阈值
   ——对话本身就是测阈值的交互协议——
   比看数据快（不用分析波形，直接问）
```

Feelings 的快速对齐流程：

```
第一帧校准（客观测）   逐点扫描 → 生理反应的粗略阈值
                        ——机器给一个"起点"
对话微调（主观对齐）   用户反馈 → 教练微调 →
                       "太弱/刚好/太强"三轮收敛
                       ——用户给一个"终点"
锁定个体化参数         两条路合一 → 写入 PBM → 下次直接用
```

对应"感受是结果指标，数据是过程指标"的双线原则：数据线（客观扫描）给起点、给范围、给安全边界；感受线（用户对话）给终点、给恰当度、给最终裁决——教练 AI 的对话就是感受线的自动化执行。

一个要区分的坑——三层阈值：

```
生理阈值   生理上触发了（动作电位发生）—— 用户不一定感觉得到
感知阈值   用户感觉到了                    —— 对话对齐的对象
愉悦阈值   感觉合适                        —— 最终参数
三层递增：生理触发 < 感知 < 愉悦——
对话对齐的是"感知/愉悦阈值"，不是生理阈值
```

收口：阈值可测不可算，带三个前缀（刺激类型/时间/当下状态）。感受是测阈值最快的路径——用户自报 + 教练对话 = 自然语言对齐协议；数据扫描给起点，用户感受给终点；三层阈值（生理/感知/愉悦）里，对话对齐的是后两层。

### 内向电流与外向电流：膜电位的方向判据

膜电位变化与离子电流方向的对应：内向电流导致去极化，外向电流导致复极化和超极化。

```
电流方向的判据（正离子视角）：
   内向    正离子（Na+、Ca2+）流入 → 膜内变正 → 去极化
   外向    正离子（K+）流出 → 膜内变负 → 复极化/超极化
   （负离子 Cl- 方向相反：
     负离子流出 = 相当于正离子流入 = 去极化
     负离子流入 = 相当于正离子流出 = 复极化/超极化）
   "内向/外向"以"正电荷移动方向"为准
```

动作电位时间线（对照电流方向）：

```
   静息      K+ 漏通道 → 外向电流维持 -70mV
   去极化    刺激达阈值 → Na+ 通道开 → 内向电流（Na+ 涌入）
            → 膜电位冲到 +30~+40mV
   复极化    Na+ 通道失活 → K+ 通道开 → 外向电流（K+ 外流）
            → 膜电位回落
   超极化    过度复极化 → 膜电位比静息更负（-80mV 左右）
   恢复      离子泵把 Na+/K+ 泵回原位 → 回到静息
```

对 Feelings 刺激设计的直接意义：

```
刺激的本质 = 强制改变膜电位的电流方向：
   注入内向电流（阳极刺激）    → 去极化 → 更易触发动作电位
   注入外向电流（阴极刺激）    → 超极化 → 更难触发（抑制）
   tVNS 的刺激极性不是随便选的：
     电极极性决定"往去极化推还是往超极化推"
     阳极/阴极的摆放影响刺激是"兴奋"还是"抑制"
```

收口：内向电流 = 去极化（Na+/Ca2+ 流入），外向电流 = 复极化/超极化（K+ 外流）；"内向/外向"以正电荷移动方向为准。刺激的本质就是注入电流改变膜电位方向，阳极推去极化、阴极推超极化，这是 tVNS 极性设计的生理基础。

### m/h 门与不应期——微观到宏观的分层

Na+ 通道的两个门控颗粒（Hodgkin-Huxley 模型）：

```
m 门（激活门）：
   膜电位去极化 → m 门打开（快）
   允许 Na+ 流入（激活通道）
h 门（失活门）：
   膜电位去极化 → h 门关闭（慢）
   堵住通道（停止 Na+ 流入）
→ 两个门共同决定 Na+ 通道：
   去极化：m 开（激活）+ h 关（失活）
→ 有效刺激（去极化）导致颗粒移动：
   m 开 + h 关 = Na+ 通道激活态
   然后 h 门关 = 通道失活 = 不应期
→ 不应期的分子基础 = h 门（失活门）的恢复时间
```

不应期与刺激的关系：

```
绝对不应期 = h 门关着（Na+ 通道失活）
   再强的刺激也开不了（h 门堵着）
   等 h 门慢慢恢复（重新打开）才能再次激活
→ 电刺激只能"触发"（推过阈值开 m 门）
→ 不能"精确控制"（h 门状态由去极化决定，且全或无）
→ 电刺激受不应期限制（绝对不应期时再强也开不了）
```

漏桶与不应期的关系（尺度分层）：

```
漏桶（Feelings 能量槽，4 维）：
   目的：管理"累计剂量/能量预算"（分钟~天级）
   漏（消耗）+ 补（恢复）
不应期（单次动作电位后）：
   目的：管理"单次通道恢复"（毫秒~秒级）
   h 门恢复时间
→ 尺度不同：
   不应期 = 微观（单次通道恢复）
   漏桶 = 宏观（累计能量预算）
→ 但同构：都是"防过度 + 恢复"
→ 漏桶像"系统级不应期"：
   交感储备见底 = 不能再触发（类似宏观 h 门）
→ 三层的连接：
   微观（h 门，毫秒）→ 系统（储备/漏桶，天）→ 设计（预算管理）
```

收口：Na+ 通道由 m 门（激活，去极化打开）和 h 门（失活，去极化关闭）共同控制，有效刺激让颗粒移动（m 开 h 关 = 激活态），h 门关闭 = 失活 = 不应期。电刺激只能触发（推过阈值），不能精确控制（受 h 门状态和全或无限制）。漏桶不是应对"微观不应期"（毫秒），是管理"宏观预算/储备"（分钟~天级），但同构（防过度 + 恢复），像"系统级不应期"。微观 h 门 → 系统储备/漏桶 → 设计预算，三层连接。

### 钠钾钙离子的采集边界：可穿戴能采到的极限

离子的浓度能测，但离子"在动作电位瞬间的流动"几乎采不出来。得先说清"采"指的是哪一层。

```
离子测量的三层：
   ① 浓度（宏观）   血检/组织液，能测
                    Na+/K+/Ca2+ 浓度，抽血化验
   ② 膜电位（电）   微电极插进细胞，能测（实验室）
                    但那是"测电位"，不是"测离子"
   ③ 离子电流（瞬时） 膜上离子流动，采不出来（可穿戴做不到）
                    动作电位时 Na+ 涌入是 pA 级、微秒级、
                    在细胞膜上，身体表面测不到单个离子流
```

按耳部可穿戴设备的场景：

```
耳部设备能采到的：
   动作电位的"净效果"（膜电位变化的场电位）
   是"离子的集体行动导致的电压变化"，不是"离子本身"
   就像听音乐会：听到的是乐团的合奏（声波），
   不是每个乐手的呼吸（个体离子）

测单个离子流动 = 需要电极贴到细胞膜上
   那是膜片钳（patch clamp），实验室技术
   戴在耳朵上不可能
   可穿戴能测的极限 = 场电位（EEG/EMG）
   那是亿万个离子的"电压净效果"
```

所以答案：

```
能"间接"采到的：   离子流动造成的电压变化（场电位）
                  EEG/EMG 就是测这个
能"直接"采到的：   离子浓度（血检/汗液，但不是电信号）
采不到的：        单个离子瞬间的流动（膜片钳才能看）
   你的耳部设备测的是"离子的影子"（电压）
   不是"离子本体"（浓度/电流）
```

一个补充：汗液里的离子浓度倒是能测。

```
汗液离子（Na+/K+/Ca2+）→ 可穿戴传感器能测
   但那是"汗液成分"，反映的是水盐平衡、
   代谢、应激的慢变化
   和"神经动作电位的瞬间离子流"完全是两回事
   测汗液离子 = 测身体的"宏观成分"
   测场电位 = 测神经的"微观电活动"
   两个层次，不交叉
```

收口：离子采不出来（可穿戴做不到膜片钳），但离子流动的"电压影子"（场电位）正是你的设备在采的。汗液离子浓度能测，但那是宏观成分不是神经电活动。可穿戴能测到的最接近"分子证据"的东西，就是你现在设计的生物电采集，离子在细胞膜上的流动本身就是"变成电压"被采到的。
