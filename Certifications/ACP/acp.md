# 阿里云 ACP 认证备考计划

## 考试基本信息

- **考试时间**：120分钟
- **题型**：单选题 + 多选题
- **满分**：100分，及格分数：80分
- **考试费用**：1200元/次
- **考试形式**：线上/线下可选

## 学习计划（30天，每天1-2小时）

### 第一周：基础学习期（第1-7天）

**目标**：系统学习阿里云核心产品和服务，建立知识框架

#### 第1-2天：计算与网络基础（4小时）
- [ ] **ECS（弹性计算服务）**
  - 实例类型、规格选择
  - 镜像、快照、自定义镜像
  - 安全组配置
  - 弹性伸缩（ESS）
  - 负载均衡（SLB）
- [ ] **VPC（专有网络）**
  - VPC、子网、路由表
  - 弹性公网IP（EIP）
  - NAT网关
  - VPN网关
- [ ] **实践**：在控制台创建ECS实例、配置VPC网络

#### 第3-4天：存储与数据库（4小时）
- [ ] **OSS（对象存储服务）**
  - 存储类型（标准、低频、归档）
  - 生命周期管理
  - 跨区域复制
  - CDN加速
- [ ] **RDS（关系型数据库）**
  - 实例类型选择
  - 备份与恢复
  - 读写分离
  - 数据迁移
- [ ] **其他存储**
  - NAS（文件存储）
  - EBS（块存储）
- [ ] **实践**：创建OSS bucket、RDS实例，配置备份策略

#### 第5-6天：安全与监控（4小时）
- [ ] **安全服务**
  - 云安全中心
  - Web应用防火墙（WAF）
  - DDoS防护
  - 访问控制（RAM）
  - 密钥管理服务（KMS）
- [ ] **监控与运维**
  - 云监控（CloudMonitor）
  - 日志服务（SLS）
  - 应用实时监控服务（ARMS）
  - 运维编排服务（OOS）
- [ ] **实践**：配置RAM用户和权限、设置监控告警

#### 第7天：复习与总结（2小时）
- [ ] 回顾本周学习内容
- [ ] 整理核心概念和配置要点
- [ ] 完成第一周自测题

---

**目标**：深入学习各产品细节，开始刷题练习

#### 第8-9天：中间件与大数据（4小时）

#### 第10-11天：应用服务与DevOps（4小时）
- [ ] **应用服务**
  - 函数计算（FC）
  - API网关
  - 应用高可用服务（AHAS）
- [ ] **DevOps**
  - 云效（DevOps平台）
  - 代码托管
- [ ] **实践**：创建函数计算服务、配置API网关

#### 第12-13天：专项产品深入学习（4小时）

  - CDN加速原理

- [ ] **域名与解析**

## 学习重点与技巧

### 核心产品优先级
1. **必考重点**（占分比高）：
   - ECS、VPC、OSS、RDS
   - SLB、安全组、RAM
   - 云监控、日志服务

2. **重要考点**：
   - 弹性伸缩、CDN
   - 函数计算、容器服务
   - 消息队列、大数据服务

3. **了解即可**：
   - 视频服务、域名服务
   - 其他边缘产品

### 学习技巧
1. **理论+实践结合**：每个产品都要在控制台实际操作
2. **建立知识体系**：按产品分类整理，形成知识网络
3. **错题本管理**：记录错题、错误原因、正确知识点
4. **场景题理解**：理解业务场景，而非死记硬背
5. **时间管理**：每天固定学习时间，保持连续性

### 考试技巧
1. **单选题**：仔细审题，注意"最合适"、"最佳"等关键词
2. **多选题**：不确定的选项不选，宁可少选不错选
3. **时间分配**：单选题1分钟/题，多选题2分钟/题
4. **检查策略**：标记不确定题目，最后统一检查
