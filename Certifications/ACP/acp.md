# 阿里云云原生微服务 ACP 认证备考计划

## 考试基本信息

- **考试时间**：120分钟
- **题型**：单选题 + 多选题，题库里一共才600道题，开刷！！
- **满分**：100分，及格分数：80分
- **考试费用**：1200元/次
- **考试形式**：线上/线下可选
- **认证方向**：云原生微服务架构师

## 学习计划（30天，每天1-2小时）

### 第一周：云原生基础学习期（第1-7天）

**目标**：掌握Kubernetes基础、容器技术、云原生基础架构

#### 第1-2天：Kubernetes基础（4小时）
- [ ] **Kubernetes核心概念**
  - Pod、Deployment、Service、ConfigMap、Secret
  - Namespace、Label、Selector
  - ReplicaSet、StatefulSet、DaemonSet
  - Job、CronJob
- [ ] **Kubernetes网络**
  - Service类型（ClusterIP、NodePort、LoadBalancer）
  - Ingress控制器
  - DNS服务发现
- [ ] **实践**：在本地或ACK集群中部署简单应用

#### 第3-4天：容器服务ACK（4小时）
- [ ] **ACK（容器服务Kubernetes版）**
  - ACK标准版、ACK Pro版、ACK Serverless
  - 集群创建与配置
  - 节点管理与节点池
  - 网络插件（Flannel、Terway）
  - 存储插件（CSI）
- [ ] **ACR（容器镜像服务）**
  - 镜像仓库管理
  - 镜像构建与推送
  - 镜像安全扫描
- [ ] **实践**：创建ACK集群、部署应用、配置镜像仓库

#### 第5-6天：微服务基础架构（4小时）
- [ ] **EDAS（企业级分布式应用服务）**
  - 应用部署与管理
  - 服务注册与发现
  - 应用监控与诊断
- [ ] **MSE（微服务引擎）**
  - Nacos服务注册与配置中心
  - ZooKeeper服务注册中心
  - 服务治理能力
- [ ] **SAE（Serverless应用引擎）**
  - 应用部署与扩缩容
  - 微服务支持
- [ ] **实践**：在EDAS/MSE中部署微服务应用

#### 第7天：复习与总结（2小时）
- [ ] 回顾本周学习内容
- [ ] 整理Kubernetes和容器核心概念
- [ ] 完成第一周自测题

  - 应用生命周期管理
  - 服务调用链追踪

  - 多环境管理

#### 第12-13天：CI/CD与DevOps（4小时）

  - 多环境发布策略
- [ ] **容器镜像构建**
  - ACR构建服务
  - 镜像安全扫描
  - 镜像加速
- [ ] **应用发布**

## 学习重点与技巧

### 核心知识域优先级
1. **必考重点**（占分比高，60-70%）：
   - **Kubernetes基础**：Pod、Deployment、Service、ConfigMap、Secret等核心资源
   - **容器服务ACK**：集群管理、网络配置、存储管理
   - **微服务治理**：EDAS、MSE（Nacos、ZooKeeper）、服务注册发现
   - **服务网格ASM**：流量管理、安全策略、可观测性
   - **监控可观测性**：ARMS、SLS、Prometheus

2. **重要考点**（20-30%）：
   - **CI/CD与DevOps**：云效、容器镜像构建、发布策略
   - **Serverless**：SAE应用部署与扩缩容
   - **消息队列**：RocketMQ与微服务集成
   - **存储与网络**：PV/PVC、Service网络、Ingress

3. **了解即可**（10%）：
   - 其他云原生相关产品
   - 边缘计算服务

### 学习技巧
1. **理论+实践结合**：
   - 每个产品都要在控制台实际操作
   - 重点练习Kubernetes YAML配置
   - 在ACK集群中部署真实应用
2. **建立知识体系**：
   - 按知识域分类整理（容器、微服务、网格、监控等）
   - 理解云原生架构设计思想
   - 形成从开发到部署到运维的完整知识链
3. **错题本管理**：记录错题、错误原因、正确知识点、相关YAML配置
4. **场景题理解**：
   - 理解微服务架构设计原则
   - 掌握服务治理最佳实践
   - 理解云原生运维模式
5. **时间管理**：每天固定学习时间，保持连续性

### 考试技巧
1. **单选题**：
   - 仔细审题，注意"最合适"、"最佳"、"推荐"等关键词
   - 注意Kubernetes资源对象的配置细节
   - 理解微服务治理场景
2. **多选题**：
   - 不确定的选项不选，宁可少选不错选
   - 注意题目中的"必须"、"应该"等限定词
3. **时间分配**：
   - 单选题1分钟/题
   - 多选题2分钟/题
   - 场景题3-4分钟/题
4. **检查策略**：
   - 标记不确定题目，最后统一检查
   - 重点检查YAML配置相关题目
