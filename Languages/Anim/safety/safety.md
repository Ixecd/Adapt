# Anim 安全——死都在交织期

## 为什么运行时安全不适用

```
编译器：
    程序 crash -> 重启进程。代价 = 一次上下文切换。

Anim：
    信号进了迷走神经 -> 已经在人体里。
    没有 kill -9。没有 ctrl+c。
    一次错误信号 = 一次真实生理响应。
    强度过载 = 岛叶在跑一个不该存在的信号。
    不会 crash —— 会创。
```

Anim 的安全全在交织期完成。能在 Pass 2 拒绝的，不留到 Pass 3。能在交织期插桩的，不等到运行期。

## 三层防线

```
Pass 2: StaticSafety     源码级安全。不看用户。只看结构。
    - 强度 > cap → 拒绝。不生成 ESIR。
    - 点缀配比超上限 → 拒绝。
    - cap 等比缩放 → 不是硬截断。保持混音结构完整性，只调低音量。
    - 组合情绪对冲检测 → 警告。"确认这是设计意图？"不拦截。

Pass 3: UserStateSafety  源码 × 用户上下文。创伤分型交叉判定。
    - 创伤 v1/v2/v3 × 社交/情绪/躯体
    - 禁主不禁点：
        grief_loss 为主旋律 → 拒绝（主旋律触发预期链全断裂）
        grief_loss 为点缀 0.08 → 放行（微量参与，安全暴露练习）
    - 创伤 v3 社交维度 → belonging_certainty 禁主

Pass 4: RuntimeGuard     交织期预埋，运行期激活。
    不是在运行时"判断"危险——
    是交织期已经把所有栅栏放好了。运行时只有"比较"一帧寄存器值。
```

## 紧急截断曲线——不是硬截

```
硬截：强度 80→0 一帧。
    → 这本身是一次预期断裂。岛叶从 80 的预期跌到零——等于另一次打击。
    用断裂去救断裂 = 修好断手拿锤子砸另一只。

紧急截断曲线：
    强度 → 60 → 40 → 20 → 保底包。
    信号沿事先定义好的缓和曲线归零。
    岛叶在足够帧里重新编译预期基线。
```

## 创伤作用域

Anim 宏的 `#[trauma_scope(v1, v2)]` = "我已经为这些创伤阶段做了安全验证"。
无标注的宏 = 默认仅对 trauma: none 开放。安全默认。想扩大作用域 = 显式声明。声明了 = 你负责。
