## 低电平有效 Active-Low

很多信号（复位 rst_n、片选 cs_n、使能、I2C 的 SDA/SCL）都是低电平有效——**"低"才触发**。为什么都这么做：

### 物理原因：接地最稳

```
高电平 = VCC（3.3V），但这个值是"相对的"，会受电源纹波、负载压降、地弹影响而晃动
低电平 = GND（0V），是"绝对基准"——全系统共享同一个地，0V 永远是 0V，不晃
→ 低电平判定裕量大：只要 <0.8V（LVCMOS 0.99V）就算低，稳
→ 高电平要求高：要 >2.31V 才算高，易受波动影响
→ 所以"低"比"高"更容易判定、更可靠
```

### 工程原因：开漏 + 默认安全

```
1. 开漏/集电极开路输出：只能"拉低"（吸收电流），不能推高
   → 低有效方便：器件默认高，需要时拉低触发
2. 上电默认安全：很多信号上电拉高（非激活态），要激活才拉低
   → 低有效 = "默认安全，触发才动"（复位/片选/使能全这套）
3. 工业惯性：复位、片选、I2C 全是低有效，历史传承

典型：I2C 开漏 + 上拉，谁拉低谁说话；复位 rst_n 平时高，拉低才复位
```

### 结论

**接地稳是物理底气，开漏+默认安全是工程惯性**——两者叠加，低有效成为硬件主流约定。对应 Verilog：信号名带 `_n` 后缀 = 低有效（`rst_n`），判断用 `if (!rst_n)`。
