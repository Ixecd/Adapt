## concurrency/ 并行与跨时钟域（预留位）

这是软件人最容易忽略、但 FPGA 最容易翻车的部分。对应 Go 的 concurrency。

### always 块并行
多个 always 块物理并行，没有"顺序"概念（和 goroutine 本质区别：硬件真并行，软件靠调度）。

### 跨时钟域 CDC
```
- 慢→快：打两拍同步（两级寄存器）
- 快→慢：握手 / FIFO
- 单 bit 信号：双触发器同步器
- 多 bit 信号：异步 FIFO / 格雷码
```

### 亚稳态 metastability
```
- 建立/保持时间违规 → 触发器输出不确定
- 不能消除，只能降低概率（打两拍）
- 打两拍后仍 X → 检查时钟关系/约束
```

### 异步 FIFO
```
- 读写不同时钟域
- 指针用格雷码 + 打拍同步
- 满/空判断（领先/滞后位）
```
