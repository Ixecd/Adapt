## 四值逻辑：0 1 X Z

Verilog 里信号有 4 种值，不只是 0/1。真实硬件里只有 0/1（X 和 Z 是仿真/设计概念）。

| 值 | 含义 | 什么时候出现 |
|----|------|-------------|
| 0 | 低电平 | 正常驱动 |
| 1 | 高电平 | 正常驱动 |
| x | 未知/无法判断 | 未初始化、总线冲突、亚稳态、仿真未定义输入 |
| z | 高阻/悬空 | 引脚没接、三态输出未使能 |

```verilog
wire a = 1'b0;
wire b = 1'b1;
wire y;

assign y = a & b;   // 结果是确定的 0，没有 X

// X 出现在"不知道"的地方：
reg x;              // 没赋初值的 reg → 仿真里是 x
wire tri = 1'bz;    // 高阻，类似"没接"
```

- X 是仿真器的"警报"：波形里出现 X = 有未初始化/冲突/亚稳态，回去查
- 两根线直接短接两个输出在标准 CMOS 里是设计错误（总线冲突），仿真器显示 X 提醒

## 上拉/下拉电阻

X 的根源是"不知道"，上拉电阻是"把不知道变成知道"的物理手段。

```verilog
// 三态输出 + 上拉：没人驱动时被上拉拉高，不会悬空乱跳
assign bus = oe ? data : 1'bz;   // oe=0 时输出高阻
```

```
作用1：防悬空   —— 引脚 Z 时被拉成确定电平（默认高/低）
作用2：防冲突   —— 开漏 + 上拉，谁拉低谁说话（I2C 的 SDA/SCL 就是经典）
```

- 不允许不确定的引脚（MODE、复位、片选、开漏总线）都靠电阻钉死电平
- FG202 的 MODE0/1 用 10K 上拉+下拉分压（R45/R46），意图是给确定电平但搞出 0.96V

## wire 家族（线网类型）

`wire` 的变体，大部分只是语义强调，综合结果一样：

| 类型 | 含义 | 用在哪 |
|------|------|--------|
| `wire` | 普通连线，无驱动时 Z（高阻） | 标准组合逻辑，99% 场景 |
| `tri` | 和 wire 完全等价，强调"三态总线" | 多驱动总线（双向数据线） |
| `tri0` | 无驱动时默认拉低为 0 | 防悬空 |
| `tri1` | 无驱动时默认拉高为 1（等效内置上拉） | 防悬空、开漏总线 |
| `trireg` | 电荷存储，无驱动时保持最后值（电容效应） | 仿真建模电荷节点，综合少见 |

## 半双工 vs 全双工（选线网类型的依据）

- **全双工**：收发各一根线，同时双向（UART 的 TX/RX、SPI 的 MOSI/MISO）→ 每根单驱动，`wire` 够
- **半双工**：一根线分时收发，要么发要么收（I2C 的 SDA、CAN、数据总线）→ 共用线要"释放高阻"，需要三态

```verilog
// 全双工：TX/RX 独立线，各一个驱动，不需要 Z
output wire tx;
input  wire rx;

// 半双工：双向线，不发时输出高阻释放总线
inout  tri data_bus;
assign data_bus = tx_en ? tx_data : 1'bz;   // 不发=Z，让给对方
```

**对应关系**：
```
全双工   → 每根线单驱动，同时收发    → wire 就够
半双工   → 一根线分时收发，需释放 Z  → tri + 三态输出
半双工+上拉 → 没人驱动时默认电平     → tri1 / 开漏+外部上拉
```

**I2C 是活例子**：SDA 半双工一根线，开漏输出（只拉低不拉高）+ 上拉电阻——没人拉低时被拉成 1，谁拉低谁说话。对应 `tri1` 或开漏+外部上拉。

## 逻辑电平阈值（CMOS）

阈值看家族，不是统一的 0.7V。0.7V 是二极管/三极管 PN 结压降，不是逻辑阈值。

```
TTL:         高 ≥ 2.0V,   低 ≤ 0.8V
CMOS(5V):    高 ≥ 3.5V,   低 ≤ 1.5V   (0.7×VCC / 0.3×VCC)
CMOS(3.3V):  高 ≥ 2.31V,  低 ≤ 0.99V  (LVCMOS33)
```

实际案例：FG202 的 MODE0/1 实测 0.96V → 按 LVCMOS33 是明确的"逻辑低"（≤0.99V），不是中间态 → MODE≈000 = AUTOBOOT 从内置 Flash 启动。
