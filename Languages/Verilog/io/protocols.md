## io/ 接口协议（预留位）

对应 Go 的 io。FPGA 和外部打交道全靠这些协议，每个都是"状态机 + 时序"。

### 串口 UART
```
- 波特率分频（计数器）
- TX：PISO + 起始位/数据/停止位
- RX：采样中点 + 判定 + SIPO
- 跨时钟域：打拍同步
```
（GW1N 板载 24MHz → rPLL → 7.3728MHz 精准波特，见 FORGET.md）

### SPI
```
- 四线：SCLK / MOSI / MISO / CS
- 4 种模式（CPOL/CPHA 决定相位）
- 主模式：状态机驱动时钟
```

### I2C
```
- 开漏 + 上拉，两根线 SDA/SCL
- 起始/停止条件、ACK/NACK、地址帧
- 双向驱动（inout + 三态）
```

### GPIO 按键消抖
```
- 机械抖动 → 消抖（计数持续 N ms 稳定）
- 边沿检测（打一拍异或）
```
