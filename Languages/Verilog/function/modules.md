## function/ 常用模块（预留位）

学课时边学边补，每个模块配可综合代码。这里是计划清单：

### 计数器 counter
最基本时序模块，任何分频/定时都基于它。
```
- 普通 N bit 计数器
- 使能计数（ce）
- 计数到值清零/翻转
```

### 分频器 divider
用计数器把高频时钟分频成低频。
```
- 偶数分频（2/4/8...）：计数器计数翻转
- 奇数分频（3/5/7...）：需两个沿（posedge+negedge）组合
- 占空比 50% 的奇数分频是常见考点
```

### 流水线 pipeline
把组合逻辑切开插寄存器，提升时钟频率（类似 Go 里"用空间换时间"）。
```
- 组合链太长 → 时序不收敛
- 插一级寄存器 → 延迟加一拍，吞吐提升
```

### 移位寄存器 shift
```
- 串入并出 SIPO（串口接收的基础）
- 并入串出 PISO（串口发送的基础）
- LFSR（伪随机数，测试用）
```

**陷阱：全 0 死锁（移位型计数器/LFSR）**：
```
问题：寄存器全 0 → 反馈 XOR 恒 0 → 移位恒 0 → 永远出不来 1（死锁）
      这也是 LFSR 最大周期是 2^n-1（排除全 0）的原因
解法：
  1. 初值非 0（避免从 0 开始）：reg [3:0] lfsr = 4'b0001;
  2. 硬件兜底（检测全 0 注入 1，自恢复）：
     if (lfsr == 4'd0) lfsr <= 4'b0001;
     else lfsr <= {lfsr[2:0], lfsr[3]^lfsr[2]};
```

**和 ROADMAP 非法状态防御同思想**：凡有"状态/计数"的电路都要问"非法/死锁状态会不会锁死，兜底在哪"——LFSR 防全 0、状态机 default 跳安全态，是同一个"安全兜底"原则。

### 环形缓冲区 ring buffer / FIFO
底层 = **数组 + 读写指针**，指针位宽溢出自动回绕实现"环形"：

```verilog
reg [7:0] buf [0:15];     // 16 槽数组
reg [3:0] wr_ptr, rd_ptr; // 写/读指针

always @(posedge clk) begin
    if (wr_en) begin
        buf[wr_ptr] <= din;
        wr_ptr <= wr_ptr + 1;    // 4 位溢出自动回 0 = 环形
    end
end
always @(posedge clk) begin
    if (rd_en) begin
        dout <= buf[rd_ptr];
        rd_ptr <= rd_ptr + 1;
    end
end
```

- **回绕靠位宽溢出**：4 位指针 +1 到 16 自动回 0，不用判断
- **满/空**：`wr==rd` 空；满 = 加 full 标志 或 留一空槽（`wr+1==rd`）
- **= FIFO 的底层实现**：异步 FIFO（不同时钟）→ 指针格雷码 + 打拍同步（见 concurrency）

### 序列信号发生器
周期输出预定 0/1 序列（如 `1011011` 循环）：
```verilog
reg [6:0] seq = 7'b1011011;
always @(posedge clk)
    seq <= {seq[5:0], seq[6]};   // 循环左移
assign out = seq[6];             // 每拍输出最高位
```
- 移位寄存器存序列循环移出 = 精确复现；LFSR = 伪随机（测试用）
- 本质 = 状态机（每个状态 = 序列位置），"带时钟的 DP"的应用
- 与 Feelings 相关：tVNS 刺激波形（脉冲/频率）就是序列发生器控制

### 函数 function vs 任务 task（调用规则 + 传参）

**调用规则**：
```
函数调用函数：可以
函数调用任务：不能 ← 你的判断
任务调用函数：可以
任务调用任务：可以
→ 函数 = 返回值的表达式（纯组合，不能含延时/控制）
→ 任务 = 语句序列（可含延时/控制，不是表达式）
→ 函数只能调函数（不能调任务），任务能调两者
```

**传参：按值传递，不是地址！**：
```verilog
function [7:0] f(input [7:0] x);
    f = x + 1;
endfunction

reg [7:0] a;
a = f(a);   // 把 a 的"值"拷贝给 x，函数内改 x 不影响 a
```

- **按值传递**（拷贝值），**不是传地址/指针**——函数内改参数不影响调用方
- 对比 C：`f(&a)` 传地址（指针），Verilog 没有"地址"概念
- 原因：Verilog 函数本质 = **组合电路**（信号流过，返回结果），电路只有"信号值"（0/1 或 vector），没有"内存地址"
- **软件人常犯的错**：把 C 的"传指针"带进 Verilog——一进硬件就扔掉"地址/指针/引用"，只有"值"和"信号"（除非显式 ROM/RAM）
