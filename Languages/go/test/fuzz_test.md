## 模糊测试
又称随机测试，一种基于随机输入发现代码缺陷的自动化测试技术

- 对单元测试预定数据的补充，查找未预料错误
- 并非验证逻辑正确，而是发现输入处理缺陷

- 保存在 `_test.go` 文件内
- 函数名以`Fuzz`开头，参数为`*testing.F`
- 类型 `F` 和 `T` 方法类似

- 初始数据，称作 **种子语料**
- 基于种子构造的随机数据，称作 **随机语料**

```go
func FuzzAdd(f *testing.F) {
	// 添加种子(可选)
	f.Add(1, 2)
	f.Add(1, 2)

	// 随机测试
	f.Fuzz(func(t *testing.T, x, y int) {
		add(x, y)
	})
}
```
默认被当做普通单元测试运行。测试数据就是种子，不会引入随机语料

只有添加`-fuzz`参数才会进行随机测试，默认无限期执行，直到失败或用户中断

- `-fuzz` 测试目标
- `-fuzztime` 测试时长或次数(1m30s, 100x)

`go test -v -fuzz Add -fuzztime 10s ./text`

模糊测试基于"覆盖引导"(coverage-guided)
