## fmt

格式化IO，输入和输出

### 输出

内置函数 `print/println`，默认输出到`stderr`，而`fmt.Print`输出到`stdout`

- Errof: 构建 `error` 对象
- Fprint，Fprintf，Fprintfn: 输出到`io.Writer`
- Sprint，Sprintf，Sprintln: 返回字符串

```text
%[填充][宽度][.小数位][序号]格式
```

```go
("% X", "abc")				// 61 62 63
("%02X", []int{0x1, 0xF2})	// 01F2       宽度2，填充0
("%-5s;", "abc")			// abc  ;     左对齐，宽度5
("010.4f", 12.345678)		// 00012.3457 宽度10，小数位4，填充0
("%0*d", 5, 123)				// 00123     从参数读取宽度，值5，填充0
```

- 宽度可从参数列表读取
- 小数位和小数点记入宽度
- Unicode 字符宽度为1

- `%T`: 输出类型信息
- `%v`: 默认格式
- `%+v`: 输出struct字段名
- `%#v`: 按Go语法格式输出

- `%p`: 指针
- `%b`: 二进制整数
- `%d`: 十进制整数
- `%x`: 十六进制，小写
- `%X`: 十六进制，大写
- `%f`: 浮点数
- `%s`: 字符串

- `+`: 数字符号（正数或负数） +100
- `-`: 左对齐
- `#`: 增加前缀
- ` `: 填充空格或省略正数符号
- `0`: 填充0

### 输入

从字符串、文件或终端读取格式化字符串

```go
func main() {
	fmt.Scanln()
}
```
